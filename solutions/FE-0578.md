$f\left(f(x)^2+xy\right)=f\left(x^2\right)+f(x)f(y)$.

Let $c=f(1)$. If $c=0$, we have $P(1,x)\Rightarrow\boxed{f(x)=0}$ for all $x$ which is indeed a solution, and otherwise $c\ne0$. Moreover this is the only constant solution, so from now on we may assume that $f$ is nonconstant.

$P(1,x)\Rightarrow f\left(x+c^2\right)=cf(x)+c$.

$P\left(x,y+c^2\right)\Rightarrow f\left(f(x)^2+xy+c^2x\right)=f\left(x^2\right)+cf(x)f(y)+cf(x)$.

$P(x,y)\Rightarrow cf\left(f(x)^2+xy\right)=cf\left(x^2\right)+cf(x)f(y)$.

Comparing, we have:

$$
f\left(f(x)^2+xy+c^2x\right)=cf\left(f(x)^2+xy\right)+(1-c)f\left(x^2\right)+cf(x).
$$

For $x\ne0$, $f(x)^2+xy$ can take any value, so for $x\ne0$:

$$
f\left(c^2x+y\right)=cf(x)+cf(y)+(1-c)f\left(x^2\right).
$$

First, set $x=-1$, this becomes, using the fact that $f\left(x-c^2\right)=\frac1cf(x)-1$:

$$
\frac1cf(y)-1=cf(-1)+cf(y)+c-c^2,
$$

and since $f$ is nonconstant we need to have $c^2=1$.

Second, set $x=2$ in the relation, using the fact that $f\left(x+2c^2\right)=c^2f(x)+c^2+c$ we have:

$$
c^2f(y)+c^2+c=cf(2)+cf(y)+(1-c)f(4),
$$

so $c^2=c$ which implies (together with $c^2=1$) that $c=1$. Now the relation becomes:

$$
f(x+y)=f(x)+f(y)
$$

for $x\ne0$, but it's clearly true for $x=0$ as well.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=f\left(x^2\right)$.

The full equation becomes:

$$
f\left(f(x)^2\right)+f(xy)=f\left(x^2\right)+f(x)f(y)
$$

so $f$ is multiplicative as well. Well-known that the only additive and multiplicative functions are zero (which we already considered) or $\boxed{f(x)=x}$.
