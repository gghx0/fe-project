This is clearly equivalent to just $f(2f(x)) = 2f(x)$.

Explicit construction: Pick any set $S\subseteq\R$ closed under multiplication by 2 (i.e. $2S := \{2x\mid x\in S\}\subseteq S$). Then any function satisfying $\text{ran}(f)\subseteq S$ and $f(x)=x$ on $2S$ works.

Conversely, any solution is of this form by taking $S = \text{ran}(f)$.
