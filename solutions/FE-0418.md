***

$f$ is injective (assume otherwise and submit $y_1,y_2$)

$f$ is surjective ($x^2+xy$ can be any real)

Let $k=f^{-1}(0)$, submitting $x=k$ we get $k^2+ky = 0 $ and since this must hold for any real $y$ we get $f(0)=0$


Let $s=f^{-1}(-x)$ for $x$ being a non-zero real, submitting $y=s$ we get $s=-x \implies f(-x) = -x$

So the only function that might work is the function $f(x) = x \; , \; \forall \; x \in \mathbb{R}$, easy to see it works
