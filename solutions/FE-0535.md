***
We solve the general equation $$f(g(x)+yf(x))=f\left(x\right)^2+f(xy)$$
***
If $f(k)=0$ for some $k$:

$P(k,x)\Rightarrow f(g(k))=f(kx)$, so $f$ is constant. The only constant solution is $\boxed{f(x)=0}$, which fits

Otherwise, assume $f(x)\ne0$ for all $x\ne0$

If $f(k)\ne k$ for some $k$:

$P\left(k,\frac{g(k)}{k-f(k)}\right)\Rightarrow f(k)=0$, but then $f(k)=k=0$ contradiction.

So $\boxed{f(x)=x}$ for all $x$
