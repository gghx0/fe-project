$f\left(f(x)^2+xf(y)\right)=xf(x)+yf(x)$

$\boxed{f(x)=0}$ is a solution otherwise there is some $j$ with $f(j)\ne0$

$P(j,x)\Rightarrow f\left(f(j)^2+jf(x)\right)=jf(j)+xf(j)\Rightarrow f$ is bijective

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow f\left(kf(x)\right)=0\Rightarrow f(kx)=0\Rightarrow f(x)=0$ which isn't bijective.

So if $f(k)=0$ then $k=0$

$P(x,-x)\Rightarrow f\left(f(x)^2+xf(-x)\right)=0\Rightarrow f(x)^2+xf(-x)=0$

$P(1,0)\Rightarrow f\left(f(1)^2\right)=f(1)\Rightarrow f(1)^2=1\Rightarrow f(-1)=-1\Rightarrow f(1)=1$ using both $f(x)^2+xf(-x)=0$ and injectivity

$P(1,x)\Rightarrow f(1+f(x))=1+x\Rightarrow f(x+2)=f(x)+2$

$P(x,y+2)\Rightarrow f\left(f(x)^2+xf(y)+2x\right)=xf(x)+yf(x)+2f(x)=f\left(f(x)^2+xf(y)\right)+2f(x)$

For $x\ne0$, $f(x)^2+xf(y)$ can take any value, so $f(y+2x)=f(y)+2f(x)$ for all $x,y$ (since $f(y+0)=f(y)+2f(0)$).

Set $y=0$, we get $f(2x)=2f(x)$ and so $f$ is additive.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=xf(x)$

Using additivity:

$$
xf(x)+f(xf(y))=f\left(f(x)^2\right)+f(xf(y))=f\left(f(x)^2+xf(y)\right)=xf(x)+yf(x),
$$

so $Q(x,y):f(xf(y))=yf(x)$.

$Q(1,x)\Rightarrow f(f(x))=x$

$Q(x,f(y))\Rightarrow f(xy)=f(x)f(y)$, and well-known that the only not allzero additive and multiplicative function is $\boxed{f(x)=x}$
