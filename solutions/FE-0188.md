Let $P(x,y)$ denote the given assertion $f(x^2+yf(y)) = x^2+f(y^2).$

$P(x,0) : f(x^2) = x^2 + f(0).$ This means $f(x) = x+f(0)$ for all $x \ge 0$.

$P(x, 1) : f(x^2+f(1)) = x^2+f(1).$ This means $f(x) = x$ for all $x \ge f(1).$ So $x+f(0)=x$ for all $x \ge f(1)$, which means $f(0)=0$ and $f(x)=x$ for all $x \ge 0.$ We have $f(y^2) = y^2$, so 

$$
f(x^2+yf(y)) = x^2 + y^2.
$$

For a fixed $y$, we have $x^2+yf(y) \ge 0$ for all sufficiently large $x$. Therefore, $x^2+yf(y) = f(x^2+yf(y)) = x^2+y^2$ for all sufficiently large $x$ for a fixed $y.$ It follows that $yf(y) = y^2$, and therefore $f(y) = y$ for all $y \neq 0.$ We have $f(0)=0$ too.

So $f(x)=x$ for all real $x.$ This function works.
