$f\left(f(x)^2+f(xy)\right)=f(x)^2+yf(x)$.

$\boxed{f(x)=0}$ is a solution, else there is some $x$ for which $f(x)^2+yf(x)$ can take any value as $y$ varies and so $f$ is surjective.

$P(x,1)\Rightarrow f\left(f(x)^2+f(x)\right)=f(x)^2+f(x)\Rightarrow f\left(x^2+x\right)=x^2+x$ by surjectivity, so $f(x)=x$ for all $x\ge0$ (since $x^2+x$ can take any nonnegative value).

$P(x,x)\Rightarrow f\left(f(x)^2+f\left(x^2\right)\right)=f(x)^2+xf(x)$.

Evaluating the left side we have $f\left(f(x)^2+f\left(x^2\right)\right)=f\left(f(x)^2+x^2\right)=x^2+f(x)^2$, and so $xf(x)=x^2$ for all $x$. Since we already established $f(0)=0$, the unique solution is $\boxed{f(x)=x}$.
