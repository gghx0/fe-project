Let $P(x,y)$ be the assertion $f(xf(x)+xf(y))=x^2+f(x)f(y)$.

$P(0,x)\Rightarrow f(0)=f(0)f(x)$.

If $f(0)\ne0$ then $f(x)=1$ for all $x$, which, upon checking, is not a solution. Contradiction, so we have to have $f(0)=0$.

$P(x,0)\Rightarrow f(xf(x))=x^2\Rightarrow[0,\infty)\subseteq f(\mathbb R)$.

From this we also get ($x=1$) that $f(f(1))=1$ and so ($x=f(1)$) $f(1)^2=1$.

Similarly, $f(-f(-1))=1$ and so $f(-1)^2=1$.

**Case 1:** $f(1)=1$

$P(1,x)\Rightarrow f(1+f(x))=1+f(x)$, so $f(x)=x$ for all $x\ge1$ since $f(x)+1$ takes any value $\ge1$.

If $f(-1)=-1$:

$P(-1,x)\Rightarrow f(1-f(x))=1-f(x)$, so $f(x)=x$ for all $x\le1$ since $-f(x)+1$ takes any value $\le1$.

Combining these two statements, $\boxed{f(x)=x}$.

It remains to consider the subcase $f(-1)=1$.

Let $x>0$ and take some large $y>\max\left\{1,\frac1x-f(x)\right\}$, we have $f(xf(x)+xf(y))=f(xf(x)+xy)=xf(x)+xy$ and so:

$P(x,y)\Rightarrow xf(x)+xy=x^2+yf(x)$.

Varying $y$, we see that $f(x)=x$ for all $x>0$.

$P(-1,x)\Rightarrow f(-1-f(x))=1+f(x)$, so $f(x)=-x$ for all $x\le-1$ since $-f(x)-1$ takes any value $\le-1$.

Let $x<0$ and take some small $y<\min\left\{-1,\frac1x+f(x)\right\}$, we have $f(xf(x)+xf(y))=f(xf(x)-xy)=-xf(x)+xy$ and so:

$P(x,y)\Rightarrow-xf(x)+xy=x^2-yf(x)$.

Varying $y$, we see that $f(x)=-x$ for all $x<0$.

Combining our two conclusions here with $f(0)=0$, we have $\boxed{f(x)=\lvert x\rvert}$ which is indeed a solution.

**Case 2:** $f(1)=-1$

$P(1,x)\Rightarrow f(-1+f(x))=1-f(x)$, so $f(x)=-x$ for all $x\ge-1$ since $f(x)-1$ takes all values $\ge-1$.

In particular, $f(-1)=1$ so:

$P(-1,x)\Rightarrow f(-1-f(x))=1+f(x)$, so $f(x)=-x$ for all $x\le-1$ since $-f(x)-1$ takes all values $\le-1$.

Therefore $\boxed{f(x)=-x}$ for all $x$ which is indeed a solution.
