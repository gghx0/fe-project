$$
f\left(f(x)^2+f(xy)\right)=x^2+xy.
$$

$P(1,x)\Rightarrow f\left(f(1)^2+f(x)\right)=1+x$ so $f$ is bijective.

$P(0,0)\Rightarrow f\left(f(0)^2+f(0)\right)=0$.

$P\left(f(0)^2+f(0),1\right)\Rightarrow f(0)=\left(f(0)^2+f(0)\right)^2+f(0)^2+f(0)$, the only real solution is $f(0)=0$.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=x^2\Rightarrow f^{-1}(x)^2=f\left(x^2\right)$.

So for all $x\ne0$, we have $f^{-1}(x)\ne0$ and so.

$P\left(f^{-1}(x),\frac{f(y)^2}{f^{-1}(x)}\right)\Rightarrow f\left(x^2+y^2\right)=f\left(x^2\right)+f(y)^2$.

Using #183, since $f\equiv0$ isn't a solution we must have $f(x)=x$ for all $x\ge0$, and $f(x)\in\{-x,x\}$ for each $x$. If $f(k)=-k$ for some $k<0$ then it would imply $f(k)=f(-k)$ which contradicts injectivity. So $\boxed{f(x)=x}$ for all $x$.
