**Claim:** if $f(g(x)+f(xy))=x^2+f(xy)$ then $g(x)-x^2$ is constant for $x\ne0$ and $f(x)-x$ is eventually constant.

**Proof.** Let $c=1-g(1)$.

$P(x,0)\Rightarrow f(g(x)+f(0))=x^2+f(0)\Rightarrow[f(0),\infty)\subseteq f(\mathbb R)$.

$P(1,x)\Rightarrow f(g(1)+f(x))=1+f(x)\Rightarrow f(x+g(1))=x+1$ for all $x\ge f(0)$, so $f(x)=x+c$ for all $x\ge f(0)+g(1)$ (proving that $f(x)-x$ is eventually linear).

$P\left(x,\frac yx\right)\Rightarrow f(g(x)+f(y))=x^2+f(y)$ for all $x\ne0$.

For any $x\ne0$, take $y\ge\max\{f(0)+g(1),-g(x)+f(0)+g(1)\}$ and this equation turns into:

$$
g(x)+y+2c=g(x)+f(y)+c=f(g(x)+f(y))=x^2+f(y)=x^2+y+c,
$$

so $g(x)=x^2-c$ for all $x\ne0$.

$f\left(f\left(x^2\right)+f(xy)\right)=x^2+f(xy)$.

By the claim, $f\left(x^2\right)-x^2=c$ for all $x\ne0$ and some constant $c$. Fix $y$ and take $x>\max\left\{0,\sqrt{\lvert f(y)+c\rvert}\right\}$:

$P\left(x,\frac yx\right)\Rightarrow f\left(f\left(x^2\right)+f(y)\right)=x^2+f(y)$

and we obtain:

$$
x^2+f(y)+2c=f\left(x^2+f(y)+c\right)=f\left(f\left(x^2\right)+f(y)\right)=x^2+f(y),
$$

so $c=0$.

Equation reduces to $f\left(x^2+f(xy)\right)=x^2+f(xy)$ so by #317 $f$ has one of the following forms:

$$
f(x)=x
$$

$$
f(x)=\begin{cases}x&\text{if }x>c\\a&\text{if }x=0\\g(x)&\text{if }0\ne x\le c\end{cases}
$$

where $c=\inf f>0$ and $a\in(c,\infty)$, and function $g:(-\infty,c]\setminus\{0\}\to[c,\infty)$

$$
f(x)=\begin{cases}x&\text{if }x\ge c\\c&\text{if }x=0\\g(x)&\text{if }0\ne x<c\end{cases}
$$

where $c=\inf f>0$ and function $g:(-\infty,c)\setminus\{0\}\to[c,\infty)$

$$
f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}
$$

where $c=\inf f\le0$ and function $g:(-\infty,c]\to[c,\infty)$.

Narrowing this down with $f(x)=x$ for all $x>0$ we have $f\equiv x$ or $c\le0$ and hence the solution sets $\boxed{f(x)=x}$ and $f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}$.

Take the case $f\not\equiv x$. Recall that $f(0)\ge c$ by the definition of $c$.

$P(0,0)\Rightarrow f(2f(0))=f(0)$.

If $f(0)>0$, then $2f(0)>c$ so $f(2f(0))=2f(0)$ which implies $f(0)=0$, contradiction.

If $f(0)<0$, $P\left(\sqrt{-f(0)},0\right)\Rightarrow f(0)=0$, contradiction.

So we must have $f(0)=0$, our remaining solution set is:

(if $c=0$:)

$$
\boxed{f(x)=\begin{cases}x&\text{if }x\ge0\\g(x)&\text{if }x<0\end{cases}}
$$

which fits for any function $g:(-\infty,0)\to[0,\infty)$.

(if $c<0$:)

$$
\boxed{f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}}
$$

which fits for any constant $c<0$ and function $g:(-\infty,c]\to[c,\infty)$.
