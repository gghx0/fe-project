$f(f(x)+yf(x))=f(x)+f(xy)$

If $f(\ell)\ne\ell$ for some $\ell$:

$P\left(\ell,\frac{f(\ell)}{\ell-f(\ell)}\right)\Rightarrow f(\ell)=0$

Therefore $f(x)\in\{0,x\}$ for each $x$.

If $f(k)=0$ for some $k\ne0$:

$P(k,1)\Rightarrow f(0)=0$

$P(k,x)\Rightarrow f(xk)=0$, so $\boxed{f(x)=0}$ for all $x$ which is a solution

Otherwise, $f(x)\ne0$ for all $x\ne0$, so $\boxed{f(x)=x}$
