***
We solve the general equation $$f(g(x)+yf(x))=xf(x)+f(xy)$$
***
If $f(k)=0$ for some $k$:

$P(k,x)\Rightarrow f(g(k))=f(kx)$, so $f$ is constant, only solution $\boxed{f(x)=0}$ which fits.

Otherwise assume $f(x)\ne0$ for all $x\ne0$

If $f(k)\ne k$ for some $k$:

$P\left(k,\frac{g(k)}{k-f(k)}\right)\Rightarrow kf(k)=0$

If $k\ne0$ then $f(k)=0$ so $k=0$, contradiction. Only option is $k=0$, we're left with $f(x)=x$ for all $x\ne0$

For $x\ne0$:

$P(x,0)\Rightarrow f(g(x)+xy)=x^2+f(0)$ so $(f(0),\infty)\subseteq f(\mathbb{R})$

$P\left(x,-\frac{g(x)}{f(x)}\right)\Rightarrow f\left(-\frac{xg(x)}{f(x)}\right)=-x^2+f(0)$ so  $(-\infty,f(0))\subseteq f(\mathbb{R})$

so $f$ is surjective (since $f(0)\in f(\mathbb{R})$), and therefore $f(k)=0$ for some $k$ so $k=0$ and our solution is $\boxed{f(x)=x}$
