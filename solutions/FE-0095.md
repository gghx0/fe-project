**Note: we show the solution for the statement of IMO 1992 Q2, which has $x$ and $y$ swapped.**
***
Solution by **e.lopes**.
***

We claim the only solution is $f(x)\equiv x$, which obviously works. We now show it is the only solution. Let $P(x,y)$ denote the assertion that $f(x^2+f(y))=y+f(x)^2$. 
***
**Claim 1:** $f(0)=0$.

_Proof._ Let $f(0)=t$. From $P(0,0)$, $f(t)=t^2$. Also, $P(x,0)$ gives $f(x^2+t) = f(x)^2$, and $P(0,x)$ gives $f(f(x)) = x + t^2$. 

We now evaluate $f(t^2+f(1)^2)$ two ways.

First, it is $f(f(1)^2 + f(t)) = t + f(f(1))^2 = t + (1 + t^2)^2 = 1 + t + 2t^2 + t^4$. 

Second, it is $f(t^2 + f(1 + t)) = 1 + t + f(t)^2 = 1 + t + t^4$. So $t = 0$, as required. 

***

It follows immediately that $f(f(x)) = x$, and $f(x^2) = f(x)^2$.

**Claim 2:** $f$ is additive.

Given any $y$, let $z = f(y)$. Then $y = f(z)$, so $f(x^2 + y) = z + f(x)^2 = f(y) + f(x)^2$.

Now given any positive $x$, take $z$ so that $x = z^2$.

Then $f(x + y) = f(z^2 + y) = f(y) + f(z)^2 = f(y) + f(z^2) = f(x) + f(y)$.

Putting $y = -x$, we get $0 = f(0) = f(x + -x) = f(x) + f(-x)$. Hence $f(-x) = - f(x)$. 

It follows that $f(x + y) = f(x) + f(y)$ holds for all $x$, $y$. 

***

Since $f(x^2)=f(x)^2$, $f$ is bounded below by $0$ over the positive reals. Thus, $f$ is linear and by manual verification only $f(x)=x$ works.
