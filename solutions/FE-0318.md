$$
f\left(x^2+f(xy)\right)=xf(x)+xf(y).
$$

**Claim:** $f(0)=0$.

Suppose otherwise.

$P(0,0)\Rightarrow f(f(0))=0$.

$P(x,0)\Rightarrow f\left(x^2+f(0)\right)=xf(x)+xf(0)$.

$P(-x,0)\Rightarrow f\left(x^2+f(0)\right)=-xf(-x)-xf(0)$, so for all $x\ne0$ we have $f(x)+f(-x)+2f(0)=0$.

In particular, $f(-f(0))=-2f(0)$ and $f(1)+f(-1)+2f(0)=0$.

$P(f(0),1)\Rightarrow f\left(f(0)^2\right)=f(0)f(1)$.

$P(-f(0),-1)\Rightarrow f\left(f(0)^2\right)=2f(0)^2-f(0)f(-1)$.

Subtracting these, $f(0)f(1)+f(0)f(-1)=2f(0)^2$. Now we can divide by $f(0)$ to get $f(1)+f(-1)=2f(0)$, but this contradicts $f(1)+f(-1)+2f(0)=0$.

Using the claim, if $f(k)=0$ for some $k\ne0$ then for all $x\ne0$:

$P(x,0)\Rightarrow f\left(x^2\right)=xf(x)$.

$P\left(x,\frac kx\right)\Rightarrow f\left(x^2\right)=xf(x)+xf\left(\frac kx\right)$, so $f\left(\frac kx\right)=0$ which implies $f(x)=0$ for all $x\ne0$ and so $\boxed{f(x)=0}$ for all $x$ which is indeed a solution.

Otherwise, assume $f(x)\ne0$ for all $x\ne0$. From $f\left(x^2\right)=xf(x)$ we get that $f$ is odd, so:

$P(x,-x)\Rightarrow f\left(x^2-f\left(x^2\right)\right)=0\Rightarrow x^2-f\left(x^2\right)=0$.

Hence, $f(x)=x$ for all $x\ge0$, and since $f$ is odd, $\boxed{f(x)=x}$ for all $x$.
