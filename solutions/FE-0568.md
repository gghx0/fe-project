$f\left(f(x)^2+xy\right)=xf(x)+f(x)f(y)$.

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow f(kx)=0$, so $\boxed{f(x)=0}$ for all $x$ which is indeed a solution.

Otherwise, suppose $f(x)\ne0$ for all $x\ne0$.

$P(-f(0),0)\Rightarrow f\left(f(-f(0))^2\right)=0$, so some $k$ exists and so $f(0)=0$.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=xf(x)$, so if $f(a)=f(b)\ne0$ then $a=b$.

In particular, $f\left(f(1)^2\right)=f(1)$, so since $f(1)\ne0$ we have $f(1)^2=1$.

**Case 1:** $f(1)=1$

$P(1,x)\Rightarrow f(x+1)=f(x)+1$.

$P(x,y+1)\Rightarrow f\left(f(x)^2+xy+x\right)=xf(x)+f(x)f(y)+f(x)=f\left(f(x)^2+xy\right)+f(x)$.

For $x\ne0$, $f(x)^2+xy$ can take any value, so this equation becomes $f(x+y)=f(x)+f(y)$ for all $x\ne0$. Since it's also true for $x=0$, $f$ is additive in general.

Now we can derive that $f\left(f(x)^2+f(y)^2\right)=x^2+y^2$, so using #475, we have $f(x)=x$ for all $x\ge0$. Using $f(x+1)=f(x)+1$ we can extend this to all of $\mathbb R$: we can get by induction in two directions that $f(x+n)=f(x)+n$ for all $n\in\mathbb Z$, then for any $x$ just choose some $n$ such that $x+n\ge0$. We'll obtain $f(x)+n=f(x+n)=x+n$ so our solution in this case is $\boxed{f(x)=x}$.

**Case 2:** $f(1)=-1$

$P(1,x)\Rightarrow f(x+1)=-f(x)-1\Rightarrow f(x+2)=f(x)$.

In particular, $f(3)=f(1)\ne0$ yet $3\ne1$, contradiction.
