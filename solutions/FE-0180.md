Let $P(x,y)$ denote the given assertion $f(x^2+y^2) = xf(x)+f(y)^2.$

$P(1, 0) : f(1) = f(1) + f(0)^2$, which means $f(0)=0$

$P(x,0): f(x^2) = xf(x)$

$P(0,x): f(x^2) = f(x)^2$

So $xf(x) = f(x)^2$ for all real $x$, which means 
$$
f(x) \in \{0, x\}
$$
 for all real $x.$
***
Case 1: $f(x) = 0$ for all real $x$

This function works.
***
Case 2: $f(x_0) \neq 0$ for some $x_0 \neq 0$

We have $f(x_0) = x_0.$

$P(x_0, y) : f(x_0^2 + y^2) = x_0^2 + f(y)^2 \ge x_0^2 > 0.$ So $f(x_0^2 + y^2) \neq 0$, which means $f(x_0^2 + y^2) = x_0^2 + y^2$. This means $f(y)^2 = y^2$. So if $y \neq 0$ then $f(y) \neq 0$ and therefore $f(y) = y.$ We also have $f(0)=0.$ So $f(x) = x$ for all real $x$, and it works.

Combining cases, the functions that work are $f(x)=0$ for all real $x$ and $f(x)=x$ for all real $x.$"
