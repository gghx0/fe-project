We claim the only solutions are $f(x)\equiv x$, $f(x)\equiv -x$, $f(x)\equiv -x+1$, $f(x)\equiv x-1$, and $f(x)\equiv 0$, which obviously work. We now show they are the only solutions. Let $P(x,y)$ denote the assertion that $f(x^2+f(x)f(y))=xf(x)+yf(x)$. 
***

**Case 1:** $f(0)=0$

$\boxed{f(x)=0}$ is a solution, else there is some $j$ with $f(j)\ne0$.

$P(x,0)\Rightarrow f\left(x^2\right)=xf(x)\Rightarrow f$ is odd.

If $f(k)=0$:

$P(j,k)\Rightarrow kf(j)=0\Rightarrow k=0$

$P(x,-x)\Rightarrow f\left(x^2-f(x)^2\right)=f\left(x^2+f(x)f(-x)\right)=0\Rightarrow x^2-f(x)^2=0\Rightarrow f(x)\in\{-x,x\}$ for each $x$

Suppose $f(a)=-a$ and $f(b)=b$ for some $0\ne a\ne b\ne 0$:

$P(a,b)\Rightarrow f\left(a^2-ab\right)=a^2+ab\Rightarrow a^2+ab\in\left\{a^2-ab,ab-b^2\right\}$

In the first case we have $ab=0$, a contradiction, and in the second case we have $a=-b$. However since $f$ is odd this implies $-a=f(a)=-f(b)=-b$ so $a=b$, contradiction.

Hence either $\boxed{f(x)=x}$ or $\boxed{f(x)=-x}$ in this case, which both fit.
***
**Case 2:** $c=f(0)\ne0$

$P(0,x)\Rightarrow f(cf(x))=cx\Rightarrow f$ is bijective

Suppose $f(x+a)=f(x)+b$ for some constants $a$ and $b\ne0$ and all $x$.

For $x\ne cf(0)=f^{-1}(0)$ we have:

$$
P(x,y+a)\Rightarrow f\left(x^2+f(x)f(y)+bf(x)\right)=f\left(x^2+f(x)f(y)\right)+af(x)
$$

Now use $f^{-1}\left(\frac{y-x^2}{f(x)}\right)$ instead of $y$ to cancel some terms, we get $f(y+bf(x))=f(y)+af(x)$. Now $f(x)$ can take any value except $0$, so $f(y+bx)=f(y)+ax$, setting $y=0$ we have $f(x)=\frac abx+c$ whether $x=0$ or $x\ne0$, testing linear solutions in the functional equation we get $\boxed{f(x)=-x+1}$ and $\boxed{f(x)=x-1}$.

Otherwise let's assume that such an $a$ and $b$ cannot exist.

Bring up any $x\ne cf(0)$, and let $g(x)=f^{-1}\left(\frac1{f(x)}\right)$ so that $f(x)f(g(x))=1$.

$P\left(x,y^2+f(y)f(z)\right)\Rightarrow f(x^2+(y+z)f(x)f(y))=xf(x)+y^2f(x)+f(x)f(y)f(z)$

Set $y=g(x)$ and we get:

$$
f\left(x^2+g(x)+z\right)=xf(x)+g(x)^2f(x)+f(z),
$$
which contradicts our statement above if $xf(x)+g(x)^2f(x)\ne0$. Otherwise, we have to have $xf(x)+g(x)^2f(x)=0$ for all such $x$, which means $x=-g(x)^2\le0$ for all $x\ne cf(0)$, contradiction. No further solutions.
