**Note: we show the solution for the statement in the AoPS thread, which is $f(yf(x))=x^2+f(x)f(y-x)$.**
***
Solution by **hyay**.
***

We claim the only solutions are $f(x)\equiv x$, $f(x)\equiv -x$, $f(x)\equiv x+1$ and $f(x)\equiv 1-x$, which obviously work. We now show they are the only solutions. Let $P(x,y)$ denote the assertion that $f(yf(x))=x^2+f(x)f(y-x)$. 

***
$P(0, 0) : f(0) = f(0)^2 \Longrightarrow f(0) = 0$ or $f(0) = 1$.

**Case 1:** $f(0) = 0$. Then we have

$P(x, 0) : f(x)f(-x) = -x^2$

$P(1, 1) : f(f(1)) = 1$

$\Longrightarrow P(f(1), f(1)) : f(f(1)) = f(1)^2$

$\Longrightarrow f(1) = 1$ or $f(1) = -1$.

If $f(1) = 1$, then $P(1, 0)$ gives $f(-1) = -1$, so

$P(1, x+1) : f(x + 1) = f(x) + 1$

$P(-1, x) : f(-x) = 1 - f(x + 1)$

$\Longrightarrow f(x) = -f(-x) \Longrightarrow P(x, 0) : f(x) = x$ or $f(x) = -x$.

Suppose there exists $x \neq 0$ such that $f(x) = -x$, then $f(x + 1) = -x + 1$, which is neither $x + 1$ nor $-x - 1$, contradiction. Hence, $f(x) = x$ for all $x \in \mathbb{R}$.

If $f(1) = -1$, then we can similarly prove $f(x) = -x$ for all $x$.

***

**Case 2:** $f(0) = 1$

$P(1, 0) : f(1)f(-1) = 0 \Longrightarrow f(1) = 0$ or $f(-1) = 0$.
Notice that if $f(x)$ is a solution, then $f(-x)$ is also a solution, so WLOG assume $f(1) = 0$.

***

**Claim 1:** $f$ is surjective. 

_Proof._ $P(x+1, x) : f((x+1)f(x)) = x^2$, so all nonnegative reals are in the range of $f$.

$P(x, \frac{1}{f(x)}) : 0 = x^2 + f(x)f(\frac{1}{f(x)} - x)$ where $x, f(x) \neq 0$, then there exists $t$ such that $f(t) < 0$.

$P(t, x) : f(xf(t)) = t^2 + f(t)f(x-t)$, since $f(t)f(x-t)$ can take any negative value, all negative reals are in the range of $f$.

Hence, $f$ is surjective.

***

Suppose $u, v \in \mathbb{R}$ so that $f(u) = \frac{1}{2}$ and $f(v) = -1$. 

**Claim 2:** If $f(x) = f(y)$ for some $x, y \in \mathbb{R}$, then $x^2 = y^2$. 

_Proof._

$P(v, -x) : f(-x-v) = v^2 - f(x)$

$P(x, -v) : f(-vf(x)) = x^2 + f(x)(v^2 - f(x))$

Comparing $P(x, -v)$ and $P(y, -v)$ gives our desired result.

***

**Claim 3:** $f(\frac{1}{2}) = \frac{1}{2}$. 

_Proof._

$P(v, -x) : f(-x-v) = v^2 - f(x)$

$P(v, \frac{v}{2}) : f(-\frac{v}{2}) = \frac{v^2}{2}$

$P(u, -v) : f(-\frac{v}{2}) = u^2 + \frac{1}{2}(v^2 - \frac{1}{2}) = \frac{v^2}{2} + u^2 - \frac{1}{4} \Longrightarrow u = \frac{1}{2}$ or $u = -\frac{1}{2}$

Assume $f(-\frac{1}{2}) = \frac{1}{2}$. Then,

$P(-\frac{1}{2}, -\frac{1}{2}) : f(-\frac{1}{4}) = \frac{3}{4}$

$P(\frac{1}{2}, -\frac{1}{2} : f(\frac{1}{4}) = \frac{1}{4}$

$P(-\frac{1}{4}, 1) : f(\frac{3}{4}) = \frac{1}{4}$

contradicting Claim 2, so $f(\frac{1}{2}) = \frac{1}{2}$.

***

Now, we have

$P(\frac{1}{2}, \frac{1}{2}) : f(\frac{1}{4}) = \frac{3}{4}$

$P(\frac{1}{2}, x) : f(\frac{1}{2}x) = \frac{1}{2}f(x - \frac{1}{2}) + \frac{1}{4}$

$P(\frac{1}{4}, x) : f(\frac{1}{4}x) = \frac{1}{4}f(x - \frac{3}{4}) + \frac{9}{16}$

$\Longrightarrow \frac{1}{4}f(x - \frac{3}{4}) + \frac{9}{16} = f(\frac{1}{4}x) = \frac{1}{2}f(\frac{1}{2}x - \frac{1}{2}) + \frac{1}{4} = \frac{1}{4}f(x - \frac{3}{2}) + \frac{3}{8}$

$\Longrightarrow f(x + \frac{3}{4}) = f(x) - \frac{3}{4}$

Finally,

$P(x, \frac{3}{4}) : f(\frac{3}{4}f(x)) = x^2 + f(x)f(\frac{3}{4} - x) = (x^2 + f(x)f(-x)) - \frac{3}{4}f(x) = 1 - \frac{3}{4}f(x)$

and since $f$ is surjective, $f(x) = 1 - x$ for all $x \in \mathbb{R}$. After removing our assumption, we get two solutions, $f(x) = x + 1$ and $f(x) = 1 - x$.
