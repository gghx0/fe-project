$$
f\left(xf(x)+f(y)^2\right)=f\left(x^2\right)+y^2.
$$

$P(0,x)\Rightarrow f\left(f(x)^2\right)=f(0)+x^2$, so if $f(a)=f(b)$ then $a^2=b^2$. We can apply this with $x=0\Rightarrow f\left(f(0)^2\right)=f(0)$ obtaining that $f(0)^4=0$ and so $f(0)=0$. In particular, if $f(k)=0$ then $P(0,k)\Rightarrow k=0$.

$P(x,0)\Rightarrow f(xf(x))=f\left(x^2\right)\Rightarrow x^2f(x)^2=x^4$, so $f(x)^2=x^2$ for all $x\ne0$, but it's also true for $x=0$.

Then the equation transforms into $f\left(xf(x)+y^2\right)=f\left(x^2\right)+y^2$ which is #188 with only solution $\boxed{f(x)=x}$.
