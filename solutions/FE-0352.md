**Claim:** if $f(f(k))=k$ for some $k$ then $f(k)^2=k^2$.

$P(k,x)\Rightarrow f\left(kf(k)+f(x)^2\right)=f(k)^2+xf(x)$.

$P(f(k),x)\Rightarrow f\left(kf(k)+f(x)^2\right)=k^2+xf(x)$.

Comparing, we have the result.

Now note that:
$$
f\left(f\left(xf(x)+f(y)^2\right)\right)\overset{P(x,y)}=f\left(f(x)^2+yf(y)\right)\overset{P(y,x)}=xf(x)+f(y)^2,
$$
so we have $f\left(xf(x)+y^2\right)^2=\left(xf(x)+f(y)^2\right)^2$. Expanding with $P(x,y)$, this is:
$$
\left(f(x)^2+yf(y)\right)^2=\left(xf(x)+f(y)^2\right)^2.
$$

$P(0,0)\Rightarrow f\left(f(0)^2\right)=f(0)^2$ so we can plug in $x=f(0)^2$, $y=0$ to the above equation to get $f(0)^8=\left(f(0)^4+f(0)^2\right)^2$ with only solution $f(0)=0$.

Now we can set just $y=0$, it implies that for all $x$, $f(x)^4=x^2f(x)^2$ and so $f(x)\in\{0,-x,x\}$.

Suppose $f(a)=-a$ and $f(b)=b$ for some $a,b\ne0$.

$P(a,b)\Rightarrow f\left(-a^2+b^2\right)=a^2+b^2$.

If $f\left(-a^2+b^2\right)=0$ then $a^2+b^2=0$, impossible for $a,b\ne0$.

If $f\left(-a^2+b^2\right)=-a^2+b^2$ then $2a^2=0$, impossible for $a\ne0$.

If $f\left(-a^2+b^2\right)=a^2-b^2$ then $2b^2=0$, impossible for $b\ne0$.

So this scenario is impossible, and $a$ and $b$ cannot both exist at once.

If $a$ exists, then $f(x)\ne x$ for all $x\ne0$, so $f(x)\in\{0,-x\}$ for all $x$. Let $S=\{x\in\mathbb R\mid f(x)=-x\}$, then if $a,b\in S$ we have:

$P(b,a)\Rightarrow f\left(a^2-b^2\right)=-a^2+b^2$, so $a^2-b^2\in S$.

Thus, our solutions are of the form:

Let $\{0\}\subseteq S\subseteq\mathbb R$ with the property that if $a,b\in S$ then $a^2-b^2\in S$, then:
$$
\boxed{f(x)=\begin{cases}-x&\text{if }x\in S\\0&\text{if }x\notin S\end{cases}}.
$$
We can check that these are solutions by cases on $x\in S$ and subcases on $y\in S$ in $P(x,y)$.

If $b$ exists, then $f(x)\ne-x$ for all $x\ne0$, so $f(x)\in\{0,x\}$ for all $x$. Let $S=\{x\in\mathbb R\mid f(x)=x\}$, then if $a,b\in S$ we have:

$P(a,b)\Rightarrow f\left(a^2+b^2\right)=a^2+b^2$, so $a^2+b^2\in S$.

Thus, our solutions are of the form:
