Define the equivalence relation $\sim$ on $\mathbb{R}$ such that $a \sim b$ for $a, b \in \mathbb{R}$ iff $a = 4^n b$ for some $n \in \mathbb{Z}$, and write $[a]$ to be the equivalence class of any $a \in \mathbb{R}$. Let $X = \mathbb{R}/\!\!\sim$, and call a set $S$ of unordered pairs $\{a, b\}$ _mounkish_ if it is a partition of the elements of $X \setminus \{[0]\}$ into pairs, where each $[a] \in X$ is replaced with a representative element $a \in [a]$. In other words, a mounkish $S$ is defined by any free involution on $X$, along with a choice of representative elements.

We claim that a function $f: \mathbb{R} \to \mathbb{R}$ satisfies $f(2f(x)) = 2x$ (call this property $P$) for all $x \in \mathbb{R}$ iff $f(0) = 0$ and there exists a mounkish set $S$ such that for any $n \in \mathbb{Z}$ and $\{a, b\} \in S$, there is some $m \in \mathbb{Z}$ such that $f(4^n a) = 2^{2n+2m-1}b$ and $f(4^n b) = 2^{2n-2m+1}a$.

Proof. To begin, observe that $f$ is trivially injective: if $f(a) = f(b)$ for $a, b \in \mathbb{R}$, then $f(2f(a)) = 2a = 2b$. We also observe $f(4r) = f(2f(2f(r))) = 4f(r)$ for any $r \in \mathbb{R}$ (call this property $Q$); this implies $f(0) = 0$.

Fix some mounkish $S$. To show that the claimed solution defined by $S$ satisfies $P$ and is consistent, first observe that $f(2f(0)) = 0 = 2f(0)$. In addition, given any $n \in \mathbb{Z}$ and $\{a, b\} \in S$, we know $f(4^n a) = 2^{2n+2m-1}b$ and $f(4^n b) = 2^{2n-2m+1}a$ for some fixed $m \in \mathbb{Z}$, so $f(2f(4^n a)) = f(2^{2n+2m}b) = 2 \cdot 4^n a$ for any $n \in \mathbb{Z}$ and $a \in \mathbb{R}$. Hence, $f$ is valid. Meanwhile, notice that any sequence of applications of $P$ (and by extension $Q$) on the initial pair $\{a, b\}$ may only generate equations in which $f$ takes arguments in $[a] \cup [b]$, so $f$ is also consistent for any $S$.

It remains to show that the claimed conditions are necessary; recall we already showed $f(0) = 0$. First, we claim that for all $r \in \mathbb{R} \setminus \{0\}$, we have $f(r) \neq 2^{2k-1}r$ for any $k \in \mathbb{Z}$. FTSOC, suppose otherwise. Then $f(2^{2k}r) = 2r$, but $f(2^{2k}r) = 2^{2k}f(r) = 2^{4k-1}r$, so $k = \frac{1}{2}$.

As such, let us define the function $g: X \to X$ satisfying $g([r]) = [s]$ iff $f(r) \in [s]$ for $[r], [s] \in X \setminus \{[0]\}$. Let us quickly verify $g$ is well-defined. If $f(r) = s$ for $r, s \in \mathbb{R}$, by $Q$ we have $f(4^n r) = 4^n s$ for any $n \in \mathbb{Z}$, so indeed $\{f(x) : x \in [r]\} = [s]$. Suppose $g([r]) = [s]$ for some $[r], [s] \in X$. By our work on $f$, we know $g([r]) \neq [2r]$. Let us write $r = a$ and $s = 2b$. Then $g([a]) = [2b]$, from which it follows that $g([b]) = [2a]$. The map $[a] \mapsto [b]$ is hence a free involution on $X$. As such, we construct our mounkish $S$ to be precisely the set of pairs $\{a, b\}$ such that $g([a]) = [2b]$ and $g([b]) = [2a]$; it is clear each element of $X$ has exactly one representative found among these pairs.

Translating back to $f$, for each $\{a, b\} \in S$, we have $g([a]) = [2b]$, so $f(a) = 2^{2m-1}b$ for some $m \in \mathbb{Z}$. It follows that $f(2^{2m}b) = 2a$, so $f(b) = 2^{-2m+1}a$. By $Q$, we readily obtain $f(4^n a) = 2^{2n+2m-1}b$ and $f(4^n b) = 2^{2n-2m+1}a$, as desired. We conclude $f$ must be of the form we described.
