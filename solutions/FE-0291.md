Let $P(x, y)$ be the given assertion.

$P(1, y) : f(f(y)f(1) + 1) = y + f(1)$.

Note that this implies that $f$ is bijective.

$P(0, 0): f(0) =0$

$P(1, -f(1)): f(-f(1))f(1) = -1$

$P(-1, f(1)) : f(-1)f(f(1)) = -1$

$P(-1, -y) : f(f(-1)f(-y) + 1) = f(1) + y$

So $f(-1)f(-y) = f(y)f(1)$.

$f(-1)^{2} = f(1)^{2}$, and since $f(1) \neq f(-1)$, we have $f(-1)= -f(1)$, and also since $f(1) \neq f(0) = 0$, we have $f(-y) = -f(y)$, so $f$ is odd.

$P(x, y) + P(x, -y) : f(x^{2}+ f(x)f(y)) + f(x^{2} - f(x)f(y)) = 2f(x^{2})$

Take $x \neq 0$ and $y$ such that $f(x)f(y) = z$.

Then $f(x^{2} + z) + f(x^{2} - z) = 2f(x^{2})$, but since $f$ is odd we have that if $x = 0$ this still holds.

Also note that $f(-x^{2} + z) + f(-x^{2} - z) = -(f(x^{2} + z) + f(x^{2} - z)) = 2f(-x^{2})$, and so $f(x + z) + f(x - z) = 2f(x)$ for all $x$ 
and $z$.

$x = z$ gives $f(2x) = 2f(x)$

$f(x + z) + f(x - z) = f(2x)$

$x + z \to a$ and $x- z \to b$ gives $f(a) + f(b)= f(a + b)$, so $f$ is aditive.

So $f(x^{2}) + xy = f(x^{2} + f(x)f(y)) = f(x^{2}) + f(f(x)f(y))$

So $xy = f(f(x)f(y))$

$y = 1$ gives $f(f(x)f(1)) = x$

$f(f(xy)f(1)) = f(f(x)f(y))$

$f(xy)f(1) = f(x)f(y)$

Define function $g:\mathbb{R}\to \mathbb{R}$ such that $g(x) \equiv \frac{f(x)}{f(1)}$.


Note that $g$ is also bijective and additive as $f(1) \neq 0$. We also have $g(1) = 1$ and $g(0) = 0$.

Since $g(xy) = \frac{f(xy)f(1)}{f(1)^{2}} = \frac{f(x)f(y)}{f(1)^{2}} = g(x)g(y)$.

So $g$ is also multiplicative.

Since $g$ is both additive and multiplicative we have that $g(x) \equiv x$ or $g(x) \equiv 0$.

Since $g(1) = 1$, the second function cannot happen.

So $g(x) \equiv x$, and so $f(x) \equiv cx$ for some constant $c$.

Plugging in $P(1, 1)$, we have that $c = 1$, and so $f(x) \equiv x$ is the only solution.
