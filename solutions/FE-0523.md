$f\left(f(x)^2+yf(x)\right)=x^2+f(x)f(y)$
***
**Case 1:** $f(k)=0$ for some $k$

$P(x,k)\Rightarrow f\left(f(x)^2+kf(x)\right)=x^2$ so $f$ takes every value $\ge0$

Rewrite the equation as:

$$
f\left(f(x)^2+yf(x)\right)=f\left(f(x)^2+kf(x)\right)+f(x)f(y),
$$

we have:

$$
f(x^2+xy)=f(x^2+kx)+xf(y)
$$

for all $x\ge0$. In particular, $f(x+1)=f(x)+c$ where $c=f(k+1)$.

$P(x,y+1)\Rightarrow f\left(f(x)^2+yf(x)+f(x)\right)=x^2+f(x)f(y)+cf(x)=f\left(f(x)^2+yf(x)\right)+cf(x)$

If $f(x)\ne0$ then $f(x)^2+yf(x)$ can take any value and so $f(y+f(x))=f(y)+cf(x)$, but this is also true if $f(x)=0$

Again, $f(x)$ can take any value $\ge0$, so $f(x+y)=f(y)+cx$ for all $x\ge0$, and taking $y\mapsto y-x$ we see that $f(-x+y)=f(y)-cx$ so this 
is true for all $x\le0$ as well. Therefore $f$ is linear, testing we have $\boxed{f(x)=x}$.
***
**Case 2:** $f(x)\ne0$ for all $x$

If $f(0)\ne1$, then:

$P\left(0,\frac{f(0)^2}{1-f(0)}\right)\Rightarrow f(0)=1$, contradiction.

So $f(0)=1$

$P(1,-f(1))\Rightarrow f(1)f(-f(1))=0$, impossible.

Hence no further solutions.
