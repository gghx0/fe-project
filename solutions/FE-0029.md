Let $P(x,y)$ be the assertion $f\left(x+f(y)^2\right)=f(x)+yf(y)$.

If $f(a)=f(b)\ne0$ then $P(0,a)$ and $P(0,b)$ imply $a=b$.

Now $\boxed{f(x)=0}$ is a solution, else there is some $j$ with $f(j)\ne0$. Also, $f$ is a solution iff $-f$ is, so WLOG $f(1)\ge0$.

$P(j,0)\Rightarrow f\left(j+f(0)^2\right)=f(j)\ne0\Rightarrow j+f(0)^2=j\Rightarrow f(0)=0$

$P(0,x)\Rightarrow f\left(f(x)^2\right)=xf(x)$

In particular, $f\left(f(1)^2\right)=f(1)$. If $f(1)\ne0$ then $f(1)^2=1$, so $f(1)=1$.
***
**Case 1:** $f(1)=0$

Since $f(0)=0$, $j\ne0$ and so $jf(j)\ne0$

$P(1,j)\Rightarrow f\left(1+f(j)^2\right)=jf(j)=f\left(f(j)^2\right)$

Since $f\left(1+f(j)^2\right)=f\left(f(j)^2\right)\ne0$, we have $1+f(j)^2=f(j)^2$, contradiction.
***
**Case 2:** $f(1)=1$

$P(x,1)\Rightarrow f(x+1)=f(x)+1$

$P(x,y+1)\Rightarrow f\left(x+f(y)^2+2f(y)\right)+1=f\left(x+f(y)^2+2f(y)+1\right)=f(x)+(y+1)(f(y)+1)=f\left(x+f(y)^2\right)+y+f(y)+1,$

so $f(x+2f(y))=f(x)+y+f(y)$

Take $y\mapsto z+2f(y)$, we have:

$$
f(x)+z+f(z)+y+3f(y)=f(x)+z+2f(y)+f(z+2f(y))=f(x+2f(z+2f(y)))=f(x+2f(z)+2y+2f(y))=f(x+2y)+z+f(z)+y+f(y),
$$

which simplifies as $f(x+2y)=f(x)+2f(y)$.

Set $x=0$, this is $f(2y)=2f(y)$, so $f(x+2y)=f(x)+f(2y)$ implying that $f$ is additive in general.

From $f(x+2f(y))=f(x)+y+f(y)$ we have $2f(f(y))=y+f(y)$ for all $y$, and from the original equation $f\left(f(x)^2\right)=xf(x)$. In the latter, take $x\mapsto x+y$ and use additivity:

$$
xf(x)+yf(y)+xf(y)+yf(x)=f\left(f(x+y)^2\right)=f\left(f(x)^2\right)+2f(f(x)f(y))+f\left(f(y)^2\right)=xf(x)+yf(y)+f(2f(x)f(y)),
$$

so $f(2f(x)f(y))=xf(y)+yf(x)$.

Take $y\mapsto f(y)$, we have:

$$
f(yf(x))+\frac{xf(y)+yf(x)}2=f(yf(x))+f(f(x)f(y))=f(f(x)(y+f(y)))=xf(f(y))+f(x)f(y)=\frac{xy+xf(y)}2+f(x)f(y),
$$

so $f(yf(x))=\frac{xy-yf(x)}2+f(x)f(y)$.

Set $x\mapsto2f(x)-x$, noting that $f(2f(x)-x)=2f(f(x))-f(x)=x$, we have:

$$
xy+f(xy)=xf(y)+yf(x).
$$

Let $g(x)=f(x)-x$, it satisfies the system $g(x+y)=g(x)+g(y)$, $g(xy)=xg(y)+yg(x)$, and $g(g(x))=-\frac32g(x)$. Using these:

$$
\begin{aligned}
-3xg(x)&\overset{(2)}=-\frac32g\left(x^2\right)\\
&\overset{(3)}=g\left(g\left(x^2\right)\right)\\
&\overset{(2)}=g\left(2xg(x)\right)\\
&\overset{(1)}=2g\left(xg(x)\right)\\
&\overset{(2)}=2xg(g(x))+2g(x)^2\\
&\overset{(3)}=-3xg(x)+2g(x)^2
\end{aligned}
$$

and we conclude $g(x)=0$, i.e. $\boxed{f(x)=x}$ for all $x$.

Solution $-f$ is $\boxed{f(x)=-x}$.
