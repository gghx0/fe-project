$$
f\left(f(x)+f\left(y^2\right)\right)=x+y^2\Rightarrow f\left(x+y^2\right)=f(x)+f\left(y^2\right),
$$

which is #15, using the result we get that $f$ is additive. Therefore:

$$
f(x+f(y))=f(x)+f(f(y))=f(x)+y
$$

so we have a reduction to #6. Easy to show that #6 implies $f(f(x))=x$ and $f(x+y)=f(x)+f(y)$ which implies #117, so the equations have the same solution set.
