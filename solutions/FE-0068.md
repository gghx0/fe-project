Let $P(x, y)$ be the given assertion

Note that $f$ cannot be constant.

If $f(u) = 0$ for some $u$, then $P(u, 1) : u = 0$.

$P\left( x, -\frac{f(x)}{x} \right) : f\left( -\frac{f(x)}{x} \right) = -\frac{x}{f(x)}$ for all $x \neq 0$.

$P(1, -f(1)) : f(1-f(1)f(-f(1)))=0$, so there exists $f(u) = 0$, and so we have that $f(x) = 0 \iff x = 0$.

So $f(0) = 0$.

Also note that $P(1, y) : f(f(1)f(y) + 1) =y+ f(1)$ gives that $f$ is bijective.


$P(x, 1) : f(x + f(x)f(1)) = f(x) + x$

$P(1, x) : f(f(x)f(1) + 1) = x + f(1)$

$P(x, x) : f(x + f(x)^{2}) = f(x) + x^{2}$

$P(x, -1) : f(x + f(x)f(-1)) = f(x) - x$

$P(x + f(x)f(y), z) : f(x + f(x)f(y) + f(x)f(z) + xyf(z)) = f(x) + xy + xz$

$P(x + f(x)f(z), y) : f(x + f(x)f(y) + f(x)f(z) + xzf(y)) = f(x) + xy + xz$

So we have that $xyf(z) = xzf(y)$ for all $x$, $y$, and $z$.

Then $x = y = 1$ gives $f(z) \equiv zf(1)$.

Plugging in and simpplifying $xyf(1)^{3} = xy$, and taking $x = y = 1$ gives $f(1)^{3} = 1$, and so $f(1) = 1$.

So $f(x) \equiv x$ for all $x$ is the only solution.
