Let $P(x,y)$ be the assertion $f(2xf(y))=yf(x)+f(xy)$.

**Claim:** $f(1)=1$ (for nonconstant solutions).

Let $c=f(1)$.

$P(x,1)\Rightarrow f(2cx)=2f(x)$.

If $c=0$, this implies that $f$ is constant, and the only constant solution is $\boxed{f(x)=0}$ (testing in the original equation).

Otherwise we may assume $c\ne0$. In particular, substitution of $x=1$ into the last equation gives $f(2c)=2c$.

$P(x,2c)\Rightarrow f(4cx)=2cf(x)+f(2cx)\Rightarrow 2f(2x)=2(c+1)f(x)$, so $f(2x)=(c+1)f(x)$.

If $c=-1$, this implies that $f$ is constant, which we've established to be impossible.

In particular, substitution of $x=1$ into the last equation gives $f(2)=c^2+c$. Moreover:
$$
f(cx)=f\left(\frac12\cdot2cx\right)=\frac1{c+1}f(2cx)=\frac2{c+1}f(x),
$$
and substiting $x=1$ here we have $f(c)=\frac{2c}{c+1}$.

$P(x,2)\Rightarrow f\left(\left(2c^2+2c\right)x\right)=2f(x)+f(2x)\Rightarrow2f((c+1)x)=(c+3)f(x)\Rightarrow f((c+1)x)=\frac{c+3}2f(x)$.

Composing our expressions for $f(2cx)$, $f(2x)$, and $f((c+1)x)$, we have:
$$
f\left(\frac{4c}{c+1}x\right)=2f\left(\frac2{c+1}x\right)=(2c+2)f\left(\frac1{c+1}x\right)\Rightarrow\frac{4c+4}{c+3}f(x).
$$
Doing the same thing we've been doing one last time:

$P(x,c)\Rightarrow f\left(\frac{4c}{c+1}x\right)=cf(x)+f(cx)\Rightarrow\frac{4c+4}{c+3}f(x)=cf(x)+\frac2{c+1}f(x)$, and taking $x$ to be something for which $f(x)\ne0$ (such as $x=1$) we'll obtain $\frac{4c+4}{c+3}=c+\frac2{c+1}$ which resolves as $c\in\{-2,1\}$.

Finally, note that if $c=-2$, $f((c+1)x)=\frac{c+3}2f(x)$ reduces to $f(-x)=\frac12f(x)$. Repeated application implies $f(x)=\frac12f(-x)=\frac14f(x)$ which is impossible for $f$ not identically zero. Only remaining option is $c=1$ as we said.

$P(0,-1)\Rightarrow f(0)=0$.

If $f(k)=0$ for some $k$:

$P(1,k)\Rightarrow k=0$.

$P(xy,z)\Rightarrow f(2xyf(z))=zf(xy)+f(xyz)$.

$P(x,2yf(z))\Rightarrow f(2xzf(y)+2xf(yz))=2yf(x)f(z)+zf(xy)+f(xyz)$.

Call this last assertion $Q(x,y,z)$.

$Q(x,1,y)\Rightarrow f(2xf(y)+2xy)=2f(x)f(y)+yf(x)+f(xy)$.

$Q\left(xy,y,\frac1y\right)\Rightarrow f(2xf(y)+2xy)=2yf(xy)f\left(\frac1y\right)+\frac1yf\left(xy^2\right)+f(xy)$.

Comparing, $2f(x)f(y)+yf(x)=2yf(xy)f\left(\frac1y\right)+\frac1yf\left(xy^2\right)$ for all $y\ne0$; call it $R(x,y)$.

$R\left(x,\frac1x\right)\Rightarrow(2f(x)-x)f\left(\frac1x\right)=\frac{f(x)}x$.

If $2f(x)-x=0$ for some $x\ne0$ then from the above $f(x)=0$, and these statements cannot be true simultaneously. It is therefore safe to divide and get $f\left(\frac1x\right)=\frac{f(x)}{2xf(x)-x^2}$ for all $x\ne0$.

$R\left(x^2,\frac1x\right)\Rightarrow\frac{4f(x)f\left(x^2\right)-xf\left(x^2\right)}{2xf(x)-x^2}=\frac{2f(x)^2}x+x\Rightarrow(4f(x)-x)f\left(x^2\right)=\left(2f(x)^2+x^2\right)(2f(x)-x)$.

If $4f(x)-x=0$ for some $x\ne0$ then $2f(x)^2+x^2>0$, so from the above, $2f(x)-x$ which we already established was impossible. It is therefore safe to divide and get $f\left(x^2\right)=\frac{\left(2f(x)^2+x^2\right)(2f(x)-x)}{4f(x)-x}$.

$R(1,x)\Rightarrow2f(x)+x=\frac{2xf(x)^2}{2xf(x)-x^2}+\frac{\left(2f(x)^2+x^2\right)(2f(x)-x)}{4xf(x)-x^2}$.

Finally:
$$
0=2f(x)+x-\frac{2xf(x)^2}{2xf(x)-x^2}-\frac{\left(2f(x)^2+x^2\right)(2f(x)-x)}{4xf(x)-x^2}=-\frac{8(x-f(x))^2f(x)^2}{x(2f(x)-x)(4f(x)-x)}
$$
for all $x\ne0$, so since we showed that $f(x)\ne0$ for all $x\ne0$ our only remaining solution is $\boxed{f(x)=x}$.
