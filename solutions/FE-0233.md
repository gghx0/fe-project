Solution by **NO_SQUARES**.
***

The answer is $x\mapsto x$ only. 

Fix an arbitrary number $y$. For all nonnegative number $s$ for some $x$ we have $x^2+xf(y)-s=0$ (for example, because $f(y)^2+4s\geqslant0$), so $f$ takes all nonnegative values as well as $x^2+xf(y)$.

Fix a negative number $x$. Then for all $s<0$ the equality $x^2+xf(y)=s$ is equivalent to $f(y)=\frac{s-x^2}{x}>0$, which is holds for some $y$. So $x^2+xf(y)$ takes all real values. It immediately implies that $f(t)=t$ for all real numbers $t$.
