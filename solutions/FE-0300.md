Let $P(x,y)$ be the given assertion $f(x^2+xy) = xf(x) + f(x)f(y).$

$P(0,y) : f(0) = f(0)f(y)$, which means either $f(y)$ is constant or $f(0)=0.$ The only constant function that works is $f(x)=0$, so we have $f(0)=0$ anyway.

$P(x,-x) : 0=xf(x)+f(x)f(-x)$. This means that for every real $x$, 

$$
f(x)=0 \text{ or }f(-x)=-x.
$$

Case 1: $f(x_0) = 0$ for some real $x_0 \neq 0$

$P\left(x_0,\frac{t}{x_0}-x_0\right): f(t) = 0.$ So $f(x)=0$ for all real $x$. This function works.

Case 2: $f(x) \neq 0$ for all nonzero real $x$

We have $f(-x) = -x$ for all nonzero real $x$, which means $f(x)=x$ for all nonzero real $x.$ We have $f(0)=0$ too, so $f(x) = x$ for all real $x.$ This function works.

Combining cases, the functions that work are $f(x)=0$ for all real $x$ and $f(x)=x$ for all real $x.$
