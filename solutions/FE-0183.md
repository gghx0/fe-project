Let $P(x,y)$ denote the given assertion $f(x^2+y^2) = f(x)^2 + f(y^2).$

$P(0,0) : f(0)=0.$

$P(x,0) : f(x^2) = f(x)^2.$

This means $f(x^2+y^2) = f(x^2) + f(y^2)$, so $f(x+y) = f(x) + f(y)$ for all $x, y \ge 0.$ Note that $f(x^2) = f(x)^2$ implies $f(x) \ge 0$ for all $x \ge 0.$ As $f$ is additive and bounded below on nonnegative inputs, $f(x) = cx$ for all $x \ge 0$ for some real constant $c \ge 0.$ As $f(x^2) = f(x)^2$, we have $cx^2 = c^2x^2$ for all $x \ge 0.$ So $c \in \{0,1\}.$

Case 1: $c=0$
The given equation becomes $0 = f(x)^2.$ So $f(x) = 0$ for all real $x.$ This function works.

Case 2: $c=1$
The given equation becomes $x^2 + y^2 = f(x)^2 + y^2.$ This (with $f(x)=x$ for all $x \ge 0$) is equivalent to $f(x) \in \{x, -x\}$ for all $x<0.$ Therefore, we have 

$$
f(x) = \begin{cases} x & x \ge 0 \\ xg(x) & x < 0 \end{cases}
$$

where $g:(-\infty,0) \to \{-1,1\}$ is an arbitrary function. These functions work.

Combining cases, we have $f(x)=0$ for all real $x$, or $f(x) = 

$$
\begin{cases} x & x \ge 0 \\ xg(x) & x < 0\end{cases}
$$

$ where $g:(-\infty,0) \to \{-1,1\}$ is an arbitrary function.
