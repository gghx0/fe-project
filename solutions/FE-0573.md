$f\left(f(x)^2+xy\right)=f(x)^2+f(x)f(y)$

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow\boxed{f(x)=0}$ for all $x$

Otherwise, assume $f(x)\ne0$ for all $x\ne0$.



$P(0,x)\Rightarrow f(0)f(x)=f\left(f(0)^2\right)-f(0)^2$

If $f(0)\ne0$ then $f$ is a constant function, our only other solution is $\boxed{f(x)=\frac12}$.

Otherwise, assume $f(0)=0$.



For $x\ne0$ we have:

$P\left(x,-\frac{f(x)^2}x\right)\Rightarrow f\left(-\frac{f(x)^2}x\right)=-f(x)$

$P\left(-\frac{f(x)^2}x,x+1\right)\Rightarrow-f(x)=f(x)^2-f(x)f(x+1)\Rightarrow f(x+1)=f(x)+1$

Therefore $f(-1)=-1$, so:

$P(-1,x)\Rightarrow f(-x)=-f(x)$ for all $x\ne0$, but it’s also true for $x=0$ and so $f$ is odd.

So for all $y\ne0$:



$$

P(x,y+1)\Rightarrow f\left(f(x)^2+xy+x\right)=f(x)^2+f(x)f(y)+f(x)=f\left(f(x)^2+xy\right)+f(x)

$$



which implies (as $f(x)^2+xy$ takes any value other than $f(x)^2$):



$$

f(x+y)=f(x)+f(y)

$$



for all $y\ne f(x)^2$, and in particular for all $y\le0$ (since $f(x+0)=f(x)+f(0)$ for any $x$). Equation can be therefore manipulated into $f(-x+y)=f(-x)+f(y)$ for all $y\le0$ which implies $f(x-y)=f(x)+f(-y)$ for all $y\le0$ by oddness. Combining $f(x-y)=f(x)+f(-y)$ and $f(x+y)=f(x)+f(y)$ for $y\le0$ we have $f(x+y)=f(x)+f(y)$ for all $y$.



$P(x,0)\Rightarrow f\left(f(x)^2\right)=f(x)^2$

The equation thus reduces to:




$$

f\left(f(x)^2\right)+f(xy)=f(x)^2+f(x)f(y),

$$




so $f$ is multiplicative as well, only other solution $\boxed{f(x)=x}$.
