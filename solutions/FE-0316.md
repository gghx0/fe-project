$f\left(x^2+f(xy)\right)=x^2+xy$

From $x=y=0$, $f(f(0))=0$

Equation is $f(x+f(y))=x+y$ for all $x>0$.

Set $y=f(0)$, we have $f(x)=x+f(0)$ for all $x>0$

For any $y$, take $x$ large enough so that $x+f(y)>0$, we have:

$$
x+f(y)+f(0)=f(x+f(y))=x+y
$$

so $f(y)=y-f(0)$ for all $y$, which implies $\boxed{f(x)=x}$ for all $x$.
