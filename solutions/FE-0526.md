$f\left(f(x)^2+yf(x)\right)=xf(x)+xf(y)$

$P(0,-f(0))\Rightarrow f(0)=0$

$P(x,-f(x))\Rightarrow f(-f(x))=-f(x)$ for all $x\ne0$, but also true for $x=0$

$P(x,0)\Rightarrow f\left(f(x)^2\right)=xf(x)$

$P(-f(x),0)\Rightarrow xf(x)=f\left(f(x)^2\right)=f(x)^2$ so $f(x)\in\{0,x\}$ for each $x$

If $f(k)=0$ for some $k\ne0$ then:

$P(k,x)\Rightarrow\boxed{f(x)=0}$ for all $x$ which is a solution.

Otherwise, $\boxed{f(x)=x}$ for all $x$
