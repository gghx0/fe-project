Let $P(x, y)$ denote $f(2xy)=f(x)f(y)+f(xy)$. From $P(x, 1)$, we have $f(2x)=f(x)(f(1)+1)$ for every real $x$. Using this in original equation gives $f(xy)f(1)=f(x)f(y)$. If $f(1)=0$ then substituting $x=y$ gives $f(x)=0$ for every real number $x$ and this is a solution. Therefore suppose $f(1)\ne 0$. If $f(a)=0$ for some $a\ne 0$ then substituting $y=a$ gives $f(xa)=0$ i.e. $f(x)=0$ for every real $x$.  So assume $f(x)\ne 0$ for every $x\ne 0$. If $f(0)\ne 0$ then substituting $y=0$ gives $f$ is constant function and from direct checking, we have $f(x)=0$ for every $x$. So assume $f(0)=0$. Now consider the function $g(x)=\frac{f(x)}{f(1)}$. Therefore $g(xy)=g(x)g(y)$, $g(2x)=g(x)(f(1)+1)$, $g(0)=0$, $g(1)=1$ and $ g(x)\ne 0$ for every $x\ne 0$. From multiplicity, $g(x)>0$ for every $x>0$. Also $g(2)=f(1)+1$. It is well known that this function has non-trivial solutions. Conversely, it is easy to see that if we take any multiplicative function $g$ then the function $f(x)=g(x)(g(2)-1)$ satisfies the problem condition.
