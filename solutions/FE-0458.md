$f(xf(x)+f(xy))=x^2+xy$.

$P(-1,1)\Rightarrow f(0)=0$.

$P(1,0)\Rightarrow f(f(1))=1$.

$P(f(1),0)\Rightarrow f(1)^2=1$.

**Case 1:** $f(1)=1$:

$P(1,x)\Rightarrow f(f(x)+1)=x+1\Rightarrow f(x+2)=f(f(f(x)+1)+1)=f(x)+2$.

Now we have $f(xf(x)+f(y))=x^2+y$ for all $x\ne0$, so:

$$
f(xf(x)+z^2+y)=x^2+zf(z)+f(y)
$$

for all $x,z\ne0$. Set $z=2$, using $f(x+4)=f(x+2)+2=f(x)+4$ this is:

$$
f(xf(x)+y+4)=x^2+f(y)+4\Rightarrow f(xf(x)+y)=x^2+f(y)
$$

for all $x\ne0$, which implies $f(xf(x)+xy)=x^2+f(xy)$. By #439 we have (combined with $f(1)=1$) the only solution in this case $\boxed{f(x)=x}$.

**Case 2:** $f(1)=-1$:

$P(1,0)\Rightarrow f(-1)=1$.

$P(1,1)\Rightarrow f(-2)=2$.

$P(1,x)\Rightarrow f(f(x)-1)=x+1$.

$P(x,1)\Rightarrow f(xf(x)+f(x))=x^2+x$.

$P(f(x)-1,1)\Rightarrow f(xf(x)+f(x))=f(x)^2-f(x)$.

Comparing, we have $f(x)^2-f(x)=x^2+x$ so $f(x)\in\{-x,x+1\}$ for each $x$.

If $f(k)\ne-k$ for some $k$, then $k\ne0$ and $f(k)=k+1$ so:

$P(k,1)\Rightarrow f\left(k^2+2k+1\right)=k^2+k$.

If $f\left(k^2+2k+1\right)=k^2+2k+2$ then $k=-2$ which contradicts $f(-2)=2$.

If $f\left(k^2+2k+1\right)=-k^2-2k-1$ then $2k^2+3k+1=0$ so $k=-\frac12$ since $k\ne-1$.

So we have $f(x)=-x$ for all $x\ne-\frac12$. Then:

$$
P\left(2,-\frac74\right)\Rightarrow f\left(-\frac12\right)=\frac12,
$$

so $\boxed{f(x)=-x}$ for all $x$ whether $x=-\frac12$ or $x\ne-\frac12$. Easy to verify that this is indeed a solution.
