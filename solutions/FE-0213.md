Note that this problem is precisely FE \#28 with $x$ restricted to the nonnegative reals. We remark that this proof was directly inspired by FE \#475, which is essentially a slightly harder version of this problem.

Let $Q(x, y)$ denote the assertion that $f(x + f(y)^2) = f(x) + y^2$, where $x \geq 0$. We claim that a function $f: \mathbb{R} \to \mathbb{R}$ satisfies $Q(x, y)$ for all $x \in \mathbb{R}_{\geq 0}$ and $y \in \mathbb{R}$ iff $f$ satisfies $\lvert f(x) \rvert = \lvert x \rvert$ for all $x \in \mathbb{R}$ and $f(x) = x$ whenever $x \geq 0$.

Proof. Let us quickly verify all such $f$ work. Since $f(y)^2 = y^2$ for all $y \in \mathbb{R}$, we have $x + f(y)^2 = f(x) + y^2 \geq 0$ for all $x \geq 0$. Hence, $f(x + f(y)^2) = f(x) + y^2$ holds for all $x \in \mathbb{R}_{\geq 0}$ and $y \in \mathbb{R}$.

It remains to show that these are the only solutions. By $Q(0, y)$, we have $f(f(y)^2) = f(0) + y^2$ for any $y \in \mathbb{R}$. Another application yields $f(0) + f(y)^4 = f(f(f(y)^2)^2) = f((f(0) + y^2)^2)$; setting $y = 0$ gives $f(0) + f(0)^4 = f(f(0)^2) = f(0)$, so $f(0) = 0$. It follows that $f(f(y)^2) = y^2$ and $f(y)^4 = f(y^4)$ for all $y \in \mathbb{R}$.

Consider the behavior of $f$ over $\mathbb{R}_{\geq 0}$. For any $x \geq 0$, we have $f(f(\sqrt{x})^2) = x$, so every $x \geq 0$ is the output of $f$ for some input $f(\sqrt{x})^2 \geq 0$. For any $y \geq 0$, we also verify that $f(y) = f(\sqrt[4]{y})^4 \geq 0$. It follows that the restriction of $f$ to $\mathbb{R}_{\geq 0}$ is a surjection to $\mathbb{R}_{\geq 0}$.

As such, we recall that any $r \geq 0$ may be written as $f(y)^2$ for some $y \geq 0$. By $Q(x, y)$, we then have $f(x + r) \geq f(x)$ for any $x, r \geq 0$, so $f$ is nondecreasing over $\mathbb{R}_{\geq 0}$.

Since $f(y)^4 = f(y^4)$, we know that $f(1) \in \{0, 1\}$. If $f(1) = 0$, then $f(0) = f(f(1)^2) = 1$, a contradiction; thus, $f(1) = 1$. Meanwhile, noting that $f(y)^2 \geq 0$, we have by $Q(f(y)^2, y)$ that $f(2f(y)^2) = f(f(y)^2) + y^2 = 2f(f(y)^2)$. Letting $r = f(y)^2$, we have $f(2r) = 2f(r)$ for any $r \geq 0$. Since $f(1) = 1$, it follows that $f(2^n) = 2^n$ for any $n \in \mathbb{Z}$. Applying $Q(x, 2^n)$, we then find $f(x + 4^n) = f(x) + 4^n$ for any $n \in \mathbb{Z}$; since $f(0) = 0$, it follows that that $f(4^n m) = 4^n m$ for any $n, m \in \mathbb{Z}$ with $m \geq 0$.

We have proven $f(x) = x$ for all $x$ in a dense subset of $\mathbb{R}_{\geq 0}$, so we are essentially done. Any $x \geq 0$ may be approximated by $4^n m \leq x \leq 4^n (m + 1)$ to arbitrarily high precision by taking $n \to -\infty$; since $f(4^n m) \leq f(x) \leq f(4^n (m + 1))$, this forces $f(x) = x$ for all $x \geq 0$. As for $x < 0$, one simply notes that $f(f(x)^2) = x^2$, from which it follows that $f(x)^2 = x^2$, implying $\lvert f(x) \rvert = -x$. This concludes the proof.
