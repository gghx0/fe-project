Find all functions $f:\mathbb{R}\to\mathbb{R}$ such that

$$
f\left(f(x)^2+f(y)\right)=xf(x)+f(y)
$$

for all $x,y\in\mathbb{R}$.

**Claim:** $f(x)\in\{0,x\}$ for all $x$

$P(-1,-1)\Rightarrow f(k)=0$ for $k=f(-1)^2+f(-1)$

$P(k,k)\Rightarrow f(0)=0$

$P(0,x)\Rightarrow f(f(x))=f(x)$

$P(f(x),y)\Rightarrow f\left(f(x)^2+f(y)\right)=f(x)^2+f(y)$, comparing with $P(x,y)$ gives $f(x)^2=xf(x)$ hence the claim.

Let $S=\{x\in\mathbb{R}\mid f(x)=x\}$ with $0\in S$. Easy to see from the equation that if $x,y\in S$ then $x^2+y\in S$.

Solution set is $f(x)=\begin{cases}x&\text{if }x\in S\\0&\text{if }x\notin S\end{cases}$ with $\{0\}\subseteq S\subseteq\mathbb{R}$ closed under $(x,y)\mapsto x^2+y$, this is equivalent to the original equation. As BlazingMuddy pointed out, there are nontrivial examples, for instance $S=(-1,\infty)$, $S=[0,\infty)$, $S=\{0\}\cup[1,\infty)$, $S=\mathbb{N}$, $S=3\mathbb{Z}$, $S=\mathbb{Q}\cap(\{0\}\cup[2,3]\cup[4,\infty))$, so we don't think theres a better way to characterize it.
