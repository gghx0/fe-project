Let $P(x,y)$ denote the given assertion.

Plugging $P(0, y)$ gives $f(f(0)y)=f(0)$. Suppose FTSOC $f(0) \ne 0$. Then by varying $y$ we see that $f$ is constant, so $f(x)=c$ for all $x$. Then $P(x,y)$ gives $c=x^2+c$ so $x=0$ but this is not true for all $x$. Thus $f(0)=0$.

Plugging $P(x,0)$ gives $f(x^2)=x^2$ so $f(x)=x$ for all $x \ge 0$. Then $P(1,y)$ gives $f(y+1)=f(y)+1$.

Now we induct on intervals of length $1$. Suppose for an integer $k$, all numbers $x$ in the interval $(-k-1, -k]$ satisfy $f(x)=x$. Then for any number $y$ in the range $(-k-2, -k-1]$ we have $f(y+1)=1+f(y)$ so $y+1=1+f(y)$ so $f(y)=y$, completing the inductive step. The base case is just $k=-1$. Thus the only solution is $f \equiv x$.
