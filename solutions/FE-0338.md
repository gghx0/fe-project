$$
f(xf(x)+yf(y))=xf(x)+f(y)^2.
$$
The obvious thing to do is to swap $x,y$, it divulges that $xf(x)+f(y)^2=yf(y)+f(x)^2$ so $f(x)^2=xf(x)+f(0)^2$. Also, $P(0,0)\Rightarrow f(0)^2=f(0)$, so we may write $f(x)^2=xf(x)+f(0)$ instead.

Now square both sides of $P(x,y)$, we get:

$$
\begin{align*}
x^2f(x)^2+xyf(x)f(y)+xf(x)f(y)^2+yf(y)^3+f(0)&=(xf(x)+yf(y))\left(xf(x)+f(y)^2\right)+f(0)\\
&=(xf(x)+yf(y))f(xf(x)+yf(y))+f(0)\\
&=f(xf(x)+yf(y))^2\\
&=\left(xf(x)+f(y)^2\right)^2\\
&=x^2f(x)^2+2xf(x)f(y)^2+f(y)^4
\end{align*}
$$
which, after some simplification, is:
$$
xyf(x)f(y)+yf(y)^3+f(0)=xf(x)f(y)^2+f(y)^4.
$$
Setting $x=y=0$ gives $f(0)^4=f(0)$, so $f(0)\in\{0,1\}$. If $f(0)=1$, setting just $y=0$ gives $xf(x)=0$. In particular, $f(1)=0$, but then $P(0,1)\Rightarrow1=0$, contradiction. So$f(0)=0$, and setting $x=0$, we have $f(y)^4=yf(y)^3$ so $f(x)\in\{0,x\}$ for each $x$. Finally, note that if $f(a)=a$ and $f(b)=b$ then $P(a,b)\Rightarrow f\left(a^2+b^2\right)=a^2+b^2$, so our solutions are of the form $\boxed{f(x)=\begin{cases}x&\text{if }x\in S\\0&\text{if }x\notin S\end{cases}}$ where $\{0\}\subseteq S\subseteq\mathbb R$ satisfies the closure property that if $a,b\in S$ then $a^2+b^2\in S$. To see that all such functions satisfy the equation, we just takes cases on whether $x$ or $y$ are in $S$.

If $x,y\in S$, then $P(x,y)\Leftrightarrow f\left(x^2+y^2\right)=x^2+y^2$, true because $x^2+y^2\in S$.

If $x\in S$ and $y\notin S$, then $P(x,y)\Leftrightarrow f\left(x^2\right)=x^2$, true because $x^2+0^2\in S$.

If $x\notin S$ and $y\in S$, then $P(x,y)\Leftrightarrow f\left(y^2\right)=y^2$, true because $y^2+0^2\in S$.

If $x,y\notin S$, then $P(x,y)\Leftrightarrow f(0)=0$, true because $0\in S$.
