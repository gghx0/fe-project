$f\left(x^2+xf(y)\right)=f(x)^2+yf(x)$

$\boxed{f(x)=0}$ is a solution, else there is some $j$ with $f(j)\ne0$

$P(0,1)\Rightarrow f(0)=0$

$P(x,0)\Rightarrow f\left(x^2\right)=f(x)^2$

If $f(k)=0$ then $P(j,k)\Rightarrow k=0$

$P(-f(x),x)\Rightarrow f(-f(x))^2+xf(-f(x))=0$

If $f(-f(x))=0$ then $-f(x)=0$ so $x=0$, whereas if $f(-f(x))\ne0$ then the above equation gives $f(-f(x))=-x$. In either case, we have $f(-f(x))=-x$. From this, $f$ is injective.

Recall that $f\left(x^2\right)=f(x)^2$, we have $f(-x)^2=f(x)^2$, so for each $x$ either $f(-x)=f(x)$ or $f(-x)=-f(x)$. If $f(-x)=f(x)$ then from injectivity $x=0$ and so $f(-x)=-f(x)$. Therefore, either case reduces to $f(-x)=-f(x)$, so $f$ is odd.

$f(-f(x))=-x$ becomes $f(f(x))=x$ and so:
