$f\left(x^2+f(xy)\right)=xf(x)+yf(x)$

$\boxed{f(x)=0}$ is a solution, else $f$ is surjective

If $f(1)=0$, $P(1,x)\Rightarrow f(1+f(x))=0\Rightarrow f(x+1)=0$ for all $x$, contradiction.

$P(1,x)\Rightarrow f(1+f(x))=f(1)+xf(1)$ so $f$ is injective since $f(1)\ne0$

$P(0,x)\Rightarrow f(f(0))=xf(0)$, so by varying $x$ we must have $f(0)=0$

$P(x,0)\Rightarrow f\left(x^2\right)=xf(x)$, so $f$ is odd

$P(x,-x)\Rightarrow f\left(x^2-f\left(x^2\right)\right)=0=f(0)\Rightarrow f\left(x^2\right)=x^2$ so $f(x)=x$ for all $x\ge0$, and since $f$ is odd we get $\boxed{f(x)=x}$ for all $x$.
