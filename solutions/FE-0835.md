This FE is equivalent to $f(x+f(x))=x+f(x)$, or equivalently $x+f(x)$ is a fixed point for all $x$. Consider a fixed set $S$, and suppose this is the set of fixed points of $f$. Clearly $S$ must be nonempty. If $x \in S$, then $x+f(x)=2x$ is a fixed point of $f$ as well, i.e. we need $2x \in S$. This is the only other restriction on $S$. If $x \not \in S$, then we just need $x+f(x) \in S$, and we are free to choose $f(x)=s-x$ for any $s \in S$, so long as $s \neq 2x$. If $x \neq 0$, this is always possible, because $2x$ cannot be the only element of $S$ since we have $4x \in S$ as well. If $x=0$ and $S=\{0\}$, then "$2x$ is the only element of $S$" is equivalent to "$x=0$ and $x \in S$", so this is also always possible.

Thus our solutions are characterized as follows: fix a nonempty set $S$ such that $x \in S \implies 2x \in S$. Then if $x \in S$, set $f(x)=x$, and if $x \not \in S$, set $f(x)=s-x$ for some $S \ni s \neq 2x$. These clearly work.
