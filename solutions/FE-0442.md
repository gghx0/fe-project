$f(xf(x)+xy)=xf(x)+f(x)f(y)$

$P(0,x)\Rightarrow f(x)f(0)=f(0)$, if $f(0)\ne0$ then $f(x)=1$ for all $x$ which isn't a solution, so we need to have $f(0)=0$

If $f(1)=0$ then $P(1,x)\Rightarrow\boxed{f(x)=0}$ for all $x$ which is a solution, otherwise assume $f(1)\ne0$.

$P(1,0)\Rightarrow f(f(1))=f(1)$

$P(f(1),0)\Rightarrow f\left(f(1)^2\right)=f(1)^2$

$P(1,-f(1))\Rightarrow f(-f(1))=-1$

$P(f(1),-f(1))\Rightarrow f(1)=1$ since $f(1)\ne0$


$P(1,x)\Rightarrow f(x+1)=f(x)+1$

$P(x,y+1)\Rightarrow f(xf(x)+xy+x)=xf(x)+f(x)f(y)+f(x)=f(xf(x)+xy)+f(x)$

For $x\ne0$, $xf(x)+xy$ can take any value, so $f(x+y)=f(x)+f(y)$ for all $x\ne0$, but it's also true for $x=0$.

$P(x,0)\Rightarrow f(xf(x))=xf(x)$

The equation becomes:

$$
f(xf(x))+f(xy)=xf(x)+f(x)f(y)\Rightarrow f(xy)=f(x)f(y),
$$

and well-known that the only other additive and multiplicative function is $\boxed{f(x)=x}$
