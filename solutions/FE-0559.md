$f\left(f(x)^2+f(x)f(y)\right)=f\left(x^2\right)+xy$

As before, $f$ is surjective, and also injective since if $f(a)=f(b)$ $P(1,a)$ and $P(1,b)$ give $a=b$.

$P(0,x)\Rightarrow f\left(f(0)^2+f(0)f(x)\right)=f(0)\Rightarrow f\left(xf(0)+f(0)^2\right)=f(0)$

If $f(0)\ne0$, by surjectivity we can choose some $x$ such that $f\left(xf(0)+f(0)^2\right)=0$, contradiction.

So $f(0)=0$.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=f\left(x^2\right)\Rightarrow f(x)^2=x^2\Rightarrow f(x)\in\{-x,x\}$

If $f(1)\ne1$, $P(1,1)\Rightarrow f(2)=0$, contradiction so $f(1)=1$.

$P(1,x)\Rightarrow f(1+f(x))=1+x\Rightarrow f(x+2)=f(1+f(1+f(x)))=f(x)+2$

$P(x,y+2)\Rightarrow f\left(f(x)^2+f(x)f(y)+2f(x)\right)=f\left(x^2\right)+xy+2x=f\left(f(x)^2+f(x)f(y)\right)+2x$

Since $f$ is surjective, $f(x)^2+f(x)f(y)$ can take any value for fixed $x\ne0$ as $y$ varies, so we obtain:

$$
Q(x,y):f(y+2f(x))=f(y)+2x
$$

for all $x\ne0$, but also true for $x=0$.

$Q(x,0)\Rightarrow f(2f(x))=2x$

$Q(2f(x),0)\Rightarrow f(4x)=4f(x)$

$Q(2f(x),y)\Rightarrow f(4x+y)=f(4x)+f(y)\Rightarrow f(x+y)=f(x)+f(y)$

So $f$ is additive, and since $f(x)\in\{-x,x\}$ means it's bounded on an interval (for example $\lvert x\rvert\le1$ for all $x\in(-1,1)$) we have that $f$ is linear. Since $f(x)=-x$ isn't a solution we're left with $\boxed{f(x)=x}$
