Let $P(x, y)$ denote $f(xf(x) + f(xy)) = f(x^{2}) + xy$.

$P(1, y) : f(f(y) + f(1)) = y + f(1)$, so $f$ is bijective.

$P(0,0) : f(0) = 0$

Then $P(x, 0) : xf(x) = x^{2}$, so $f(x) = x$ for all $x \neq 0$.

Since $f(0) = 0$, we have that $f(x) \equiv x$, which is a solution.
