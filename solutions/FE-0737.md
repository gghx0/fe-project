"The answer is $f\equiv0$, $f(x)\equiv x$ and $f(x)\equiv-2x$.

$f\equiv0$ clearly works. From now suppose that there exists $y_0$ such that $f(y_0)\neq0$. $P(x, y_0)$ gives $f(...)=2xf(y_0)$, so $f$ is a surjective function. 

Suppose that for some $x_0$ we have $f(x_0)=-x_0$. Then $P(x_0, y)$ gives $f(0)=2x_0f(y)$, so $x_0=0$, because $f$ is surjective. 

For an arbitrary number $d$ there exists a number $y$ such that $f(y)=d$. $P(x, y)$ gives $f(xd+f(x)d)=2xd$ for all real numbers $x$ and $d$.

Now suppose that $x\neq0$ and put $d=\frac{t}{x+f(x)}$ (we have $x+f(x)\neq0$). We obtain $f(t)=2x\cdot\frac{t}{x+f(x)}$ or $f(t)f(x)+xf(t)=2xt$. Putting $x=1$, we get $f(t)=\frac{2}{1+f(1)}\cdot t=ct$ for all $t$. Note that $c\neq0$.

Now we have $c(xcy+cxcy)=2xcy$, so $c+c^2=2$, i.e. $(c-1)(c+2)=0$ and so $c=1$ or $c=2$, as we wanted to prove. "
