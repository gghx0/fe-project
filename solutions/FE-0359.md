Let $P(x,y)$ be the assertion $f\left(xf(x)+f\left(y^2\right)\right)=x^2+y^2$.

$P\left(0,\sqrt x\right)\Rightarrow f(f(x))=x$ for all $x\ge0$

If $f(a)=f(b)$ with $a,b\ge0$ then $a=b$.

Let $x\ge0$:

$P(f(x),y)\Rightarrow f\left(xf(x)+f\left(y^2\right)\right)=f(x)^2+y^2\Rightarrow f(x)^2=x^2$

So for all $x\ge0$ we have $f(x)\in\{x,-x\}$, in particular $f(0)=0$


If there is a constant $C$ such that $f(x)=-x$ for all $x>C$, then WLOG $C\ge0$, we have (from $f(f(x))=x$) that $f(x)=-x$ for all $x<-C$

For any $x$, take $y$ large enough so that $y^2>\max\{C,xf(x)+C\}$, we have:

$$
x^2+y^2=f\left(xf(x)+f\left(y^2\right)\right)=f\left(xf(x)-y^2\right)=-xf(x)+y^2,
$$

so $f(x)=-x$ for all $x\ne0$, i.e. $\boxed{f(x)=-x}$ which is indeed a solution.

Otherwise, suppose that $f(x)=x$ for some arbitrarily large values of $x$.

Suppose there is some $x\ge0$ such that $f(x)\ne x$ and choose $y>x+1$ such that $f\left(y^2\right)=y^2$. We have:

$$
f\left(-x^2+y^2\right)=x^2+y^2
$$

and $-x^2+y^2\ge0$ so either $-x^2+y^2=x^2+y^2$ or $x^2-y^2=x^2+y^2$. In the second case $y=0$ which is impossible, so we need $x=0$, contradiction.

Therefore $f(x)=x$ for all $x\ge0$.

Equation becomes $f(xf(x)+y^2)=x^2+y^2$ which is #185, only solution $\boxed{f(x)=x}$
