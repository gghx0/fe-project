$f\left(x^2+yf(x)\right)=xf(x)+f(xy)$

$P(1,0)\Rightarrow f(0)=0$

If $f(x)\ne x$ then $x\ne0$ and so:

$P\left(x,\frac{x^2}{x-f(x)}\right)\Rightarrow f(x)=0$

Therefore $f(x)\in\{0,x\}$ for each $x$.

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow f\left(k^2\right)=f(kx)$, so $f$ is constant, only solution is $\boxed{f(x)=0}$ which fits.

Otherwise $f(k)=0\Rightarrow k=0$, we have $\boxed{f(x)=x}$
