$$
f\left(x^2+f\left(y^2\right)\right)=xf(x)+y^2.
$$

$P(-x,y)\Rightarrow f\left(x^2+f\left(y^2\right)\right)=-xf(-x)+y^2$, so $f(-x)=-f(x)$ for all $x\ne0$.

$P(0,x)\Rightarrow f\left(f\left(x^2\right)\right)=x^2$, so $f(f(x))=x$ for all $x\ge0$.

For all $-f(0)\ne x<0$ we have $f(f(-x))=-x$ and so $f(-f(x))=-x$. Note that $f(x)\ne0$ since it would contradict $x\ne-f(0)$, so $f(f(x))=x$ for $-f(0)\ne x<0$ as well.

Combining these two statements, we have $f(f(x))=x$ for all $x\ne-f(0)$.

If $f(0)>0$ then:

$P(x,0)\Rightarrow xf(x)=f\left(x^2+f(0)\right)\Rightarrow f(xf(x))=f\left(f\left(x^2+f(0)\right)\right)=x^2+f(0)$ since $x^2+f(0)\ge0$. Here we can set $x=1$ to get $1=f(f(1))=1+f(0)$, contradicting $f(0)>0$.

So $f(0)\le0$ and we get $f(f(-f(0)))=-f(0)$ since $-f(0)\ge0$, and therefore $f(f(x))=x$ for all $x$.

If $f(0)\ne0$ we may perform the following calculation:
$$
-f(0)=f(f(-f(0)))=f(-f(f(0)))=f(0),
$$
so $f(0)=0$.

$P(x,0)\Rightarrow f\left(x^2\right)=xf(x)$.

The equation now transforms into $f\left(x^2+yf(y)\right)=xf(x)+y^2$, which is #189 with solutions $\boxed{f(x)=x}$ and $\boxed{f(x)=-x}$, both fit.
