**Claim:** if $f(g(x)+f(xy))=x^2+f(xy)$ then $g(x)-x^2$ is constant for $x\ne0$ and $f(x)-x$ is eventually constant.

**Proof.** Let $c=1-g(1)$.

$P(x,0)\Rightarrow f(g(x)+f(0))=x^2+f(0)\Rightarrow[f(0),\infty)\subseteq f(\mathbb R)$.

$P(1,x)\Rightarrow f(g(1)+f(x))=1+f(x)\Rightarrow f(x+g(1))=x+1$ for all $x\ge f(0)$, so $f(x)=x+c$ for all $x\ge f(0)+g(1)$ (proving that $f(x)-x$ is eventually linear).

$P\left(x,\frac yx\right)\Rightarrow f(g(x)+f(y))=x^2+f(y)$ for all $x\ne0$.

For any $x\ne0$, take $y\ge\max\{f(0)+g(1),-g(x)+f(0)+g(1)\}$ and this equation turns into:

$$
g(x)+y+2c=g(x)+f(y)+c=f(g(x)+f(y))=x^2+f(y)=x^2+y+c,
$$

so $g(x)=x^2-c$ for all $x\ne0$.

$f\left(f(x)^2+f(xy)\right)=x^2+f(xy)$.

By the claim, $f(x)^2-x^2$ is constant for $x\ne0$. Since $f(x)-x$ is eventually constant, we must have $f(x)^2-x^2=0$ for all $x\ne0$. To see this, we can let $f(x)^2-x^2=a$ and $f(x)-x=b$ for $x>c$ and perform some simple algebra:

$$
(x+b)^2-x^2=a\Rightarrow 2bx+b^2=a
$$

for all $x>c$ which means $b=0$ and $a=b^2$ as desired.

Equation reduces to $f\left(x^2+f(xy)\right)=x^2+f(xy)$ so by #317 $f$ has one of the following forms:

$$
\boxed{f(x)=x}
$$

$$
f(x)=\begin{cases}x&\text{if }x>c\\a&\text{if }x=0\\g(x)&\text{if }0\ne x\le c\end{cases}
$$

where $c=\inf f>0$ and $a\in(c,\infty)$, and function $g:(-\infty,c]\setminus\{0\}\to[c,\infty)$

$$
f(x)=\begin{cases}x&\text{if }x\ge c\\c&\text{if }x=0\\g(x)&\text{if }0\ne x<c\end{cases}
$$

where $c=\inf f>0$ and function $g:(-\infty,c)\setminus\{0\}\to[c,\infty)$

$$
f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}
$$

where $c=\inf f\le0$ and function $g:(-\infty,c]\to[c,\infty)$.

Narrowing this down with $f(x)^2=x^2$ for all $x\ne0$ we have $c\le0$, so it just remains to consider the last solution set $f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}$.

Recall that $c$ was defined as $c=\inf f$, so by definition $f(0)\ge c$. If $f(0)\ne0$ then $f(0)^2+f(0)>f(0)\ge c$ so:

$P(0,0)\Rightarrow f\left(f(0)^2+f(0)\right)=f(0)\Rightarrow f(0)^2+f(0)=f(0)$, contradiction.

So $f(0)=0$.

If $f(x)=x$ for some $x\le c$ then using the fact that $f(x)\ge c$ for all $x$ we must have $x=c$. Therefore $f(x)\ne x$ for all $x<c$, and we have the solution sets $\boxed{f(x)=\lvert x\rvert}$ in the case $c=0$ and:

$$
\boxed{f(x)=\begin{cases}x&\text{if }x>c\\-x&\text{if }x\le c\end{cases}}
$$

and

$$
\boxed{f(x)=\begin{cases}x&\text{if }x\ge c\\-x&\text{if }x<c\end{cases}}
$$

which fits for any constant $c<0$.
