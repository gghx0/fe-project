This is a trivial problem.
***

Observe that the set of all values $x^2+y^2$ can take is the set of all nonnegative real numbers. So the problem is equivalent to finding all functions $f$ with $f(x)=x$ for all nonnegative reals $x.$ Therefore, all functions that work are 

$$
f(x) = \begin{cases}x & x \ge 0 \\ g(x) & x < 0\end{cases}
$$
where $g: (-\infty, 0) \to \mathbb R$ is an arbitrary function.
