$f\left(x^2+xf(y)\right)=f\left(x^2\right)+f(xy)$

If $f(k)=0$ for some $k\ne0$:

$P(x,k)\Rightarrow f(xk)=0$, so $\boxed{f(x)=0}$ for all $x$ which is a solution

Otherwise, assume $f(x)\ne0$ for all $x\ne0$.

$P(x-f(x),x)\Rightarrow f\left((x-f(x))^2\right)=0\Rightarrow(x-f(x))^2=0\Rightarrow\boxed{f(x)=x}$ for all $x$
