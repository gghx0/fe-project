$f\left(x^2+xy\right)=x^2+f(x)f(y)$

Only solution will be $\boxed{f(x)=x}$.

$x=y=0\Rightarrow f(0)\in\{0,1\}$

If $f(0)=1$, $P(1,0)\Rightarrow0=1$, contradiction, so $f(0)=0$.


$y=0\Rightarrow f\left(x^2\right)=x^2$, so $f(x)=x$ for all $x\ge0$

For any $y$ take some $x$ with $x>\max\{0,-y\}$, then $x\ge0$ and $x^2+xy\ge0$ and so:

$$
x^2+xf(y)=x^2+f(x)f(y)=f\left(x^2+xy\right)=x^2+xy,
$$

so $f(y)=y$ for all $y$ since $x\ne0$.
