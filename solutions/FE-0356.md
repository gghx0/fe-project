$$
f\left(xf(x)+f(y)^2\right)=f(x^2)+yf(y).
$$
If $f(a)=f(b)\ne0$:

$P(x,a)\Rightarrow f\left(xf(x)+f(a)^2\right)=f\left(x^2\right)+af(a)$.

$P(x,b)\Rightarrow f\left(xf(x)+f(a)^2\right)=f\left(x^2\right)+bf(a)$, so comparing, $a=b$.

If $f(0)\ne0$ we can use this on:

$P(0,0)\Rightarrow f\left(f(0)^2\right)=f(0)$, it implies $f(0)^2=0$, contradiction.

Therefore $f(0)=0$.

**Claim:** $f\left(x^2\right)\in\left\{0,x^2\right\}$ for all $x$.

Suppose $f\left(u^2\right)\ne0$ for some $u$.

$P(u,0)\Rightarrow f(uf(u))=f\left(u^2\right)$, using our previously mentioned partial injectivity property, we have that if $f\left(x^2\right)\ne0$ then $uf(u)=u^2$. Moreover, since $f\left(u^2\right)\ne0$ we have $u\ne0$, so $f(u)=u$.

$P(0,u)\Rightarrow f\left(u^2\right)=u^2$, the claim is proven.

$P(0,x)\Rightarrow f\left(f(x)^2\right)=xf(x)$, we can apply the above to this equation to get $xf(x)\in\left\{0,f(x)^2\right\}$, so for all $x$ we have $f(x)\in\{0,x\}$.

Finally, note the following two properties: first, if $f(a)=a$ and $f(b)=b$ then

$P(0,a)\Rightarrow f\left(a^2\right)=a^2$.

$P(a,b)\Rightarrow f\left(a^2+b^2\right)=a^2+b^2$

and secondly, if $f(a)=0$ then:

$P(a,0)\Rightarrow f\left(a^2\right)=0$.

The contrapositive of the second statement is that if $a\ne0$ and $f\left(a^2\right)=a^2$ then $f(a)=a$, but $f\left(a^2\right)=a^2\Rightarrow f(a)=a$ is also true for $a=0$. Therefore our solutions look like the following:

Let $\{0\}\subseteq S\subseteq\mathbb R$ with the property that if $a,b\in S$ then $a^2+b^2\in S$, and if $a^2\in S$ then $a\in S$. Then:
$$
\boxed{f(x)=\begin{cases}x&\text{if }x\in S\\0&\text{if }x\notin S\end{cases}}.
$$
To see that these work, take cases.

If $x,y\in S$, then $P(x,y)\Leftrightarrow f\left(x^2+y^2\right)=f\left(x^2\right)+y^2$, true since $x^2+0^2\in S$ and $x^2+y^2\in S$.

If $x\in S$ and $y\notin S$, then $P(x,y)\Leftrightarrow f\left(x^2\right)=f\left(x^2\right)$.

If $x\notin S$ and $y\in S$, then $P(x,y)\Leftrightarrow f\left(y^2\right)=f\left(x^2\right)+y^2$, true since $x^2\notin S$ ($x^2\in S$ would imply $x\in S$) and $0^2+y^2\in S$.

If $x,y\notin S$, then $P(x,y)\Leftrightarrow f(0)=f\left(x^2\right)$, true since $0\in S$ and $x^2\notin S$ as before.

There exist non-trivial examples of $S$, like the algebraic numbers, the formulation can be slightly simplified to be about additive closure and closure under square roots (with some extra work done).
