$$
f\left(x^2+f(x)f(y)\right)=f\left(x^2\right)+yf(x).
$$
Note that $\boxed{f(x)=0}$ is a solution, otherwise there is some $j$ such that $f(j)\ne0$.

$P(j,x)\Rightarrow f\left(j^2+f(j)f(x)\right)=f\left(j^2\right)+xf(j)$, so $f$ is bijective.

If $f(k)=0$, $P(j,k)\Rightarrow k=0$ and so $f(0)=0$.

$P(1,-1)\Rightarrow f(-1)f(1)=-1$.

$P(-1,1)\Rightarrow f(1)+f(-1)=0$, combining these we obtain $f(1)\in\{-1,1\}$. Since $f$ is a solution iff $-f$ is, WLOG $f(1)=1$.

$P(1,x)\Rightarrow f(1+f(x))=1+x\Rightarrow f(x+2)=f(1+f(1+f(x)))=f(x)+2$.

$P(x,y+2)\Rightarrow f\left(x^2+f(x)f(y)+2f(x)\right)=f\left(x^2\right)+yf(x)+2f(x)=f\left(x^2+f(x)f(y)\right)+2f(x)$.

For $x\ne0$, $f(x)\ne0$ and so $x^2+f(x)f(y)$ can take any value, and so we have $f(y+2f(x))=f(y)+2f(x)$. Note that this is also true for $x=0$, so we can apply surjectivity to get $f(y+2x)=f(y)+2x$. By #2, $f(x)=x+f(0)$ for all $x$ so our only other solution is $\boxed{f(x)=x}$. With $-f$ we have the solution $\boxed{f(x)=-x}$.
