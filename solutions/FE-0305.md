$f\left(x^2+xy\right)=f(x)^2+f(x)f(y)$

$P(0,0)\Rightarrow f(0)=2f(0)^2\Rightarrow f(0)\in\left\{0,\frac12\right\}$

$P(1,0)\Rightarrow f(1)=f(1)^2+f(1)f(0)\Rightarrow f(1)\in\left\{0,1,\frac12\right\}$

If $f(1)=0$:

$P(1,x-1)\Rightarrow\boxed{f(x)=0}$ which fits.

If $f(1)=1$:

$P(1,x)\Rightarrow f(x+1)=f(x)+1\Rightarrow f(0)=0$

$P(x,y+1),P(x,y)\Rightarrow f\left(x^2+xy+x\right)-f\left(x^2+xy\right)=f(x)$

Take $y\mapsto\frac{y-x^2}x$, we have:

$$
f(x+y)=f(x)+f(y)
$$

for all $x\ne0$, but also for $x=0$.

$P(x,0)\Rightarrow f\left(x^2\right)=f(x)^2$, so $f$ is bounded below on a nontrivial interval and therefore linear. The only solution in this case is $\boxed{f(x)=x}$

If $f(1)=\frac12$

$P(1,0)\Rightarrow f(0)=\frac12$

$P(0,x)\Rightarrow\boxed{f(x)=\frac12}$

All are solutions.
