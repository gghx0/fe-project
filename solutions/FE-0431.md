$$
f(xf(x)+f(x)f(y))=f\left(x^2\right)+yf(x).
$$
Note that $\boxed{f(x)=0}$ is a solution, any other solution must have some $j$ such that $f(j)\ne0$. If $f(a)=f(b)$:
$$
f\left(j^2\right)+af(j)\overset{P(j,a)}=f(jf(j)+f(j)f(a))=f(jf(j)+f(j)f(b))\overset{P(j,b)}=f\left(j^2\right)+bf(j),
$$
so $a=b$, that is, $f$ is injective.

$P(-f(0),0)\Rightarrow f\left(f(0)^2\right)=f(0)\Rightarrow f(0)^2=0\Rightarrow f(0)=0$.

$P(x,0)\Rightarrow f(xf(x))=f\left(x^2\right)\Rightarrow xf(x)=x^2$, so $f(x)=x$ for all $x\ne0$. Combined with $f(0)=0$ this implies $\boxed{f(x)=x}$ for all $x$.
