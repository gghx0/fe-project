Let $P(x, y)$ denote the problem assertion. We claim that a function $f: \mathbb{R} \to \mathbb{R}$ satisfies $P(x, y)$ for all $x, y \in \mathbb{R}$ iff $f$ satisfies $\lvert f(x) \rvert = \lvert x \rvert$ for all $x \in \mathbb{R}$ and $f(x) = x$ whenever $x \geq 0$.

Let us quickly verify all such $f$ work. Since $f(x)^2 = x^2$ for all $x \in \mathbb{R}$, we have $f(x)^2 + f(y)^2 = x^2 + y^2 \geq 0$. Hence, $f(f(x)^2 + f(y)^2) = x^2 + y^2$.

It remains to show that these are the only solutions. To begin, let us focus on the behavior of $f$ over $\mathbb{R}_{\geq 0}$. For any $x \geq 0$, we have $f(f(\sqrt{x})^2 + f(0)^2) = x$, so every $x \geq 0$ is the output of $f$ for some input $f(\sqrt{x})^2 + f(0)^2 \geq 0$. For any $r \geq 0$, we may then choose $a = f(\sqrt[4]{r})^2 + f(0)^2$ and $b = 2f(0)^2$ to verify that $f(r) = a^2 + b^2 \geq 0$ for all $r \geq 0$. It follows that the restriction of $f$ to $\mathbb{R}_{\geq 0}$ is a surjection to $\mathbb{R}_{\geq 0}$.

We observe that over the nonnegatives, $f$ in fact bijects to $\mathbb{R}_{\geq 0}$. Indeed, to show injectivity over the $\mathbb{R}_{\geq 0}$, we simply note that $f(x) = f(y)$ implies $f(2f(x)^2) = f(2f(y)^2) = 2x^2 = 2y^2$ for any $x, y \geq 0$.

Since $f(2f(x)^2) = 2x^2$, we know $8f(x)^4 = f(2f(2f(x)^2)^2) = f(8x^4)$, so $f(0), f(\frac{1}{2}) \in \{0, \frac{1}{2}\}$. We have $f(2f(0)^2) = 0$ and $f(2f(\frac{1}{2})^2) = \frac{1}{2}$, so we also know $f(0) = \frac{1}{2}$ iff $f(\frac{1}{2}) = 0$. It follows that $f(\frac{1}{4}) = f(f(0)^2 + f(\frac{1}{2})^2) = \frac{1}{4}$.

Evaluating $P(\frac{1}{4}, x)$ yields $f(\frac{1}{16} + f(x)^2) = \frac{1}{16} + x^2$. Nesting this gives $\frac{1}{16} + (\frac{1}{16} + f(x)^2)^2 = f(\frac{1}{16} + f(\frac{1}{16} + f(x)^2)^2) = f(\frac{1}{16} + (\frac{1}{16} + x^2)^2)$. Expanding, we have $\frac{17}{256} + \frac{1}{8}f(x)^2 + f(x)^4 = f(\frac{17}{256} + \frac{1}{8}x^2 + x^4)$. Since $\frac{17}{256} < \frac{1}{2}$, pick $t \in \mathbb{R}$ satisfying $\frac{17}{256} + \frac{1}{8}t^2 + t^4 = \frac{1}{2}$. We obtain $f(\frac{1}{2}) = \frac{17}{256} + \frac{1}{8}f(t)^2 + f(t)^4 \geq \frac{17}{256}$, so necessarily $f(\frac{1}{2}) = \frac{1}{2}$ and $f(0) = 0$.

Given $f(0) = 0$, we then have $f(f(x)^2) = x^2$ by $P(x, 0)$; a second application yields $f(x)^4 = f(f(f(x)^2)^2) = f(x^4)$. By $P(f(x)^2, y)$, we find $f(x^4 + f(y)^2) = f(f(f(x)^2)^2 + f(y)^2) = f(x^4) + y^2$; writing $w = x^4$, we have $f(w + f(y)^2) = f(w) + y^2$ for any $w \geq 0$; call this assertion $Q(w, y)$. Recalling that any $r \geq 0$ may be written as $f(y)^2$ for some $y \geq 0$, we obtain $f(w + r) \geq f(w)$ for any $w, r \geq 0$, so $f$ is nondecreasing over $\mathbb{R}_{\geq 0}$.

Notice that $f(2f(x)^2) = 2x^2 = 2f(f(x)^2)$. Letting $r = f(x)^2$, we have $f(2r) = 2f(r)$ for any $r \geq 0$. Since $f(\frac{1}{2}) = \frac{1}{2}$, it follows that $f(2^n) = 2^n$ for any $n \in \mathbb{Z}$. Applying $Q(w, 2^n)$, we then find $f(w + 4^n) = f(w) + 4^n$ for any $n \in \mathbb{Z}$; since $f(0) = 0$, it follows that that $f(4^n m) = 4^n m$ for any $n, m \in \mathbb{Z}$ with $m \geq 0$.

We have proven $f(x) = x$ for all $x$ in a dense subset of $\mathbb{R}_{\geq 0}$, so we are essentially done. Any $x \geq 0$ may be approximated by $4^n m \leq x \leq 4^n (m + 1)$ to arbitrarily high precision by taking $n \to -\infty$; since $f(4^n m) \leq f(x) \leq f(4^n (m + 1))$, this forces $f(x) = x$ for all $x \geq 0$. As for $x < 0$, one simply notes that $f(f(x)^2) = x^2 = f(f(-x)^2)$, from which $\lvert f(x) \rvert = f(-x) = -x$ follows from the injectivity of $f$ over $\mathbb{R}_{\geq 0}$. This concludes the proof.
