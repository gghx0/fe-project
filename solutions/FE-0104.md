Let $P(x,y)$ denote the given assertion $f(f(x)+yf(y)) = x+f(y^2)$.

$$
P(x,0) : f(f(x)) = x+f(0)
$$

Claim: $f$ is injective.
Proof: If $f(a)=f(b)$ for some reals $a,b$, then $a+f(0) = f(f(a)) = f(f(b)) = b+f(0) \implies a=b.$ $\square$

$P(f(x^2), y): f(x^2+f(0)+yf(y)) = f(x^2) + f(y^2)$

$P(f(y^2),x) : f(y^2+f(0)+xf(x)) = f(y^2) + f(x^2)$

As $f$ is injective, $x^2+f(0)+yf(y) = y^2+f(0)+xf(x).$ This means 

$$
x^2 = xf(x) + C
$$

for some real constant $C.$ By plugging in $x=0$, we get $0 = C.$ So $x^2 = xf(x)$ for all real $x$, which means $f(x) = x$ for all $x \neq 0.$ As $f(f(x)) = x + f(0)$ we get $f(0) = 0$ as well.

So $f(x) = x$ for all real $x.$ This function works.
