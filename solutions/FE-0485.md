Note: To shorten this proof, we invoke the solution of FE \#475.

Let $P(x, y)$ denote the problem assertion. We claim that a function $f: \mathbb{R} \to \mathbb{R}$ satisfies $P(x, y)$ for all $x, y \in \mathbb{R}$ iff $f$ satisfies $\lvert f(x) \rvert = \lvert x \rvert$ for all $x \in \mathbb{R}$ and $f(x) = x$ whenever $x \geq 0$.

Proof. Let us quickly verify all such $f$ work. Since $f(x)^2 = x^2$ and $f(y^2) = y^2$ for all $x, y \in \mathbb{R}$, we have $f(x)^2 + f(y^2) = x^2 + y^2 \geq 0$. Hence, $f(f(x)^2 + f(y^2)) = x^2 + y^2$.

It remains to show that these are the only solutions. For any $x \geq 0$, we have $f(f(\sqrt{x})^2 + f(0)) = x$, so every $x \geq 0$ is the output of $f$ for some input $f(\sqrt{x})^2 + f(0)$.

Next, we shall prove $f(0) = 0$.

First, suppose $f(0) > 0$. Then applying $P(x, 0)$ twice yields $f(x^4 + f(0)) = f(f(f(x)^2 + f(0))^2 + f(0)) = (f(x)^2 + f(0))^2 \geq f(0)^2$ for all $x \in \mathbb{R}$, so we have $f(x + f(0)) \geq f(0)^2$ for all $x \geq 0$. Now, fix some constant $t \in (0, f(0))$. Since $f(t)^2 \geq 0$, we then have $t^2 = f(f(t)^2 + f(0)) \geq f(0)^2$, a clear contradiction. Thus, $f(0) \leq 0$.

As such, let us write $f(0) = -c^2$ for some fixed $c \geq 0$. Recalling that $c$ is in the image of $f$, let $c = f(r)$ for some $r \in \mathbb{R}$. By $P(r, 0)$, it follows that $f(0) = f(f(r)^2 + f(0)) = r^2 \geq 0$. Hence, $f(0) = 0$.

We then conclude by $P(0, f(x))$ that $f(x^2) = f(f(f(x)^2)) = f(x)^2$. Therefore, the assertion $P$ implies the assertion $f(f(x)^2 + f(y)^2) = x^2 + y^2$. In other words, $f$ satisfies FE \#475, so we are done.
