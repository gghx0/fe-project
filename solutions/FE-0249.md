$f\left(x^2+xf(y)\right)=f\left(x^2\right)+yf(x)$.

If $f(k)=0$ for some $k\ne0$:

$P(x,k)\Rightarrow\boxed{f(x)=0}$ which is indeed a solution.

Otherwise, assume $f(x)\ne0$ for all $x\ne0$.

$P(0,-1)\Rightarrow f(0)=0$.

$P(1,-1)\Rightarrow f(1+f(-1))=0\Rightarrow f(-1)=-1$.

$P(-1,f(1))\Rightarrow f(1-f(f(1)))=0\Rightarrow f(f(1))=1$.

$P(1,f(1))\Rightarrow f(2)=f(1)+f(1)^2$.

$P(-1,-1)\Rightarrow f(2)=f(1)+1$.

Comparing, we obtain $f(1)\in\{-1,1\}$. If $f(1)=-1$ then $f(2)=0$ which we already ruled impossible, so $f(1)=1$.

$P(1,x)\Rightarrow f(1+f(x))=1+x$, so $f$ is surjective and:

$$
f(x+2)=f(f(f(x)+1)+1)=f(x)+2.
$$

$P(x,y+2)\Rightarrow f\left(x^2+xf(y)+2x\right)=f\left(x^2\right)+yf(x)+2f(x)=f\left(x^2+xf(y)\right)+2f(x)$.

For $x\ne0$, $x^2+xf(y)$ can take any value (by surjectivity), so:

$$
Q(x,y):f(y+2x)=f(y)+2f(x)
$$

but this is also true for $x=0$.

Setting $y=0$, we have $f(2x)=2f(x)$, so the equation turns into:

$$
f(y+2x)=f(y)+2f(x)=f(y)+f(2x)\Rightarrow f(x+y)=f(x)+f(y),
$$

i.e. $f$ is additive. Original equation now turns into:

$$
f(xf(y))=yf(x).
$$

With $(1,x)$ this is $f(f(x))=x$ and with $(x,f(y))$ this is $f(xy)=f(x)f(y)$. The only additive and multiplicative functions are $\boxed{f(x)=x}$ and $f(x)=0$, the latter one we already considered so no additional solutions.
