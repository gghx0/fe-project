$f\left(f\left(x^2\right)+xf(y)\right)=xf(x)+yf(x)$

$\boxed{f(x)=0}$ is a solution otherwise there is some $j$ with $f(j)\ne0$

$P(j,x)\Rightarrow f\left(f\left(j^2\right)+jf(x)\right)=jf(j)+xf(j)\Rightarrow f$ is bijective

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow f\left(f\left(k^2\right)+kf(x)\right)=0\Rightarrow f\left(f\left(k^2\right)+kx\right)=0\Rightarrow f(x)=0$ which isn't bijective.

So if $f(k)=0$ then $k=0$

$P(-x,x)\Rightarrow f\left(f\left(x^2\right)-xf(x)\right)=0\Rightarrow f\left(x^2\right)=xf(x)$

Equation reduces to $f(xf(x)+xf(y))=xf(x)+yf(x)$ which is #381, only other solution $\boxed{f(x)=x}$
