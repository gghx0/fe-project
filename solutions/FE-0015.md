This is a classic problem. 
***
We claim the only solution is $f(x)\equiv cx$ for some real constant $c$, which obviously works. We now show it is the only solution. Let $P(x,y)$ denote the assertion that $f(x+y^2)=f(x)+f(y^2)$. 

***
Note that $P(x,y)$ implies $f(x+y)=f(x)+f(y)$ for positive $y$.

$P(0,0): f(0)=0$.

$P(-y^2,y): f(-y^2)=-f(y^2)$ so $f$ is odd. 

Hence, $f$ is additive. Since it is bounded over an interval, $f(x)=cx$.
