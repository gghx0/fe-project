Let $P(x,y)$ denote the given assertion $f(x^2+yf(y)) = xf(x)+y^2.$

$P(x,0) : f(x^2) = xf(x)$

$P(0, y) : f(yf(y)) = y^2.$ This means $f(f(y^2)) = y^2$, and therefore $f(f(x)) = x$ for all $x \ge 0.$

Taking $f$ of both sides of $P(x,0)$, we get $x^2 = f(xf(x)).$

We can get, for all $x \ge 0$, $x^2 = f(xf(x)) = f(f(x)f(f(x))) = f(x)^2.$ So $f(x) \in \{x, -x\}$ for all $x \ge 0.$
$P(-x, 0) : f(x^2) = -xf(-x).$ This means $xf(x) = -xf(-x)$, so $f(-x) = -f(x)$ for all real $x$, and so 

$$
f(x) \in \{x,-x\}
$$

for all real $x.$

Case 1: $f(x) = x$ for all real $x$

This function works.

Case 2: $f(x_0) \neq x_0$ for some real $x_0$

We must have $f(x_0) = -x_0 \neq 0.$

$P(x, x_0) : f(x^2 - x_0^2) = xf(x) + x_0^2$. As $f(x)^2 = x^2$ for all real $x$, this means 

$$
\begin{align*}x^4 = x^2f(x)^2 &= (f(x^2-x_0^2) - x_0^2)^2 \\ &= f(x^2-x_0^2)^2 - 2f(x^2-x_0^2)x_0^2 + x_0^4 \\ &= (x^2 - x_0^2)^2 + x_0^4 - 2x_0^2f(x^2-x_0^2) \\ x^4 &= x^4 + x_0^2(-2x^2 + 2x_0^2 - 2f(x^2-x_0^2)) \\ 0 &= -2x^2 + 2x_0^2 - 2f(x^2-x_0^2) \\ f(x^2-x_0^2) &= -(x^2 - x_0^2)\end{align*}
$$

Therefore, $f(x) = -x$ for all $x \ge 0 \ge -x_0^2.$ As $f(-x) = -f(x)$, we have $f(x) = -x$ for all real $x.$ This function works.

Combining cases, the functions that work are $f(x)=x$ for all real $x$ and $f(x)=-x$ for all real $x.$
