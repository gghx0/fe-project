Solution by **der_Englander**.
***

All additive involutions work. This includes pathological solutions.

Putting $y = 0$ gives $f(f(x)) = x + f(0)$ so $f$ is a bijection. 
Now choose $z$ so that $f(z) = 0$; we have $f(y^2) = z + f(y^2)$ so $z$ must be $0$. So $f$ is an involution.

Now putting $x = f(w)$ we get $f(w+y^2) = f(w) + f(y^2)$. Letting $w = -y^2$, we see that $f$ is odd. We already have $f(a+b) = f(a) + f(b)$ where at least one of $a$, $b$ is nonnegative; now we can also see that for negative $a$, $b$:

$$
f(a+b) = -f(-a-b) = -f(-a)-f(-b) = f(a) + f(b).
$$

So we're done.
