Solution by **BlazingMuddy**
***


We claim the only solutions are $f(x)\equiv x$ and $f(x)\equiv -x$, which obviously work. We now show they are the only solutions. Let $P(x,y)$ denote the assertion that $f(f(x^2) + x f(y)) = x^2 + f(x) f(y)$. 
***

First, $P(0, y)$ yields $f(f(0)) = f(0) f(y)$ for all $y \in \mathbb{R}$. Since $f$ cannot be constant, this tells us that $f(0) = 0$. Next, $P(\sqrt{x}, 0)$ yields $f(f(x)) = x$ for all $x \geq 0$. Replacing $y$ with $f(y)$ yields that for any $x \in \mathbb{R}$ and $y \geq 0$,
$$ 
f(f(x^2) + xy) = x^2 + f(x) y. 
$$

For any $x \neq 0$ and for any $y$ large enough (we need $y \geq \max\{0, -x^{-1}\}$), we have
$$ f(f(x^2) + xy + 1) - f(f(x^2) + xy) = (x^2 + f(x)(y + x^{-1})) - (x^2 + f(x) y) = \frac{f(x)}{x}. $$
In particular, for any $x > 0$, there exists a real number $M_x$ such that $f(y + 1) - f(y) = f(x)/x$ for any $y \geq M_x$. Thus we get $f(x)/x = f(1)$ via $f(x)/x = f(y + 1) - f(y) = f(1)$ for some $y \geq \max\{M_x, M_1\}$. Similarly, for any $x < 0$, there exists a real number $M_x$ such that $f(y + 1) - f(y) = f(x)/x$ for any $y \leq M_x$. Thus we get $f(x)/x = -f(-1)$ via $f(x)/x = f(y + 1) - f(y) = -f(-1)$ for some $y \leq \min\{M_x, M_1\}$. In summary, there exist real numbers $c_1$ and $c_2$ such that $f(x) = c_1 x$ for all $x > 0$ and $f(x) = c_2 x$ for all $x < 0$.

If $c_1 > 0$, then $f(f(x)) = x$ for all $x > 0$ yields $c_1 = 1$. Then $P(-1, 1)$ yields $c_2 = -f(-1) = 1$, and so $f(x) = x$ for all $x \in \mathbb{R}$. If $c_1 < 0$, then $f(f(x)) = x$ for all $x > 0$ yields $c_1 c_2 = 1$. But then $P(1, 1)$ yields $c_1^2 = 1$, so $c_1 = c_2 = -1$ and thus $f(x) = -x$ for all $x \in \mathbb{R}$.
