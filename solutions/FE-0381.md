$f(xf(x)+xf(y))=xf(x)+yf(x)$

$\boxed{f(x)=0}$ is a solution, otherwise there is some $j$ with $f(j)\ne0$

$P(j,x)\Rightarrow f(jf(j)+jf(x))=jf(j)+xf(j)\Rightarrow f$ is bijective

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow f(kf(x))=0\Rightarrow f(kx)=0\Rightarrow f(x)=0$ for all $x$ which isn't surjective.

So if $f(k)=0$ then $k=0$

$P(x,-x)\Rightarrow f(xf(x)+xf(-x))=0\Rightarrow xf(x)+xf(-x)=0$, and since $k$ exists we also have $f(0)=0$ so $f$ is odd.


$P(1,0)\Rightarrow f(f(1))=f(1)\Rightarrow f(1)=1$

$P(1,x)\Rightarrow f(1+f(x))=1+x\Rightarrow f(x+2)=f(x)+2$

$P(x,y+2)\Rightarrow f(xf(x)+xf(y)+2x)=xf(x)+yf(x)+2f(x)=f(xf(x)+xf(y))+2f(x)$

If $x\ne0$, then $xf(x)+xf(y)$ can take any value so $f(y+2x)=f(y)+2f(x)$ but this is also true for $x=0$. So ($y=0$) we have $f(2x)=2f(x)$, so $f$ is additive.

$P(x,0)\Rightarrow f(xf(x))=xf(x)$

From additivity:

$$
xf(x)+f(xf(y))=f(xf(x))+f(xf(y))=f(xf(x)+xf(y))=xf(x)+yf(x)
$$

so $Q(x,y):f(xf(y))=yf(x)$.

$Q(1,x)\Rightarrow f(f(x))=x$

$Q(x,f(y))\Rightarrow f(xy)=f(x)f(y)$, and well-known that the only additive and multiplicative function is $\boxed{f(x)=x}$
