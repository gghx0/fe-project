Let $P(x, y)$ denote $f(x^{2} + f(xy)) = x^{2} + xf(y)$ for all reals $x$ and $y$.

$P(0, 0) : f(f(0)) = 0$

$P(1, y) : f(f(y) + 1) = f(y) + 1$, and since $f(u) = 0$ for some $u$ we have that $f(1) = 1$.

Then $f(2) = 2$, and by induction we have $f(n) = n$ for all non-negative integers $n$.

$P(x, 1) : f(x^{2} + f(x)) = x^{2} + x$

$P(x, n) : f(x^{2} + f(xn)) = x^{2} + xn$ for all non-negative integers $n$.

For all $x$, take arbitrarily large positive integer $n$ such that $-4x \leq n^{2}$, i.e. $x \geq -\frac{n^{2}}{4}$.

Then $x = y^{2} + ny$ for some real $y$.

So $P(y, n) : f(y^{2} + f(yn)) = x$, and so $f$ is surjective.

Then $P(1, y) : f(f(y) + 1) = f(y) + 1$, and since $f$ is surjective we have that 

$f(y + 1) = y + 1$ for all $y$, and so $f(x) \equiv x$, which is a solution.
