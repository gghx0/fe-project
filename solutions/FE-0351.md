$f\left(xf(x)+f(y)^2\right)=f(x)^2+y^2$.

Let $c=f(0)$.

**Claim:** if $af(a)=bf(b)$ then $a^2=b^2$.

$P(a,0)\Rightarrow f\left(af(a)+c^2\right)=f(a)^2$.

$P(b,0)\Rightarrow f\left(bf(b)+c^2\right)=f(b)^2$.

Comparing, $f(a)^2=f(b)^2$.

$P(0,a)\Rightarrow f\left(f(a)^2\right)=c^2+a^2$.

$P(0,b)\Rightarrow f\left(f(a)^2\right)=c^2+b^2$.

Comparing, $a^2=b^2$.

**Claim:** $f(0)=0$, $f(1)=1$.

$P(0,0)\Rightarrow f\left(c^2\right)=c^2$.

$P\left(c^2,0\right)\Rightarrow f\left(c^4+c^2\right)=c^4$.

$P\left(0,c^2\right)\Rightarrow f\left(c^4\right)=c^4+c^2$.

So we can apply the first claim on $c^4+c^2$ and $c^4$ to get $\left(c^4+c^2\right)^2=c^8$ with only solution $c=0$.

$P(0,x)\Rightarrow f\left(f(x)^2\right)=x^2$, so we obtain:

$$
f\left(x^4\right)=f\left(f\left(f(x)^2\right)^2\right)=f(x)^4.
$$

In particular, $f(1)=f(1)^4$ so $f(1)\in\{0,1\}$. $f(1)=0$ would give $P(1,1)\Rightarrow0=1$, so we must have $f(1)=1$.

**Claim:** $f$ is odd.

Recall that if $f(a)^2=f(b)^2$ then $a^2=b^2$ (from the first claim). So:

$P(0,x)\Rightarrow f\left(f(x)^2\right)=x^2$.

$P(0,-x)\Rightarrow f\left(f(-x)^2\right)=x^2$, so $f(x)^4=f(-x)^4$ which implies $f(-x)^2=f(x)^2$.

$P\left(x,f(y)^2\right)\Rightarrow f\left(xf(x)+y^4\right)=f(x)^2+f\left(y^4\right)$.

$P\left(-x,f(y)^2\right)\Rightarrow f\left(-xf(-x)+y^4\right)=f(x)^2+f\left(y^4\right)$, so $\left(xf(x)+y^4\right)^2=\left(-xf(-x)+y^4\right)^2$ and so $xf(x)=-xf(-x)$. Combined with $f(0)=0$, this implies $f$ is odd.

**Claim:** $xf(x)\ge0$ for all $x$.

Suppose $uf(u)<0$ for some $u$. From $f\left(f(x)^2\right)=x^2$, $f$ takes any nonnegative value, so there is some $v$ with $uf(u)+f(v)^2=0$. Then:

$P(u,v)\Rightarrow0=f(u)^2+v^2\Rightarrow f(u)=0$, contradiction.

From $f\left(xf(x)+y^4\right)=f(x)^2+f\left(y^4\right)$ the equation transforms into #199:

$$
Q(x,y):f(x+yf(y))=f(x)+f(y)^2
$$

for all $x\ge0$.

**Claim:** $f(x+y+f(y))=f(x)+2f(y)$ for all $x,y>0$.

Take $x,y>0$:

$Q(y,1)\Rightarrow f(y+1)=f(y)+1$.

$Q(x,y+1)\Rightarrow f(x+yf(y)+y+f(y)+1)=f(x)+f(y)^2+2f(y)+1$.

Note that $f(y)\ge0$ from $yf(y)\ge0$, so $x+y+f(y)+1\ge0$ which allows us by $Q(x+y+f(y)+1,y)$ to simplify this to:

$$
f(x+y+f(y)+1)=f(x)+2f(y)+1.
$$

Again, $x+y+f(y)\ge0$ so by $Q(x+y+f(y),1)$ we have:

$$
f(x+y+f(y))=f(x)+2f(y)
$$

as desired.

**Claim:** $f(x)=x$ for all $x>0$.

If $f(k)=0$ then $P(0,k)\Rightarrow k=0$, so $P(0,x)\Rightarrow f\left(f(x)^2\right)=x^2$ implies $(0,\infty)\subseteq f(\mathbb R^+)$.

Recall that $f(x+1)=f(x)+1$ for all $x\ge0$ by $Q(x,1)$, it allows us to say that $f(x+n)=f(x)+n$ for all $x>0$ and $n\in\mathbb Z_{\ge0}$ (induction).

Then in $f(x+y+f(x))=2f(x)+f(y)$, set $y=n-f(x)>0$ for some large enough $n\in\mathbb Z_{\ge0}$, the equation becomes:

$$
f(x)+n=f(x+n)=2f(x)+f(n-f(x))\Rightarrow f(n-f(x))=n-f(x).
$$

Take any $u>0$, we can find some $x$ for which $f(x)=1-\{u\}$ since $f$ takes every nonnegative value, and by the above equation for $n=\lfloor u\rfloor+1$ we have $n-f(x)=u>0$ and so:

$$
f(n-f(x))=n-f(x)\Rightarrow f(\lfloor u\rfloor+\{u\})=\lfloor u\rfloor+\{u\}.
$$

Finally, oddness gives $f(x)=x<0$ and so $\boxed{f(x)=x}$ for all $x$ whether $x>0$, $x=0$, or $x<0$.
