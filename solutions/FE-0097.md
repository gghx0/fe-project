$f\left(f(x)+y^2\right)=f(x)+y^2$ is equivalent to $f(y)=y$ for all $y\ge f(x)$, so solutions are (for a constant $c\in\mathbb{R}$) $f(x)=x$, $f(x)=\begin{cases}g(x)&\text{if }x<c\\x&\text{if }x\ge c\end{cases}$ for a function $g:(-\infty,c)\to[c,\infty)$ or $f(x)=\begin{cases}g(x)&\text{if }x\le c\\x&\text{if }x>c\end{cases}$ for a function $g:(-\infty,c]\to(c,\infty)$
