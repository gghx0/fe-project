$$
f(xf(y)+f(xy))=xf(y)+yf(x).
$$

**Case 1:** $f(1)\ne0$

$P(1,x)\Rightarrow f(2f(x))=f(x)+xf(1)$, so $f$ is injective.

$P(x,y),P(y,x)\Rightarrow f(xf(y)+f(xy))=xf(y)+yf(x)=f(yf(x)+f(xy))$ so by injectivity $xf(y)=yf(x)$ for all $x$. Setting $y=1$ and testing, we have the only solution in this case $\boxed{f(x)=x}$.

**Case 2:** $f(1)=0$

Suppose there is some $j$ with $f(j)\ne0$.

$P(-1,0)\Rightarrow f(0)=0$.

$P(x,1)\Rightarrow f(f(x))=f(x)$.

$P\left(\frac1{f(j)},f(j)\right)\Rightarrow f\left(\frac1{f(j)}\right)=-\frac1{f(j)}$.

Plugging this into $f(f(x))=f(x)$, we have $f\left(-\frac1{f(j)}\right)=-\frac1{f(j)}$.

$P\left(-1,\frac1{f(j)}\right)\Rightarrow f(-1)=-1$.

$P\left(-1,-\frac1{f(j)}\right)\Rightarrow f(-1)=1$.

Contradiction. Since no such $j$ exists, $\boxed{f(x)=0}$ for all $x$ which is indeed a solution.
