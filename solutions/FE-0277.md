$f\left(x^2+f(x)f(y)\right)=x^2+f(xy)$.

Solutions are $\boxed{f(x)=\lvert x\rvert}$ and $\boxed{f(x)=x}$, both can be checked to satisfy the equation.

$P(x,0)\Rightarrow f\left(x^2+f(x)f(0)\right)=x^2+f(0)$, so $[f(0),\infty)\subseteq f(\mathbb R)$.

If $f(0)<0$, this implies that there is some $k$ with $f(k)=0$, and such a $k$ cannot be $0$ itself since $f(0)\ne0$. So:

$P(k,x)\Rightarrow f\left(k^2\right)=k^2+f(kx)$, so $f$ is constant, but there are no constant solutions.

Therefore $f(0)\ge0$.

$P(0,x)\Rightarrow f(f(0)f(x))=f(0)$, so $f(xf(0))=f(0)$ for all $x\ge f(0)$.

For $x\ge0$ we have:

$P(xf(0),0)\Rightarrow f\left(x^2f(0)^2+f(0)^2\right)=x^2f(0)^2+f(0)\Rightarrow f(0)=x^2f(0)^2+f(0)$ (since $x^2f(0)+f(0)\ge f(0)$), and since this is true for all such $x$ we must have $f(0)=0$.

$P(x,0)\Rightarrow f\left(x^2\right)=x^2$, so $f(x)=x$ for all $x\ge0$.

$P(x,x)\Rightarrow f\left(x^2+f(x)^2\right)=x^2+f\left(x^2\right)\Rightarrow x^2+f(x)^2=2x^2$, so $f(x)\in\{-x,x\}$ for each $x$.

It remains to consider whether $f(x)=-x$ or $f(x)=x$ for $x<0$.

If $f(-k)=k$ for some $k>0$, then recall $f(k)=k$.

$P(x,k)\Rightarrow f\left(x^2+kf(x)\right)=x^2+f(xk)$.

$P(x,-k)\Rightarrow f\left(x^2+kf(x)\right)=x^2+f(-xk)$.

Comparing, we have $f(xk)=f(-xk)$ so (since $k\ne0$) $f$ is even, our solution in this case is $f(x)=\lvert x\rvert$.

Otherwise, $f(-x)=-x$ for all $x>0$ and our solution is $f(x)=x$.
