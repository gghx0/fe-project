Find all functions $f:\mathbb R\to\mathbb R$ such that:

$$
f\left(xf(x)+f(y)^2\right)=xf(x)+y^2
$$

for all $x,y\in\mathbb R$.

Let $P(x,y)$ be the assertion $f\left(xf(x)+f(y)^2\right)=xf(x)+y^2$.

We claim that the solutions are of the form:

$$
\boxed{f(x)=\begin{cases}-x&\text{if }x\in S\\x&\text{if }x\notin S\end{cases}}
$$

where $c\in(0,1)$ is any constant and $S\subseteq\left[-c,-c^2\right)$ or $S\subseteq\left(-c,-c^2\right]$ any set. This includes the particular solution $f(x)=x$ when $S=\emptyset$.

To show that these satisfy the equation, note first that $f(x)^2=x^2$ for all $x$, so it remains to show that:

$$
f\left(xf(x)+y^2\right)=xf(x)+y^2.
$$

If $S\subseteq\left[-c,-c^2\right)$ then $xf(x)\ge-c^2$ for all $x$ whether $x\in S$ or $x\notin S$. This translates to $xf(x)+y^2\ge-c^2$ and therefore $xf(x)+y^2\notin S$ so the equation is satisfied.

If $S\subseteq\left(-c,-c^2\right]$ then $xf(x)>-c^2$ for all $x$ whether $x\in S$ or $x\notin S$. This translates to $xf(x)+y^2>-c^2$ and therefore $xf(x)+y^2\notin S$ so the equation is satisfied.

**Claim 1:** $f(0)=0$, $f(1)=1$.

$P(0,x)\Rightarrow f\left(f(x)^2\right)=x^2$, so:

$$
f\left(x^4\right)=f\left(f\left(f(x)^2\right)^2\right)=f(x)^4.
$$

With $x=0$ and $x=1$ we have $\{f(0),f(1)\}\subseteq\{0,1\}$.

If $f(0)=f(1)$ then:

$P(x,0)\Rightarrow f\left(xf(x)+f(0)^2\right)=xf(x)$.

$P(x,1)\Rightarrow f\left(xf(x)+f(0)^2\right)=xf(x)+1$, contradiction. Now suppose $f(0)=1$ and $f(1)=0$, a contradiction suffices to prove the claim.

$P(x,0)\Rightarrow f(xf(x)+1)=xf(x)$.

$P(0,xf(x)+1)\Rightarrow f\left(x^2f(x)^2\right)=x^2f(x)^2+2xf(x)+1$.

$P\left(f(x)^2,1\right)\Rightarrow f\left(x^2f(x)^2\right)=x^2f(x)^2+1$.

Comparing the last two, we obtain $f(x)=0$ for all $x\ne0$, but this gives a contradiction upon $P(0,2)\Rightarrow f\left(f(2)^2\right)=4$.

**Claim 2:** $f(x)>x-1$ for all $x\ge0$.

First, from $f\left(x^4\right)=f(x)^4$ we have $f(x)\ge0$ for all $x\ge0$, and in particular $f(x)>x-1$ for all $0\le x<1$.

Now:

$P\left(1,f(x)^2\right)\Rightarrow f\left(x^4+1\right)=f(x)^4+1=f\left(x^4\right)+1$, so $f(x+1)=f(x)+1$ for all $x\ge0$. By induction, $f(x+n)=f(x)+n$ for all $x\ge0$ and $n\in\mathbb N$, so we can extend $f(x)>x-1$ for all $0\le x<1$ to all $x\ge0$.

**Claim 3:** $f(x)\ge x$ for all $x\ge0$.

For $x\ge0$ and $n\in\mathbb N$:

$$
\begin{align*}
f(x)-x+\frac{3f(x)^2-3x^2}{2n}+\frac{f(x)^3-x^3}{n^2}+\frac{f(x)^4-x^4}{4n^3}&=\frac{(f(x)+n)^4-(x+n)^4}{4n^3}\\
&=\frac{f(x+n)^4-(x+n)^4}{4n^3}\\
&=\frac{f\left((x+n)^4\right)-(x+n)^4}{4n^3}\\
&>-\frac1{4n^3}
\end{align*}
$$
and the claim follows from $n\to\infty$.

**Claim 4:** $f(x)\le x$ for all $x\ge0$.

$P(0,x)\Rightarrow f(x)^2\le f\left(f(x)^2\right)=x^2$, and since $f(x)\ge0$ for all $x\ge0$ we can take the square root to get the result.

Combining Claims 3 and 4, $f(x)=x$ for all $x\ge0$.

**Claim 5:** $f(x)=x$ for all $x\le-1$.

$P(0,x)\Rightarrow f(x)^2=x^2$, so $P(x,y)$ becomes $f\left(xf(x)+y^2\right)=xf(x)+y^2$.

Suppose $f(u)=-u$ for some $u\le-1$, then $u^2+u\ge0$ so:

$P\left(u,\sqrt{u^2+u}\right)\Rightarrow f(u)=u$, so $u=0$ contradicting $u\le-1$.

Now we have to figure out what happens to $f(x)$ for $x\in(-1,0)$. Let $S=\{x\in(-1,0)\mid f(x)=-x\}$ and $c=\displaystyle\sup_{x\in(-1,0)}f(x)$. Note two properties: first, that $f(x)=x\Leftrightarrow x\notin S$, and secondly that $c$ is finite, since $\lvert f(x)\rvert=\lvert x\rvert<1$ for all $x\in(-1,0)$ implies $c\le1$. If $c\le0$ then $f(x)=x$ for all $x\in(-1,0)$, leading to $f(x)=x$, part of the aforementioned solution set with $S=\emptyset$. So we may assume that $c\in(0,1]$.

**Claim 6:** $S\subseteq\left[-c,-c^2\right]$.

Note that $c=\displaystyle\sup_{x\in S}(-x)=-\inf S$, so $S\subseteq[-c,0)$.

Suppose $-c^2<u<0$ with $u\in S$. Then, since $c^2>-u$, there is some $v\in S$ with $v^2>-u$. But then:

$P\left(v,\sqrt{u+v^2}\right)\Rightarrow f(u)=u$, contradicting $u\in S$.

The claim is proven. Now if $-c\in S$ then $P(-c,0)\Rightarrow f\left(-c^2\right)=-c^2\Rightarrow-c^2\notin S$, so at least one of $-c$ and $-c^2$ must be absent from $S$.

Suppose $c=1$, then $S\subseteq\{-1\}$. If $-1\in S$ then it would imply that both $-c$ and $-c^2$ are in $S$, this is impossible so we must have $S=\emptyset$, however this contradicts $c=1$ (since we would have $f(x)=x$ for all $x$).

Therefore, $c\ne1$, so the solution set we provided is complete.
