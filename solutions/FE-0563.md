$f\left(f(x)^2+xy\right)=x^2+f(x)f(y)$.

$P(0,x)\Rightarrow f\left(f(0)^2\right)=f(0)f(x)$, there are no constant solutions so we must have $f(0)=0$.

$P(1,0)\Rightarrow f\left(f(1)^2\right)=1$.

$P\left(f(1)^2,0\right)\Rightarrow f(1)^4=f(1)$.

If $f(1)=0$, $P(1,1)\Rightarrow0=1$, contradiction. So $f(1)=1$.

$P(1,x)\Rightarrow f(x+1)=f(x)+1$.

$P(x,y+1)\Rightarrow f\left(f(x)^2+xy+x\right)=x^2+f(x)f(y)+f(x)=f\left(f(x)^2+xy\right)+f(x)$.

For $x\ne0$, $f(x)^2+xy$ can take any value, so we have $f(x+y)=f(x)+f(y)$ for all $x\ne0$. It's also true for $x=0$, so $f$ is additive.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=x^2$.

We obtain $f\left(f(x)^2+f(y)^2\right)=x^2+y^2$, so by #475 we have $f(x)=x$ for all $x\ge0$. Using $f(x+1)=f(x)+1$ we can extend this to all of $\mathbb R$: we can get by induction in two directions that $f(x+n)=f(x)+n$ for all $n\in\mathbb Z$, then for any $x$ just choose some $n$ such that $x+n\ge0$. We'll obtain $f(x)+n=f(x+n)=x+n$ so our solution in this case is $\boxed{f(x)=x}$.
