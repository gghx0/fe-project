This problem is similar to $\#7$ (2022 A6).

Denote the assertion by $P(x, y)$.
Let $V$ = $Im(f)$.

$P(-f(0), 0)$ gives

$$
f(-f(0) + f(0)) = f(-f(0)) + f(0) \implies f(-f(0)) = 0
$$

So, $0 \in V$

***

Claim 1: $a \in V \implies -a \in V$.

Proof: If $a = -f(0)$, the result is trivial. So we assume $a \neq -f(0)$, and $a = f(t)$.

Then $P(-a-f(0), \frac{t}{-a-f(0)})$ gives $f(-a -f(0) + f(t)) = f(-a-f(0)) + f(t) \implies f(-f(0)) = a + f(-a-f(0)) \implies -a = f(-a-f(0))$
***
Claim 2: $a, b \in V \implies a+b \in V$

Proof: If $a = f(0)$, and $b = f(0)$, Then $P(0, 0)$ gives $f(f(0)) = 2f(0) = a + b$.

Otherwise, WLOG, $a \neq f(0)$. So, we have $a = f(z)$, $b = f(w)$, $z \neq 0$. Then $P(z, \frac{w}{z})$ gives $f(z + f(w)) = f(z) + f(w) \implies f(z + f(w)) = a + b.$

Hence, V is a subgroup of $(\mathbb{R}, +)$. Let $S$ be a set of coset representatives for $\mathbb{R} / V$. Hence every real number $x$ has a unique representation $s$ + $v$, where $s \in S$ and $v \in V$.

Now suppose $a$, $b$ are in the same additive coset of $\mathbb{R} / V$, with $a \neq b$. Then $b - a \in V$, so let $b- a = f(t)$. WLOG $a \neq 0$, as $a$, $b$ are distinct. Then $P(a, t/a)$ gives $f(a + f(t)) = f(a) + f(t) \implies f(b) = f(a) + b - a \implies f(a) - a = f(b) - b$. So $f(a) - a$ is fixed across all members of each additive coset. In particular, $f(a) -a = f(s) - s$, where $s$ is such that $a = s + v$ is the unique representation of $a$ into $S + V$. So $f(a) = f(s) - s + a = f(s) + v$. So f is defined by its values on $S$.

In fact, this is a full characterisation of all possible f. In other words, f can be defined as follows. Let V be a subgroup of $(\mathbb{R}, +)$. Let $S$ be a set of coset representatives of $\mathbb{R} / V$. Hence, every real number $x$ can be represented uniquely as $x = s + v$, where $s \in S$ and $v \in V$. Now choose an arbitrary function $g: S \to V$. Define $f(x) = g(s) + v$.



It remains to show these functions all work.

Suppose $x = s_1 + v_1$, $xy = s_2 +v_2$. $f(x+f(xy)) = f(x + g(s_2)+v_2)  = f(s_1 + (v_1+v_2+g(s_2))$.

We know $v_1 + v_2 + g(s_2) \in V$, as $V$ is closed under addition.

So $f(s_1 + (v_1+v_2+g(s_2)) = g(s_1) + v_1 +v_2 + g(s_2) = g(s_1) + v_1 + g(s_2)+ v_2 = f(x) + f(xy)$.
