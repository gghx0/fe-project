$$
f\left(f\left(x^2\right)+f(xy)\right)=f(x)^2+yf(x).
$$

$\boxed{f(x)=0}$ is a solution, else there is some $j$ with $f(j)\ne0$.

$P(0,x)\Rightarrow f(2f(0))=f(0)^2+xf(0)$, varying $x$ we see that $f(0)=0$ and so $j\ne0$.

$P(j,x)\Rightarrow f\left(f\left(j^2\right)+f(jx)\right)=f(j)^2+xf(j)$, so $f$ is surjective since $f(j)^2+xf(j)$ can take any value.

If $f(a)=f(b)$:

$P\left(j,\frac aj\right)\Rightarrow f\left(f\left(j^2\right)+f(a)\right)=f(j)^2+\frac{af(j)}j$.

$P\left(j,\frac bj\right)\Rightarrow f\left(f\left(j^2\right)+f(a)\right)=f(j)^2+\frac{bf(j)}j$.

Comparing, we obtain $a=b$ and so $f$ is injective.

One more assertion to finish the problem:

$P(x,-f(x))\Rightarrow f\left(f\left(x^2\right)+f(-xf(x))\right)=0=f(0)\Rightarrow f\left(x^2\right)+f(-xf(x))=0$ by injectivity. With $x\mapsto-x$ this is $f\left(x^2\right)+f(xf(-x))=0$, so $f(xf(-x))=f(-xf(x))$ and we can use injectivity againt to get $xf(-x)=-xf(x)$. This implies that $f$ is odd, because $f(0)=0$. Finally, we can apply oddness to $f\left(x^2\right)+f(-xf(x))=0$ to get $f\left(x^2\right)=f(xf(x))$, and use injectivity again to $xf(x)=x^2$. Since $f(0)=0$ again, this is $\boxed{f(x)=x}$.
