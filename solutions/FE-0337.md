$$
f(xf(x)+yf(y))=xf(x)+yf(y).
$$

Let $\{0\}\subseteq S\subseteq\mathbb R$ satisfying the closure property that if $a,b\in S$ then $(a+b)^2\in S$, then:

$$
\boxed{f(x)=\begin{cases}x&\text{if }x\in S+S\\\frac{g(x)}x&\text{if }x\notin S+S\end{cases}}
$$

where $S+S=\{a+b\mid a,b\in S\}$ and $g:\mathbb R\setminus(S+S)\to S$ is any function. To show that these functions work, note that if $x\in S+S$ then $xf(x)=x^2\in S$, while if $x\notin S+S$ then $x\ne0$ and so $xf(x)=g(x)\in S$. Then $xf(x)\in S$ for all $x$, so $xf(x)+yf(y)\in S+S$ for all $x,y$, so $f(xf(x)+yf(y))=xf(x)+yf(y)$.

To see that all solutions are of this form, take $S=\{xf(x)\mid x\in\mathbb R\}$. Easy to see that $\{0\}\subseteq S\subseteq\mathbb R$, and rewriting the equation as:

$$
(xf(x)+yf(y))f(xf(x)+yf(y))=(xf(x)+yf(y))^2,
$$

we see that $S$ has the aforementioned closure property. Finally, we have $f(x)=x$ for all $x\in S+S$ and $xf(x)\in S$ for all $x\notin S+S$, so the solution set is complete.
