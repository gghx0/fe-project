$f\left(f\left(x^2\right)+f\left(y^2\right)\right)=xf(x)+f(y)^2$

First, we reduce this equation to $f\left(x^2\right)=f(x)^2=xf(x)$ and $f(f(x)+f(y))=f(x)+f(y)$, then we provide the general solution.

Swapping $x,y$, we obtain $xf(x)+f(y)^2=yf(y)+f(x)^2$ so $f(x)^2=xf(x)+f(0)^2$. Squaring the original equation:

$$
\left(f\left(x^2\right)+f\left(y^2\right)\right)f\left(f\left(x^2\right)+f\left(y^2\right)\right)+f(0)^2=x^2f(x)^2+2xf(x)f(y)^2+f(y)^4,
$$

$$
\left(f\left(x^2\right)+f\left(y^2\right)\right)\left(xf(x)+f(y)^2\right)+f(0)^2=x^2f(x)^2+2xf(x)f(y)^2+f(y)^4.
$$

Set $x=y=0$, we obtain $2f(0)^3+f(0)^2=f(0)^4$ so $f(0)\in\left\{-\sqrt2+1,\sqrt2+1,0\right\}$.

Set $x=y=1$ and use $f(0)^2=f(1)^2-f(1)$, we obtain $f(1)^4-2f(1)^2+f(1)=0$ so $\left(f(1)^2-f(1)\right)^3-4\left(f(1)^2-f(1)\right)^2-\left(f(1)^2-f(1)\right)=0$ and so $f(0)\in\left\{0,\sqrt{2+\sqrt5},-\sqrt{2+\sqrt5}\right\}$.

Comparing, we obtain $f(0)=0$. Then $f(x)^2=xf(x)$, so $f(x)\in\{0,x\}$ for each $x$.

$P(x,0)\Rightarrow f\left(f\left(x^2\right)\right)=xf(x)$

Next thing to prove is $f\left(x^2\right)=f(x)^2$. Suppose we have some $x$ for which this is not true, clearly $x\ne0$.

If $f(x)=0$ then $f\left(x^2\right)=x^2$ so $P(x,0)$ gives $x^2=0$, contradiction.

If $f(x)=x$ then $f\left(x^2\right)=0$ so $P(x,0)$ gives $0=x^2$, contradiction.

Then it follows that $f\left(x^2\right)=xf(x)=-xf(-x)$ so $f$ is odd.

Final thing to prove is $f(f(x)+f(y))=f(x)+f(y)$. Original equation becomes:

$$
f\left(f\left(x^2\right)+f\left(y^2\right)\right)=f\left(x^2\right)+f\left(y^2\right)
$$

so $f(f(x)+f(y))=f(x)+f(y)$ for all $x,y\ge0$.

We've shown that $f\left(x^2\right)=f(x)^2=xf(x)$ for all $x$ and $f(f(x)+f(y))=f(x)+f(y)$ for $x,y\ge0$ as desired.

Let $S\subseteq[0,\infty)$ such that:

1.  $0\in S$
2.  if $a,b\in S$ then $a+b\in S$
3.  if $x\in S$ then $x^2\in S$ and $\sqrt x\in S$

Then the general solution is $\boxed{f(x)=\begin{cases}0&\text{if }\lvert x\rvert\notin S\\x&\text{if }\lvert x\rvert\in S\end{cases}}$.

We have pathological solutions such as when $S$ is the set of constructible numbers - the set of $0$ and all real numbers $r$ such that you can construct a line segment of length $\lvert r\rvert$ with a straightedge, compass, and segment of length $1$.
