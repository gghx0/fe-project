$f(f(x)+f(y))=x+f(y)$ for all $y\ge0$

$P(x,0)\Rightarrow f(f(x)+f(0))=x+f(0)$

$P(0,x)\Rightarrow f(f(x)+f(0))=f(x)$ for all $x\ge0$

So for all $x\ge0$ we have $f(x)=x+f(0)$. Taking $x\ge\max\{0,-2f(0)\}$ these equations imply that $x+3f(0)=x+f(0)$, so $f(0)=0$

Equation becomes $f(f(x)+y)=x+y$ for all $y\ge0$, which is just #93. Only solution $\boxed{f(x)=x}$.
