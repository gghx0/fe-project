We claim the only solution is $f(x) \equiv x$.

_Proof._
Let $P(x, y)$ denote the problem assertion. It is clear $f(x) \equiv x$ satisfies $P$.

To show this is the only solution, observe $P(0, 0): f(0) = f(0)^2$, so $f(0) \in \{0, 1\}$. If $f(0) = 1$, then $P(1, 0): f(1) = 1 + f(1)$, a clear absurdity.

As such, $f(0) = 0$; we have $P(x, 0): f(x^2) = x^2$ for all $x \in \mathbb{R}$, i.e., $f(x) = x$ for all $x \geq 0$. Now, fix some $x < 0$, and pick some $y \in (0, -x)$. Since $x^2 + xy > 0$, it follows that $x^2 + xy = f(x^2 + xy) = x^2 + f(x)y$, so $f(x) = x$ for all $x \in \mathbb{R}$, as desired.
