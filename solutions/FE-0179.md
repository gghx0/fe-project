Clearly the functions $f(x) = cx$ work, so we prove that they are the only ones.
Let $P(x,y)$ denote the assertion $f(x^2 + y^2) = xf(x) + yf(y)$.

$P(x, 0): f(x^2) = xf(x)$
$P(x,y): f(x^2+y^2) = xf(x)+yf(y) = f(x^2) + f(y^2)$

By $f(x^2) = xf(x)$ we can easily see that $f(0) = 0$ and $f(-x) = -f(x)$ for nonzero $x$, so $f$ is odd. With the second equation, we can also see that $f$ is additive. Therefore

$$
\begin{aligned}
f((x+1)^2) &= (x+1)f(x+1) \\
\iff f(x^2) + f(2x) + f(1) &= xf(x) + xf(1) + f(x) + f(1) \\
\iff xf(x) + 2f(x) + f(1) &= xf(x) + xf(1) + f(x) + f(1) \\
\iff f(x) &= xf(1)
\end{aligned}
$$

Therefore $f(x) = cx$ for some constant $c$.
