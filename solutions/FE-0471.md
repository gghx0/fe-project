$$
f(xf(x)+f(xy))=f\left(x^2\right)+yf(x).
$$
Note that $\boxed{f(x)=0}$ is a solution, any other solution must have some $j$ such that $f(j)\ne0$.

$P(j,x)\Rightarrow f(jf(j)+f(jx))=f\left(j^2\right)+xf(j)$, and $f\left(j^2\right)+xf(j)$ can take any real value so $f$ is surjective. If $f(1)=0$ we have:

$P(1,x)\Rightarrow f(f(x))=0$, and in particular there is some $x$ such that $f(x)=j$, so $f(j)=0$. This is clearly a contradiction, so we cannot have $f(1)=0$.

If $f(a)=f(b)$:
$$
f(1)+af(1)\overset{P(1,a)}=f(f(1)+f(a))=f(f(1)+f(b))\overset{P(1,b)}=f(1)+bf(1),
$$
so $a=b$ (since $f(1)\ne0$), that is, $f$ is injective.

$P(-1,1)\Rightarrow f(0)=f(1)+f(-1)$.

$P(1,-1)\Rightarrow f(f(0))=0$.

$P(0,0)\Rightarrow f(0)=0$.

$P(x,0)\Rightarrow f(xf(x))=f\left(x^2\right)\Rightarrow xf(x)=x^2$, so $f(x)=x$ for all $x\ne0$. Combined with $f(0)=0$ this implies $\boxed{f(x)=x}$ for all $x$.
