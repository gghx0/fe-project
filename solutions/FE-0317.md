$f\left(x^2+f(xy)\right)=x^2+f(xy)$.

Equation implies $f(x+f(y))=x+f(y)$ for all $x>0$, or $f(x)=x$ for all $x>f(y)$. If $f$ is unbounded below we get $\boxed{f(x)=x}$ for all $x$. Otherwise, let $c=\inf f$, then $f(x)=x$ for all $x>c$ and so:

$$
f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}
$$

for a function $g:(-\infty,c]\to[c,\infty)$.

The last thing to ensure is that $f(f(0))=f(0)$, it gives us the solution sets:

(if $c>0$ and $f(0)>c$):

$$
\boxed{f(x)=\begin{cases}x&\text{if }x>c\\a&\text{if }x=0\\g(x)&\text{if }0\ne x\le c\end{cases}}
$$

which fits for any constants $c>0$ and $a\in(c,\infty)$, and function $g:(-\infty,c]\setminus\{0\}\to[c,\infty)$.

(if $c>0$ and $f(0)\le c$): clearly $f(0)=c$, so:

$$
\boxed{f(x)=\begin{cases}x&\text{if }x\ge c\\c&\text{if }x=0\\g(x)&\text{if }0\ne x<c\end{cases}}
$$

which fits for any constant $c>0$ and function $g:(-\infty,c)\setminus\{0\}\to[c,\infty)$.

(if $c\le0$):

$$
\boxed{f(x)=\begin{cases}x&\text{if }x>c\\g(x)&\text{if }x\le c\end{cases}}
$$

which fits for any constant $c\le0$ and function $g:(-\infty,c]\to[c,\infty)$.
