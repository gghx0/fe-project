Find all functions $f:\mathbb{R}\to\mathbb{R}$ such that:

$$
f(xf(x)+xf(y))=f\left(x^2\right)+yf(x)
$$

for all $x,y\in\mathbb{R}$.

First, $\boxed{f(x)=0}$ is a solution, else $\exists j:f(j)\ne0$.

If $f(a)=f(b)$:

$P(j,a)\Rightarrow f(jf(j)+jf(a))=f\left(j^2\right)+af(j)$

$P(j,b)\Rightarrow f(jf(j)+jf(a))=f\left(j^2\right)+bf(j)$

Comparing, $a=b$, so $f$ is injective.

$P(0,-1)\Rightarrow f(0)=0$

$P(x,0)\Rightarrow f(xf(x))=f\left(x^2\right)\Rightarrow xf(x)=x^2\Rightarrow f(x)=x$ for all $x\ne0$

These facts combined imply $\boxed{f(x)=x}$ for all $x$.
