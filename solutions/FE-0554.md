$f\left(f(x)^2+f(x)f(y)\right)=f(x)^2+xy$

$P(x,0)\Rightarrow f\left(f(x)^2+f(x)f(0)\right)=f(x)^2\Rightarrow f\left(x^2+xf(0)\right)=x^2$ since $f$ is surjective. $x=0$ implies $f(0)=0$, so $f(x)=x$ for all $x\ge0$

$P(x,x)\Rightarrow f\left(2f(x)^2\right)=f(x)^2+x^2\Rightarrow2f(x)^2=f(x)^2+x^2$ so $f(x)\in\{-x,x\}$ for each $x$.

If $f(a)\ne-a$ and $f(b)\ne b$ for some $b$, then $a,b\ne0$ and so:

$P(a,b)\Rightarrow f\left(a^2-ab\right)=a^2+ab$

Since $f\left(a^2-ab\right)\in\left\{a^2-ab,ab-a^2\right\}$, either $a^2-ab=a^2+ab\Rightarrow ab=0$ or $ab-a^2=a^2+ab\Rightarrow a=0$, but both are impossible and so either $\boxed{f(x)=x}$ for all $x$ or $f(x)=-x$ for all $x$, the latter isn't a solution.
