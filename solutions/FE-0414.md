***
We solve the general equation $$f(g(x)+yf(x))=f\left(x^2\right)+f(xy)$$
***
If $f(k)=0$ for some $k$:

$P(k,x)\Rightarrow f(g(k))=f\left(k^2\right)+f(kx)$, so $f$ is constant, only constant solution is $\boxed{f(x)=0}$ which fits.

Otherwise assume $f(x)\ne0$ for all $x\ne0$


If $f(k)\ne k$ for some $k$

$P\left(k,\frac{g(k)}{k-f(k)}\right)\Rightarrow f\left(k^2\right)=0\Rightarrow k^2=0$, but then $f(0)=0$ so $f(k)=f(0)=0=k$, contradiction.

Therefore $\boxed{f(x)=x}$ for all $x$.
