$$
f(2f(x)f(y))=xy+f(xy).
$$

$P(x,1)\Rightarrow f(2f(1)f(x))=x+f(x)$ so $f$ is injective.

$P(xy,1)\Rightarrow f(2f(xy)f(1))=xy+f(xy)=f(2f(x)f(y))$ so $f(xy)f(1)=f(x)f(y)$ by injectivity. If $f(1)=0$ then setting $x=y$ gives $f(x)=0$ for all $x$ which is not a solution. So $f(1)\ne0$ and we can define a function $g:\mathbb R\to\mathbb R$ as $g(x)=\frac{f(x)}{f(1)}$ such that $g(xy)=g(x)g(y)$.

$P(x,1)\Rightarrow f\left(\frac1{2f(1)^2}\right)f(2f(1)f(x))=(x+f(x))f\left(\frac1{2f(1)^2}\right)\Rightarrow g(g(x))=ag(x)+bx$ where $b=\frac1{f(1)^2}f\left(\frac1{2f(1)^2}\right)$ and $a=bf(1)$.

Let $Q(x,y)$ be the assertion $g(xy)=g(x)g(y)$.

$Q(x,0)\Rightarrow g(0)(g(x)-1)=0\Rightarrow g(0)=0$ since $g$ is injective (therefore nonconstant).

$Q(x,1)\Rightarrow g(x)(g(1)-1)=0\Rightarrow g(1)=1$ since $g$ is nonconstant.

Therefore $b=g(g(1))-ag(1)=1-a$.

If $g(k)=0$ for some $k\ne0$, then:

$Q\left(\frac xk,k\right)\Rightarrow g(x)=0$ which contradicts that $g$ is nonconstant.

Hence $g(x)\ne0$ for all $x\ne0$.

If $a=0$ then (by its definition) $b=0$, which contradicts $b=1-a$.

If $a=1$ then $b=1-a=0$, so (by its definition) $a=0$, contradiction.

For all $x\ne0$:

$Q\left(x,\frac1x\right)\Rightarrow g\left(\frac1x\right)=\frac1{g(x)}$, in $g(g(x))=ag(x)+(1-a)x$ now we have (again for $x\ne0$):

$$
\frac1{ag(x)+(1-a)x}=\frac1{g(g(x))}=\frac a{g(x)}+\frac{1-a}x,
$$

which simplifies to:

$$
xg(x)=a^2xg(x)+a(1-a)x^2+a(1-a)g(x)^2+(1-a)^2xg(x)
$$

$$
\Rightarrow a(1-a)x^2+\left(2a^2-2a\right)xg(x)+a(1-a)g(x)^2=0.
$$

We already established $a\notin\{0,1\}$, so we can divide everything by $a(1-a)$ to get:

$$
x^2-2xg(x)+g(x)^2=0\Rightarrow g(x)=x.
$$

Then $f$ is linear. Testing, our only linear solution is $\boxed{f(x)=x}$.
