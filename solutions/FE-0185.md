Let $P(x,y)$ denote the given assertion $f(x^2+yf(y)) = x^2+y^2.$

$P(x,0) : f(x^2) = x^2.$ This means $f(x)=x$ for all $x \ge 0.$

For any fixed $y$, we have $x^2 + yf(y) \ge 0$ for all sufficiently large $x.$ This means $x^2 + yf(y) = f(x^2+yf(y)) = x^2 + y^2$ for all sufficiently large $x$ for a fixed $y$, which means $yf(y) = y^2.$ So $f(y) = y$ for all $y \neq 0.$ We also have $f(0) = 0$ by $P(0,0)$.

So $f(x)=x$ for all real $x$, and it works.
