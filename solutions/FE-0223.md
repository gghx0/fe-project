Solution by **AIME4096**.
***

We claim that the complete solution set consists of the functions $f(x)=kx$ for all $x\in\mathbb{R}$, where $k\in\mathbb{R}$, together with the additional family $f(0)=k$ and $f(x)=kx$ for every $x\neq0$, where $k>0$. The first family is immediate, since $f(x^2+f(y^2))=k(x^2+ky^2)=kx^2+k^2y^2=xf(x)+f(y)^2$. For the second family, let $k>0$ and define $f(0)=k$ and $f(x)=kx$ for $x\neq0$. If $x,y\neq0$, then $x^2+f(y^2)=x^2+ky^2>0$, so $f(x^2+f(y^2))=k(x^2+ky^2)=kx^2+k^2y^2=xf(x)+f(y)^2$. If $y=0$, then $x^2+k>0$, so $f(x^2+k)=k(x^2+k)=kx^2+k^2=xf(x)+f(0)^2$. If $x=0$ and $y\neq0$, then $f(y^2)=ky^2>0$, so $f(f(y^2))=f(ky^2)=k^2y^2=f(y)^2$. Finally, at $(0,0)$ both sides equal $k^2$. Thus all claimed functions are indeed solutions. Let $P(x,y)$ denote the assertion $f(x^2+f(y^2))=xf(x)+f(y)^2$ for all $x,y\in\mathbb{R}$, and put $c=f(0)$.

**Lemma 1.** For every $x\neq0$, $f(-x)=-f(x)$.

*Proof.* Comparing $P(x,y)$ and $P(-x,y)$ gives $xf(x)+f(y)^2=-xf(-x)+f(y)^2$. Hence $xf(x)=-xf(-x)$, and since $x\neq0$, $f(-x)=-f(x)$. $\square$

**Lemma 2.** We have $f(c)=c^2$, $f(x^2+c)=xf(x)+c^2$ for every $x\in\mathbb{R}$, and $f(f(y^2))=f(y)^2$ for every $y\in\mathbb{R}$.

*Proof.* Substituting $(0,0)$, $(x,0)$, and $(0,y)$ into $P$ gives, respectively, $f(c)=c^2$, $f(x^2+c)=xf(x)+c^2$, and $f(f(y^2))=f(y)^2$. $\square$

**Lemma 3.** We have $c\ge0$.

*Proof.* Suppose that $c<0$, and put $a=\sqrt{-c}>0$, so that $c=-a^2$. By Lemma $2$, $f(c)=c^2=a^4$. Since $c=-a^2\neq0$, Lemma $1$ gives $f(-c)=-f(c)=-a^4$. As $-c=a^2$, we obtain $f(a^2)=-a^4$. On the other hand, Lemma $2$ with $x=a$ gives $c=af(a)+c^2$, so $f(a)=\frac{c-c^2}{a}=-a(1+a^2)$. Now apply $P(a^2,a)$. Since $(a^2)^2+f(a^2)=a^4-a^4=0$, the left-hand side equals $f(0)=c=-a^2$. The right-hand side equals $a^2f(a^2)+f(a)^2=-a^6+a^2(1+a^2)^2=a^2+2a^4>0$, a contradiction. Hence $c\ge0$. The next idea is to replace the original functional equation by a group action on the tail of the graph. This is the main structural device of the proof. We shall regard a vector $(h,k)$ as encoding the statement that translating the input by $h$ translates the corresponding tail of the graph vertically by $k$. $\square$

**Definition.** A pair $(h,k)\in\mathbb{R}^2$ is called a *tail-translation vector* if there exists $R\in\mathbb{R}$ such that $f(t+h)=f(t)+k$ for every $t\ge R$. Let $\mathcal T$ denote the set of all tail-translation vectors.

**Lemma 4.** The set $\mathcal T$ is an additive subgroup of $\mathbb{R}^2$, and for each fixed $h\in\mathbb{R}$ there is at most one $k\in\mathbb{R}$ such that $(h,k)\in\mathcal T$.

*Proof.* Suppose $(h_1,k_1),(h_2,k_2)\in\mathcal T$. Choose $R$ sufficiently large that all applications below are valid. Then $f(t+h_1+h_2)=f(t+h_1)+k_2=f(t)+k_1+k_2$, so $(h_1+h_2,k_1+k_2)\in\mathcal T$. If $(h,k)\in\mathcal T$, then from $f(t+h)=f(t)+k$, after replacing $t$ by $t-h$ and taking $t$ sufficiently large, we obtain $f(t-h)=f(t)-k$, so $(-h,-k)\in\mathcal T$. Finally, if $(h,k_1)$ and $(h,k_2)$ both belong to $\mathcal T$, then for all sufficiently large $t$, $f(t)+k_1=f(t+h)=f(t)+k_2$, and therefore $k_1=k_2$.

Thus the projection of $\mathcal T$ onto the first coordinate carries an additive "translation cocycle". More precisely, if $\mathcal H=\{h\in\mathbb{R}:\exists k\text{ with }(h,k)\in\mathcal T\}$, then the uniqueness statement allows us to define an additive map $\lambda:\mathcal H\to\mathbb{R}$ by $(h,\lambda(h))\in\mathcal T$. The functional equation will now force this abstract additive map to determine the actual slope of $f$. $\square$

**Lemma 5.** For every $y\in\mathbb{R}$, the vector $(f(y^2)-c,f(y)^2-c^2)$ belongs to $\mathcal T$.

*Proof.* Subtract $P(x,0)$ from $P(x,y)$. By Lemma $2$, $f(x^2+f(y^2))-f(x^2+c)=f(y)^2-c^2$. Put $t=x^2+c$. Since $x^2$ ranges over $[0,\infty)$, $t$ ranges over $[c,\infty)$, and hence $f(t+f(y^2)-c)=f(t)+f(y)^2-c^2$ for every $t\ge c$. Therefore $(f(y^2)-c,f(y)^2-c^2)\in\mathcal T$. $\square$

**Lemma 6.** If $f\not\equiv0$, then $\mathcal T$ contains some vector $(h,k)$ with $h>0$ and $k\neq0$.

*Proof.* Assume for the sake of contradiction that $f(y)^2=c^2$ for every $y\in\mathbb{R}$. If $c=0$, this immediately gives $f\equiv0$, contrary to hypothesis. Hence $c\neq0$, and $|f(y)|=|c|$ for every $y$. Lemma $2$ then gives $|f(x^2+c)|=|c|$, whereas $f(x^2+c)=xf(x)+c^2$. Therefore $|c|=|xf(x)+c^2|\ge x|c|-c^2$. Choosing $x>|c|+1$ makes the right-hand side strictly larger than $|c|$, a contradiction. Hence there exists $y$ such that $f(y)^2-c^2\neq0$. By Lemma $5$, $(h_0,k_0)=\bigl(f(y^2)-c,f(y)^2-c^2\bigr)\in\mathcal T$ with $k_0\neq0$. Its first coordinate cannot be zero, since otherwise $(0,k_0)\in\mathcal T$ would imply $f(t)=f(t)+k_0$ for every sufficiently large $t$, impossible. Thus $h_0\neq0$. If $h_0>0$, take $(h,k)=(h_0,k_0)$; if $h_0<0$, take its negative. Then $(h,k)\in\mathcal T$, $h>0$, and $k\neq0$. $\square$

**Lemma 7.** Suppose $(h,k)\in\mathcal T$ with $h>0$ and $k\neq0$. Then there exist $R_0>0$ and $r=\frac{h}{k}$ such that $f(x)=rx$ for every $x\ge R_0$.

*Proof.* Choose $R$ such that $f(t+h)=f(t)+k$ for every $t\ge R$. Choose $R_0>0$ sufficiently large that $x^2\ge R$ and $x^2+c\ge R$ whenever $x\ge R_0$. Fix $x\ge R_0$, and define $u_n=\sqrt{x^2+nh}$ for every integer $n\ge0$. Since $x^2+c\ge R$, repeated application of the translation relation gives $f(x^2+c+nh)=f(x^2+c)+nk$ for every $n\ge0$. Since $u_n^2=x^2+nh$, Lemma $2$ gives $f(u_n^2+c)=u_nf(u_n)+c^2$. Consequently $u_nf(u_n)=xf(x)+nk$. Put $A=xf(x)$. Then $u_nf(u_n)=A+nk$, and because $u_n^2=x^2+nh$, we obtain $f(u_n)^2=\frac{(A+nk)^2}{x^2+nh}$. For each $n\ge0$, Lemma $5$ gives a tail-translation vector $V_n=\bigl(f(u_n^2)-c,f(u_n)^2-c^2\bigr)$. Since $u_{n+1}^2-u_n^2=h$ and $u_n^2\ge x^2\ge R$, the defining relation for $(h,k)$ gives $f(u_{n+1}^2)-f(u_n^2)=k$. Hence $V_{n+1}-V_n=\bigl(k,f(u_{n+1})^2-f(u_n)^2\bigr)\in\mathcal T$.

For every $n\ge1$, both $\bigl(k,f(u_n)^2-f(u_{n-1})^2\bigr)$ and $\bigl(k,f(u_{n+1})^2-f(u_n)^2\bigr)$ belong to $\mathcal T$. They have the same first coordinate $k$, so Lemma $4$ forces their second coordinates to be equal. Thus the sequence $\bigl(f(u_n)^2\bigr)_{n\ge0}$ has constant first difference. Therefore there exist $B,L\in\mathbb{R}$ such that $f(u_n)^2=B+nL$ for every $n\ge0$. Combining the two formulas for $f(u_n)^2$ gives $\frac{(A+nk)^2}{x^2+nh}=B+nL$ for every $n\ge0$. Equivalently, the polynomial $R(z)=(A+kz)^2-(x^2+hz)(B+Lz)$ vanishes at every nonnegative integer. At this point the discrete orbit can be compressed into a complex-analytic statement. Define $H(w)=w^2R(\frac{1}{w})$ for $w\neq0$. Since $R$ has degree at most $2$, $H$ extends holomorphically to $w=0$. For every positive integer $n$, we have $H(\frac{1}{n})=n^{-2}R(n)=0$, and $\frac{1}{n}\to0$. By the identity theorem, $H$ is identically zero. Thus $R$ is the zero polynomial.

Comparing coefficients in $(A+kz)^2=(x^2+hz)(B+Lz)$ gives $A^2=x^2B$, $2Ak=x^2L+hB$, and $k^2=hL$. Substituting $B=A^2/x^2$ and $L=k^2/h$ into the middle identity yields $2Ak=\frac{x^2k^2}{h}+\frac{hA^2}{x^2}$. Multiplying by $hx^2$ and completing the square gives $(x^2k-hA)^2=0$. Hence $x^2k=hA=hxf(x)$. Since $x>0$, we obtain $f(x)=\frac{k}{h}x$. Therefore $f(x)=rx$ for every $x\ge R_0$. $\square$

**Lemma 8.** If $f\not\equiv0$, then there exists $r\neq0$ and $R>0$ such that $f(x)=rx$ for every $x\ge R$.

*Proof.* By Lemma $6$, choose $(h,k)\in\mathcal T$ with $h>0$ and $k\neq0$. Lemma $7$ gives $f(x)=\frac{k}{h}x$ for every sufficiently large positive $x$. Setting $r=\frac{k}{h}$ gives $r\neq0$.

**Lemma 9.** For every nonzero solution, the slope $r$ of the positive tail satisfies $rc=c^2$.

*Proof.* Let $R>0$ be such that $f(x)=rx$ for every $x\ge R$. Choose $x$ sufficiently large that $x\ge R$ and $x^2+c\ge R$. By Lemma $2$, $f(x^2+c)=xf(x)+c^2$. Since both $x$ and $x^2+c$ lie in the linear tail, this becomes $r(x^2+c)=rx^2+c^2$, and hence $rc=c^2$. Since $c\ge0$ by Lemma $3$, the last identity yields $c=0$ or, if $c>0$, $r=c$. $\square$

**Lemma 10.** If $c=0$, then $f(x)=rx$ for every $x\in\mathbb{R}$ for some $r\in\mathbb{R}$.

*Proof.* If $f\equiv0$, take $r=0$. Otherwise Lemma $8$ gives a nonzero $r$ and a positive linear tail. Fix any $x\neq0$. Choose $y>0$ sufficiently large that $y$ and $y^2$ belong to the positive linear tail. Then $f(y)=ry$ and $f(y^2)=ry^2$. Set $z=x^2+ry^2$. If $r>0$, then $z\to+\infty$ as $y\to+\infty$, so for sufficiently large $y$ the positive linear-tail formula gives $f(z)=rz$. If $r<0$, then $z\to-\infty$, so $-z\to+\infty$ and the positive linear-tail formula gives $f(-z)=-rz$. Since $z\neq0$ for sufficiently large $y$, Lemma $1$ gives $f(z)=-f(-z)=rz$. Applying $P(x,y)$ now gives $r(x^2+ry^2)=xf(x)+r^2y^2$. Canceling $r^2y^2$ yields $xf(x)=rx^2$, and since $x\neq0$, $f(x)=rx$. Together with $f(0)=c=0$, this proves the claim. $\square$

**Lemma 11.** If $c>0$, then $f(0)=c$ and $f(x)=cx$ for every $x\neq0$.

*Proof.* By Lemma $9$, the positive-tail slope satisfies $r=c$. Hence there exists $R>0$ such that $f(t)=ct$ for every $t\ge R$. Fix $x\neq0$. Choose $y>0$ sufficiently large that $y,y^2\ge R$ and $z=x^2+cy^2\ge R$. This is possible because $c>0$ and therefore $z\to+\infty$ as $y\to+\infty$. Then $f(y)=cy$, $f(y^2)=cy^2$, and $f(z)=cz$. Applying $P(x,y)$ gives $c(x^2+cy^2)=xf(x)+c^2y^2$, so $cx^2=xf(x)$. Since $x\neq0$, $f(x)=cx$. $\square$

Thence, by Lemma $3$, $c=f(0)\ge0$. If $c=0$, Lemma $10$ gives $f(x)=rx$ for some $r\in\mathbb{R}$. If $c>0$, Lemma $11$ gives $f(0)=c$ and $f(x)=cx$ for every $x\neq0$. Therefore the complete solution set is
$$
f(x)=kx\forall x\in\mathbb{R}, k\in\mathbb{R}\text{ and } f(0)=k,f(x)=kx(x\neq0), k>0.
$$
as desired. $\blacksquare$
