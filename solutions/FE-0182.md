***

Let $P(x,y)$ denote the given assertion $f(x^2+y^2) = f(x)^2 + f(y)^2.$

$P(0,0): f(0) = 2f(0)^2$. This means $f(0) \in \left\{0, \frac{1}{2} \right\}.$

Case 1: $f(0) = 0$

$P(x, 0) : f(x^2) = f(x)^2$

So $f(x^2+y^2) = f(x^2) + f(y^2).$ Therefore $f$ is additive on nonnegative reals, and is bounded $\ge 0$ on nonnegative reals because $f(x^2) = f(x)^2 \ge 0.$ It follows that $f(x) = cx$ for all $x \ge 0$ for some real constant $c.$ We have $cx^2 = c^2x^2$, so $c \in \{0, 1\}.$

Case 1.1: $c=0$

We get $0 =f(x)^2$, so $f(x)=0$ for all real $x.$ This function works.


Case 1.2: $c=1$

We get $x^2 = f(x)^2$, and with $f(x) = 0$ for all $x \ge 0$, this is equivalent to the problem. So we get 

$$
f(x) = \begin{cases} x & x \ge 0 \\ xg(x) & x < 0 \end{cases}
$$

for an arbitrary function $g : (-\infty,0) \to \{-1,1\}.$ This works.
***
Case 2: $f(0) = \frac{1}{2}$

$P(x,0) : f(x^2) = f(x)^2 + \frac{1}{4}.$

So $f(x^2+y^2) = f(x^2) + f(y^2) - \frac{1}{2}.$ Therefore $x \mapsto f(x) - \frac{1}{2}$ is additive on nonnegative reals, and is bounded $\ge -\frac{1}{4}$ on nonnegative reals because $f(x^2) - \frac{1}{2} = f(x)^2 + \frac{1}{4}- \frac{1}{2} \ge -\frac{1}{4}.$ It follows that $f(x) = cx+ \frac{1}{2}$ for all $x \ge 0$ for some real constant $c.$ We have $cx^2 + \frac{1}{2} = \left(cx + \frac{1}{2}\right)^2 + \frac{1}{4}$, so $c=0.$

We get $\frac{1}{2} = f(x)^2 + \frac{1}{4}.$ Therefore $f(x) \in \left\{-\frac{1}{2}, \frac{1}{2}\right\}$ for all $x<0.$ So 

$$
f(x) = \begin{cases} \frac{1}{2} & x \ge 0 \\ g(x) & x<0\end{cases}
$$

for an arbitrary function $g : (-\infty, 0) \to \left\{-\frac{1}{2},\frac{1}{2}\right\}.$ This works.

Combining cases, the functions that work are $f(x)=0$ for all real $x$, $f(x) = 

$$
\begin{cases} x & x \ge 0\\xg(x) & x<0\end{cases}
$$

for an arbitrary function $g:(-\infty,0) \to \{-1,1\}$, and $f(x) = 

$$
\begin{cases} \frac{1}{2} & x \ge 0 \\g(x) & x<0\end{cases}
$$

for an arbitrary function $g:(-\infty,0) \to \left\{-\frac12,\frac12\right\}.$
