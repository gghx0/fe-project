$$
f\left(x^2+f(y)^2\right)=xf(x)+yf(y).
$$

$\boxed{f(x)=0}$ is a solution, otherwise there is some $j$ with $f(j)\ne0$.

$P(0,x)\Rightarrow f\left(f(x)^2\right)=xf(x)$.

From this, we get a few things:

$P(0,0)\Rightarrow f\left(f(0)^2\right)=0$.

$P\left(0,f(0)^2\right)\Rightarrow f(0)=0\Rightarrow j\ne0$.

Moreover, if $f(a)=f(b)\ne0$, $P(0,a)$ and $P(0,b)$ give $a=b$.

If $f(k)=0$ for some $k$ then:

$P(k,j)\Rightarrow f\left(k^2+f(j)^2\right)=jf(j)$.

$P(0,j)\Rightarrow f\left(f(j)^2\right)=jf(j)$.

We obtain $f\left(k^2+f(j)^2\right)=f\left(f(j)^2\right)\ne0$ and so $k^2+f(j)^2=f(j)^2$, that is, $k=0$.

For all $x\ne0$ then:

$P(x,0)\Rightarrow f\left(x^2\right)=xf(x)$.

$P(0,x)\Rightarrow f\left(f(x)^2\right)=xf(x)$.

We obtain $f\left(f(x)^2\right)=f\left(x^2\right)\ne0$, so $f(x)^2=x^2$ for all $x\ne0$.

We also have $f(x)^2=x^2$ for $x=0$, so it's true for all $x$. Therefore this equation reduces to:

$$
f\left(x^2+y^2\right)=xf(x)+yf(y)
$$

which is #179, only solutions of the form $f(x)=cx$, $c\in\mathbb R$. Combining this wth $f(x)^2=x^2$ for all $x$, we have the remaining solutions $\boxed{f(x)=-x}$ and $\boxed{f(x)=x}$, which indeed satisfy $P(x,y)$.
