$f\left(f(x)^2+f(xy)\right)=f(x)^2+xy$

If $f(a)=f(b)$, then $P(1,a)$ and $P(1,b)$ imply $a=b$ so $f$ is injective, and clearly surjective.

$P(x,0)\Rightarrow f\left(f(x)^2+f(0)\right)=f(x)^2$

$P\left(x,\frac1xf^{-1}\left({f(0)}x\right)\right)\Rightarrow f^{-1}\left({f(0)}x\right)=0$ for all $x\ne0$, which is impossible for $f(0)\ne0$ since $f^{-1}$ is bijective.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=f(x)^2\Rightarrow f\left(x^2\right)=x^2$, so $f(x)=x$ for all $x\ge0$

$P\left(x,-\frac{f(x)^2}x\right)\Rightarrow f\left(f(x)^2+f\left(-f(x)^2\right)\right)=0=f(0)\Rightarrow f(x)^2+f\left(-f(x)^2\right)=0$ for all $x\ne0$, but also true for $x=0$. By surjectivity this is $f\left(-x^2\right)=-x^2$, so $f(x)=x$ for all $x\le0$ too, only solution $\boxed{f(x)=x}$
