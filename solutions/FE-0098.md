Find all functions $f:\mathbb R\to\mathbb R$ such that:

$$
f\left(f(x)+y^2\right)=f(x)+yf(y)
$$

for all $x,y\in\mathbb R$.

$P(-1,-1)\Rightarrow f(f(-1)+1)=0$.

$P(f(-1)+1,0)\Rightarrow f(0)=0$.

$P(f(-1)+1,x)\Rightarrow f\left(x^2\right)=xf(x)$, so $xf(x)=-xf(-x)$ which implies that $f$ is odd (since $f(0)=0$).

**Claim:** $f(x+f(y))=f(x)+f(y)$.

From $P(x,y)$ we now have $f\left(f(x)+y^2\right)=f(x)+f\left(y^2\right)$, so $f(f(x)+y)=f(x)+f(y)$ for all $y\ge0$.

So for all $y\ge0$:

$$
-f(f(x)-y)=f(-f(x)+y)=f(f(-x)+y)=f(-x)+f(y)=-f(x)+f(y)=-f(x)-f(-y)
$$

which implies $f(f(x)-y)=f(x)+f(-y)$ for all $y\ge0$. The claim gets proven by combining these two statements.

In the claim, substitute $y\mapsto y^2$, we have $f(x+yf(y))=f(x)+yf(y)$ which is #21. Using the result there, either $xf(x)=0$ for all $x$ or $f(x)=x+c$ for all $x$. Since $f(0)=0$ we have the two solutions $\boxed{f(x)=0}$ and $\boxed{f(x)=x}$.
