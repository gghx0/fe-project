$f(xf(x)+f(x)f(y))=xf(x)+xf(y)$

If $f(k)=0$ for some $k\ne0$:

$P(k,x)\Rightarrow f(0)=kf(x)$, so $f$ is constant. Only constant solution is $\boxed{f(x)=0}$

Otherwise, assume $f(x)\ne0$ for all $x\ne0$

$P(0,0)\Rightarrow f\left(f(0)^2\right)=0\Rightarrow f(0)^2=0\Rightarrow f(0)=0$

For $x\ne0$:

$P(-f(x),x)\Rightarrow0=-f(x)f(-f(x))-f(x)^2\Rightarrow f(-f(x))=-f(x)$

$P(x,-f(x))\Rightarrow f\left(xf(x)-f(x)^2\right)=0\Rightarrow xf(x)-f(x)^2=0\Rightarrow f(x)=x$

Since $f(0)=0$, $\boxed{f(x)=x}$ which fits.
