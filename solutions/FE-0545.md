$f\left(f(x)^2+f(x)f(y)\right)=x^2+f(xy)$.

If $f(a)=f(b)$:

$P(a,1)\Rightarrow f\left(f(a)^2+f(a)f(1)\right)=a^2+f(a)$.

$P(b,1)\Rightarrow f\left(f(a)^2+f(a)f(1)\right)=b^2+f(a)$

so $a^2=b^2$.

**Claim:** $f(x)=x$ for all $x\ge0$.

$P(0,0)\Rightarrow f\left(2f(0)^2\right)=f(0)\Rightarrow4f(0)^4=0\Rightarrow f(0)=0$.

Similarly, if $f(k)=0$ for any $k$ then $k=0$.

$P(x,0)\Rightarrow f\left(f(x)^2\right)=x^2$.

From this equation, we obtain two things: that $[0,\infty)\subseteq f(\mathbb R)$ and that:

$$
f\left(x^4\right)=f\left(f\left(f(x)^2\right)^2\right)=f(x)^4.
$$

Substituting $x=1$, the last equation turns into $f(1)^4=f(1)$, and since $f(1)\ne0$, $f(1)=1$.

$P(1,x)\Rightarrow f(f(x)+1)=f(x)+1$, and since $f(x)+1$ can take any value $\ge1$ we have $f(x)=x$ for all $x\ge1$.

For $0<x<1$ we have, for large enough $y$, $y>1$ and $y^2+yf(x)>1$ and $xy>1$ and so:

$P(y,x)\Rightarrow y^2+yf(x)=y^2+xy\Rightarrow f(x)=x$.

So whether $x=0$, $0<x<1$, or $x\ge1$ we have $f(x)=x$.

Now $f\left(f(x)^2\right)=x^2$ becomes $f(x)^2=x^2$ and so $f(x)\in\{-x,x\}$.

If $f(-k)=k$ for some $k>0$ then:

$P(x,k)\Rightarrow f\left(f(x)^2+kf(x)\right)=x^2+f(xk)$.

$P(x,-k)\Rightarrow f\left(f(x)^2+kf(x)\right)=x^2+f(-xk)$

and so comparing, $f$ is even and we get the solution $\boxed{f(x)=\lvert x\rvert}$ which indeed fits.

If there is no such $k$, then $\boxed{f(x)=x}$ for all $x$.
