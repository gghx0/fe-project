This is a trivial problem.
***

We claim the only solution is $f(x)\equiv x$, which obviously works. We now show it is the only solution. Let $P(x,y)$ denote the assertion that $f(x+f(x)f(y))=x+f(xy)$. 
***
$P(-f(0),0): f(u)=0$ for $u=-f(0)+f(-f(0))f(0)$.

$P(u,y): 0=u+f(uy)$. If $u\ne 0$, then $f$ is constant, which does not work. Hence, $u=0$ so $f(0)=0$.

$P(x,0): f(x)=x$.
