***

Let $P(x,y)$ be the given assertion $f(f(x^2) + f(y^2)) = x^2+f(y)^2.$

Comparing $P(x, y)$ and $P(y,x)$ we get $x^2 + f(y)^2 = y^2 + f(x)^2.$ This means \[f(x)^2 = x^2+C\] for some real constant $C.$
$P(x,x) : f(2f(x^2)) = x^2 + f(x)^2 = 2x^2 + C.$

So we have 
$$
\begin{align*}
(2x^2+C)^2 &= f(2f(x^2))^2 
\\ &= 4f(x^2)^2 + C 
\\ &= 4x^4 + 5C
\end{align*}
$$

for all real $x.$ The polynomials $(2x^2+C)^2$ and $4x^4+5C$ must have the same $x^2$ coefficient, so $4C = 0.$ This means $C=0$ and so 
$$
f(x)^2 = x^2
$$
for all real $x.$ Plugging this into the given assertion we get
$$
f(f(x^2) + f(y^2)) = x^2 + y^2
$$
$$
\begin{align*}
(x^2+y^2)^2 &=f(f(x^2) + f(y^2))^2 
\\ &= (f(x^2) + f(y^2))^2 
\\ &= f(x^2)^2 + 2f(x^2)f(y^2) + f(y^2)^2 
\\ &= x^4 + 2f(x^2)f(y^2) + y^4  
\end{align*}
$$
This means $2f(x^2)f(y^2) = 2x^2y^2$, which means $f(x)f(y) = xy$ for any $x,y > 0.$ Note that $f(x)^2 = x^2$ means $f(x) \in \{x,-x\}$ for all real $x.$ We now have $f(x) = x$ for all $x>0$ or $f(x)=-x$ for all $x>0.$
***
Case 1: $f(x)=x$ for all $x>0$

Using this and $f(x)^2 = x^2$ for all real $x$, the given equation becomes $f(x^2 + y^2) = x^2 + y^2 $, which is true as $x^2+y^2 \ge 0$ (note that $f(0)=0$ too). We get 
$$
f(x)= \begin{cases}x & x \ge 0 \\ xg(x) & x < 0\end{cases} 
$$
where $g : (-\infty, 0) \to \{-1,1\}$ is any function.
***
Case 2: $f(x) = -x$ for all $x>0$

Using this and $f(x)^2 = x^2$ for all real $x$, the given equation becomes $f(-x^2 - y^2) = x^2+y^2$. As $-x^2-y^2$ takes any nonpositive real value, we have $f(x) = -x$ for all $x \le 0.$ So we get $f(x) = -x$ for all real $x$ in this case.
***
Combining cases, we get $f(x)= \begin{cases}x & x \ge 0 \\ xg(x) & x < 0\end{cases}$ where $g : (-\infty, 0) \to \{-1,1\}$ is any function, or $f(x) = -x$ for all real $x.$
