Solution by **EmptySet**.
***

Either $f(x) = 0$ or $f(x) = x$ for all $x$.

Suppose we have some $u$ for which $f(u) \ne u$. Then we may pick $v$ such that $f(u^2) + v\cdot f(u) = uv$, so then $P(u, v) \implies f(u^2) = 0$. Note that there is a contradiction here if $u = 0$, so $f(0) = 0$.

Now, $P(u^2, y) \implies f(u^2 \cdot y) = f(f(u^4)) - f(u^4)$ does not depend on $y$, so $f$ is constant. And because $f(0) = 0$, we must have that $f(x) = 0$ for all $x$.
