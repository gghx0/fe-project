$f\left(f(x)^2+xy\right)=xf(x)+f(xy)$.

If $f(a)=f(b)\ne0$:

$P(a,0)\Rightarrow f\left(f(a)^2\right)=af(a)+f(0)$.

$P(b,0)\Rightarrow f\left(f(a)^2\right)=bf(a)+f(0)$

so $a=b$.

$P(0,0)\Rightarrow f\left(f(0)^2\right)=f(0)$.

If $f(0)\ne0$ then from the above $f(0)^2=0$, contradiction. So $f(0)=0$, and by $P\left(x,\frac yx\right)$ we have $f\left(f(x)^2+y\right)=xf(x)+f(y)$ whether $x=0$ or $x\ne0$. This is #29, solutions $\boxed{f(x)=0}$, $\boxed{f(x)=x}$, $\boxed{f(x)=-x}$ which we can check with this equation, they all work.
