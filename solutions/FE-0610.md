$$
f\left(f\left(x^2\right)+f\left(y^2\right)\right)=f\left(x^2\right)+f\left(y^2\right).
$$

Let $\emptyset\ne S\subseteq\mathbb R$ with the closure property that if $a,b\in S$ such that $a+b\ge0$ then $a+b\in S$. Then:

$$
\boxed{f(x)=\begin{cases}x&\text{if }x\in S+S\\g(x)&\text{if }x\in[0,\infty)\setminus(S+S)\\h(x)&\text{if }x\in(-\infty,0)\setminus(S+S)\end{cases}},
$$

where $S+S=\{a+b\mid a,b\in S\}$ and $g:[0,\infty)\setminus(S+S)\to S$ and $h:(-\infty,0)\setminus(S+S)\to\mathbb R$ are any functions.

To see that these functions work, note that for all $x\ge0$ we have $f(x)\in S$, since if $x\in S+S$ then $x=a+b\ge0$ for some $a,b\in S$ so $f(x)=a+b\in S$, and if $x\in[0,\infty)\setminus(S+S)$ then $f(x)=g(x)\in S$. So for all $x,y\ge0$, $f(x)+f(y)\in S+S$ and so $f(f(x)+f(y))=f(x)+f(y)$ for all $x,y\ge0$.

Now to show that all functions are of this form. Take $S=f(\mathbb R_{\ge0})$. It's easy to see that $\emptyset\ne S\subseteq\mathbb R$, and that if $a,b\in S$ with $a+b\ge0$ then $a+b\in S$. Now for all $x\in S+S$, $f(x)=x$, for all $x\in[0,\infty)\setminus(S+S)$, we have $f(x)\in S$, and $f$ is unconstrained elsewhere.
