$$
f(xf(x)+f(xy))=xf(x)+f(x)f(y).
$$

Suppose $f(k)=0$ for some $k\ne0$.

$P\left(k,\frac xk\right)\Rightarrow f(f(x))=0$, in particular $f(f(1))=0$ and $f(0)=f(f(f(1)))=0$.

$P(x,0)\Rightarrow f(xf(x))=xf(x)$.

In $f(f(x))=0$, substituting $x\mapsto xf(x)$ to get $xf(x)=0$, and combined with the fact that $f(0)=0$ we have $\boxed{f(x)=0}$ which is indeed a solution.

Otherwise, assume $f(x)\ne0$ for all $x\ne0$.

$P(-f(0),0)\Rightarrow f(-f(0)f(-f(0))+f(0))=0$.

$P(-f(0)f(-f(0))+f(0),1)\Rightarrow f(0)=0$.

$P(-1,1)\Rightarrow f(-1)(1-f(1))=0$, and since $f(-1)\ne0$ we have $f(1)=1$.

**Claim:** $f(f(x))=x$.

Easy to show it for $x=0$, now we show it for $x\ne0$.

$P(x,0)\Rightarrow f(xf(x))=xf(x)$.

$P(-1,0)\Rightarrow f(-f(-1))=-f(-1)$.

$P(1,-f(-1))\Rightarrow f(1-f(-1))=1-f(-1)$.

$P(-1,-1)\Rightarrow f(1-f(-1))=f(-1)^2-f(-1)$.

Comparing the last two, $f(-1)=\pm1$.

If $f(-1)=-1$:

$P(1,x)\Rightarrow f(1+f(x))=1+f(x)$.

$P(-1,-x)\Rightarrow f(1+f(x))=1-f(-x)$, so $f$ is odd.

Now we use $f(-xf(x))=-f(xf(x))=-xf(x)$:

$P(-f(x),x)\Rightarrow f(f(x)f(f(x))-xf(x))=0\Rightarrow f(x)f(f(x))-xf(x)=0$, so for all $x\ne0$ we have $f(x)\ne0$ and so $f(f(x))=x$ as desired.

If $f(-1)=1$:

$P\left(x,\frac1x\right)\Rightarrow f(xf(x)+1)=xf(x)+f(x)f\left(\frac1x\right)$.

$P\left(x,-\frac1x\right)\Rightarrow f(xf(x)+1)=xf(x)+f(x)f\left(-\frac1x\right)$, so $f\left(\frac1x\right)=f\left(-\frac1x\right)$ for all $x\ne0$, so $f$ is even.

Now we use $f(-xf(x))=f(xf(x))=xf(x)$:

$P(-f(x),x)\Rightarrow f(-f(x)f(f(x))+xf(x))=0\Rightarrow-f(x)f(f(x))+xf(x)=0$, so for all $x\ne0$ we have $f(x)\ne0$ and so $f(f(x))=x$ as desired.

Finally:

$P(1,f(x-1))\Rightarrow\boxed{f(x)=x}$.
