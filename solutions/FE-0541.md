The answer is $x\mapsto x$ only. 

We will prove that $f$ is surjective. 

Fix an arbitrary number $y$. For all nonnegative number $s$ for some $x$ we have $x^2+xf(y)-s=0$ (for example, because $f(y)^2+4s\geqslant0$), so $f$ takes all nonnegative values. 

Fix a negative number $x$. The for all $s<0$ the equality $x^2+xf(y)=s$ is equivalent to $f(y)=\frac{s-x^2}{x}>0$, which is holds for some $y$. Therefore, $f$ takes all negative values and thus $f$ is surjective. 

Now fix a number $x$ and let $y$ be such number that $f(y)=-f(x)$. Then $P(x, y)$ gives $f(0)=x^2-xf(x)$. Putting $x=0$ we get $f(0)=0$, so $x^2=xf(x)$ and for $x\neq0$ we also have $f(x)=x$.
