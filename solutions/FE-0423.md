$f(xf(x)+f(x)f(y))=xf(x)+xy$

$P(0,0)\Rightarrow f\left(f(0)^2\right)=0$

$P\left(f(0)^2,0\right)\Rightarrow f(0)=0$

If $f(k)=0$: $P(k,1)\Rightarrow k=0$, so $x=0\Leftrightarrow f(x)=0$

$P(x,-f(x))\Rightarrow f(xf(x)+f(x)f(-f(x)))=0\Rightarrow xf(x)+f(x)f(-f(x))\Rightarrow f(-f(x))=-x$ for $x\ne0$, also true for $x=0$

$P(-f(x),-f(y))\Rightarrow f(xf(x)+xy)=xf(x)+f(x)f(y)$

We reduced the equation to #442, only valid solution $\boxed{f(x)=x}$
