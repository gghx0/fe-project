$f\left(f\left(x^2\right)+f(xy)\right)=xf(x)+xy$

$P(1,x)\Rightarrow f(f(1)+f(x))=f(1)+x$, so $f$ is bijective

$P(-x,-y)\Rightarrow f\left(f\left(x^2\right)+f(xy)\right)=-xf(-x)+xy$, comparing with $P(x,y)$ we have $xf(x)=-xf(-x)$ so $f(-x)=-f(x)$ for all $x\ne0$. But there is some $k$ such that $f(k)=0$, and if $k\ne0$ then $f(-k)=-f(k)=0=f(k)$ so $-k=k$, which contradicts $k\ne0$, and so $f(-x)=-f(x)$ for $x=0$ as well!

$P(x,-x)\Rightarrow xf(x)-x^2=0\Rightarrow f(x)=x$ for all $x\ne0$, then $\boxed{f(x)=x}$ since $f(0)=0$ as well
