$f(xf(y)+f(x)f(y))=2yf(x)$

$\boxed{f(x)=0}$ is a solution, else there is some $j$ with $f(j)\ne0$

If $f(a)=f(b)$:

$P(j,a)\Rightarrow f(jf(a)+f(j)f(a))=2af(j)$

$P(j,b)\Rightarrow f(jf(a)+f(j)f(a))=2bf(j)$

so $a=b$, that is, $f$ is injective.

$P\left(x,\frac12\right)\Rightarrow f\left(xf\left(\frac12\right)+f(x)f\left(\frac12\right)\right)=f(x)\Rightarrow xf\left(\frac12\right)+f(x)f\left(\frac12\right)=x$

If $f\left(\frac12\right)=0$ this is $x=0$ for all $x$, impossible, and so $f$ is linear. Testing, we have remaining solutions $\boxed{f(x)=-2x}$ and $\boxed{f(x)=x}$.
