$f\left(f\left(x^2\right)+yf(x)\right)=x^2+xf(y)$

$P(0,-1)\Rightarrow f(0)=0$

$P\left(\sqrt x,0\right)\Rightarrow f(f(x))=x$ for all $x\ge0$

If $f(k)=0$ for some $k\ne0$, then $P(k,x)\Rightarrow f(x)=0$ for all $x$ which isn't a solution, so $x=0\Leftrightarrow f(x)=0$

$P(1,-1)\Rightarrow f(-1)=-1$

$P(-1,xf(1))\Rightarrow f(f(1)-xf(1))=1-f(xf(1))$

$P(1,-x)\Rightarrow f(f(1)-xf(1))=1+f(-x)$

Comparing the last two, we obtain $f(-x)=-f(xf(1))$ and applying this twice, $f(x)=-f(-xf(1))=f\left(xf(1)^2\right)$

But then for $x>0$ we have $xf(1)^2=f\left(f\left(xf(1)^2\right)\right)=f(f(x))=x$ so $f(1)^2=1$

If $f(1)=-1$, $P(1,0)\Rightarrow-1=1$, which is impossible, so we have to have $f(1)=1$.

$P(1,x)\Rightarrow f(x+1)=f(x)+1$

$P(x,y+1)\Rightarrow f\left(f\left(x^2\right)+yf(x)+f(x)\right)=x^2+xf(y)+x=f\left(f\left(x^2\right)+yf(x)\right)+x$

If $x\ne0$ then $f\left(x^2\right)+yf(x)$ can take any value, so $f(y+f(x))=f(y)+x$ for all $x\ne0$, but also true for $x=0$.

Setting $y=0$, we have $f(f(x))=x$ for all $x$, and setting $x\mapsto f(x)$, $f$ is additive.

Back in the original equation, it reduces to $f(yf(x))=xf(y)$, and when taking $x\mapsto f(x)$ again, we see that $f$ is multiplicative as well as additive, only solution $\boxed{f(x)=x}$, since $f\equiv0$ isn't a solution
