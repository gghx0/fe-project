$f(x+f(y))=f(x)+y$ for all $y\ge0$

$P(x,0)\Rightarrow f(x+f(0))=f(x)$

Take some $y\ge\max\{0,-f(0)\}$, then:

$P(x,y+f(0))\Rightarrow f(x+f(y))=f(x)+y+f(0)$

$P(x,y)\Rightarrow f(x+f(y))=f(x)+y$

so $f(0)=0$.
***
$P(0,x)\Rightarrow f(f(x))=x$ for all $x\ge0$

$P(-f(x),x)\Rightarrow f(-f(x))=-x$ for all $x\ge0$

Take any $y\ge0$, if $f(y)\ge0$ then:

$P(x,f(y))\Rightarrow f(x+y)=f(x)+f(y)$

if $f(y)\le0$ then:

$P(x+y,-f(y))\Rightarrow f(x+y)=f(x)+f(y)$

Either way we have $f(x+y)=f(x)+f(y)$ for all $y\ge0$.

Because of this, $f$ is odd. So for $y\le0$:

$$
P(-x,-y)\Rightarrow f(-x+f(-y))=f(-x)-y\Rightarrow f(x+f(y))=f(x)+y
$$

and so the equation is reduced to #6 whether $y\ge0$ or $y\le0$.
